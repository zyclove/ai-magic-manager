# 持久执行任务与当前准备结果接合

## 目标与依据

以 `eb22103` 为基线，前一阶段已实现逐操作资格与当前策略准备，29 套件、859 项通过。执行账本仍只保存文档和候选资源，准备服务尚未从真实任务取得当前发布/绑定上下文。因此先接合这两个现有组件，后续独占资源连接器只能使用服务端任务事实。

完整目标继续包括资源独占归属、发布事务入队、实际写入/分配以及设备回执。此接合不替代这些工作，不开启 `ENFORCE`，不新增对外接口或声称设备受控。

Google 官方 `policies.patch` 是更新或创建接口，未传 updateMask 时会修改全部可变字段；单凭读到资源不存在，不能推导后续写入拥有原子创建或独占权。这是继续保持权属门槛的依据，不能靠随机 ID 或内容相同绕过。[官方接口说明](https://developers.google.com/android/management/reference/rest/v1/enterprises.policies/patch)（2026-10-17 查阅）。

## 实施契约

1. `ManagedPolicyExecutionJournal.writePreparationTarget` 从真实持久任务构造只读目标。仅允许当前 WRITE_POLICY/ASSIGN_POLICY 租约；校验租户、租约代次/令牌/时限、候选资源、设备、文档及版本。先取得授权锁，再取得任务锁，复用现有锁顺序。
2. 重新取得绑定权限与发布版本。被取消、已变成结果不确定状态、到期、权限撤回或版本变化的任务不能返回目标。读取不能创建事件、延长租约或改变状态。
3. 新 `ManagedExecutionPreparationService` 依次读取目标、调用现有准备服务、再次读取目标。两次目标必须一致；准备结果的绑定、发布及文档必须匹配任务冻结值。整个编排入口禁止处于外层数据库事务中。
4. 返回内部候选结果，截止时间取任务期限、租约期限、设备报告和应用证据期限的最小值；返回前检查截止点。结果不是远程写入许可，日志与 toString 不包含资源名、令牌或策略正文。
5. 后续独占资源校验从此目标取得服务端生成并持久化的候选资源；写入前仍须重新检查并提交不确定状态。原有恢复流程和发布关闭状态保持不变。

## 文件范围与验证

- 仅修改执行账本，新增接合服务与专属测试；不修改 `PolicyService`、V1、保留清单或界面文件。
- 使用现有 Spring 事务、JDBC、JUnit、Mockito；不增加调度框架、网络协议或第三方依赖。
- 上下文测试用真实 H2 基线、真实执行账本与明确的下层授权替身；接合测试使用真实账本/接合入口及显式准备结果替身，不将其描述为真实 EMM 端到端。
- 覆盖：合法来源及无副作用、伪造租约/资源/文档、跨租户、过期/取消/未知结果状态、授权撤回、发布变化、网络期间变化、编译结果不匹配、准确截止点及事务边界。
- 先实际 RED，再实现与完整回归；每轮冻结源并核对哈希、原始退出码和自然进程树退出。沿用每阶段 180 秒限制，SDK 与 Git index 分别交接。

## 后续编排的调用契约

| 调用阶段 | 读取的事实 | 允许的动作 | 失败后的处理 |
| --- | --- | --- | --- |
| 从账本领取 | 服务端任务 ID、租约令牌和代次、冻结文档、候选资源 | 取得有限期任务处理权 | 不能把领取成功解释为提供方资源归属 |
| 本次准备接合 | 当前绑定、管理员/合同授权、发布版本、操作资格、设备报告 | 产生内部准备结果 | 过期/变更/撤权直接拒绝，不推进写状态 |
| 后续资源权属核验（待实现） | 同一租户、提供方、企业、任务、设备注册、资源、文档摘要和证据版本 | 只接受独立可信的独占机制证明 | 无证据或到期保持关闭；读取 404 不放行 |
| 最后检查与写前落库（待接合） | 当前租约、授权版本、证据截止及执行状态 | 提交不确定状态后才能发送网络写入 | 持久化失败不发送；网络结果未知只读核对 |
| 精确内容与版本确认（已有传输/账本能力，待编排） | 同一候选资源的完整内容及提供方版本 | 满足全部条件后进入分配准备 | 内容/版本不匹配转复核，不新建资源重试 |
| 设备应用确认（已有只读恢复能力，待完整验收） | 对应设备、策略资源、精确版本及合规报告 | 确认真正生效 | 无报告继续等待；不以服务器写入成功充当生效 |

准备入口仅限服务端内部调用，参数只有当前任务租约。前端仍使用既有执行记录接口展示原因，不传递提供方资源名、租约令牌或准备对象。此阶段没有新的前端操作；后续完整编排接通后，页面才可展示与真实进度对应的准备中、下发中、等待设备、已生效或需要处理。
