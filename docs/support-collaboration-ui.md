# 支持协作界面与客户端契约

承接 `support-diagnostics-plan.md` 的配对、授权和管理界面步骤，复用 Flutter Material、既有 Session/OIDC、Spring 授权接口及严格诊断投影。当前采用独立候选验证，未替换运行中的服务。

## 管理员流程

设备详情仅向当前 OWNER／GUARDIAN／ORG_ADMIN 提供“限时支持授权”，设备需处于 ACTIVE。操作依次为输入接收人配对码、服务端核对主体和已验证邮箱、选择诊断范围、填写 5–1440 分钟期限、勾选明确确认、提交。默认仅选择设备状态，期限一小时。

界面不把显示姓名或邮箱当作授权凭据，也不声称接收人经过平台官方客服认证。请求绑定具体接收人主体、设备注册周期及设备版本。提交后以服务端返回的授权记录和截止时间为准；重放返回已撤销或已到期记录时展示当前状态。

提交结果不明确时，将本次输入与幂等键保留在当前页面内，按原内容重试。冻结内容以只读文本呈现，不继续暴露编辑框；错误和重试说明固定在操作区。关闭页面会清除这些临时内容，用户需先查看授权历史确认结果，再决定是否重新创建。

## 接收人及授权历史

“支持协作”是账号级入口。具有 IdP 成人资格的接收人可以在没有任何客户工作空间成员关系时使用“我的配对请求”和“收到的授权”。客户管理员另有“本空间授权”。儿童或无资格账号不能依靠导航获得支持访问权限。

- 配对请求必须明确点击生成。原码仅在首次成功响应展示，不写入浏览器存储，也不自动复制到剪贴板。丢失首个响应后，重试可确认请求但无法取回原码，可取消后重新生成。
- 配对已被客户消费时，重放展示当前状态并提供查看收到授权的入口，不再要求取消不可取消的配对。刷新配对列表也会同步当前状态并清除已消费的原码；对身份、版本和创建／到期时间进行一致性检查。已结束的请求可关闭记录后重新生成。
- 授权历史使用服务端分页。状态为“有效期内”仅表示记录期限，页面明确说明实际读取仍检查当前客户权限和设备状态。
- 撤销需要单独确认，携带所见授权版本和幂等键；结果不明确时保留原操作重试。页面说明撤销会阻止后续读取，但无法收回对方已经保存的副本。
- 诊断必须明确点击读取，只展示实际获准的部分；未授权部分为 null，客户端拒绝意外出现的额外诊断部分。版本、能力、配置指纹、时间和证据说明复用同一组允许列表规则，不呈现原始日志、规则正文或儿童自由文本。

## 会话、生命周期及请求边界

界面绑定账号、工作空间、角色、接收资格以及设备注册与版本。绑定改变会清除旧内容并使旧操作失效。标签页进入后台、切换页面和退出登录后，清除配对码、确认信息、诊断及未确认操作；恢复前台后由用户重新读取，不自动重新生成或授权。已开始请求的迟到结果不写回界面。

使用固定 API 路径和有界流式响应，拒绝重定向；普通响应上限 128 KiB、错误上限 64 KiB、诊断上限 512 KiB，请求期限 25 秒。成功响应须为 JSON 且禁止缓存。客户端只保留已知错误代码和规范关联标识，未识别错误正文不会直接展示。共享认证客户端不会被单次操作关闭。

生产 Dart 客户端的隔离 HTTP 旅程涵盖首次配对／无原码重放、接收人核对、幂等授权、授权历史、实际诊断投影、弱认证／儿童资格／外部接收人拒绝、撤销与旧创建重放、已消费配对不可取消。此处 JWT 由隔离服务器注入，不代表管理员真实完成了 OTP。
