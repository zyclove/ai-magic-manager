# 策略预览使用说明

## 查看影响

1. 在策略详情中打开“预览与发布”，选择设备或设备组。
2. 点击“预览这些设备”。请求失败时保留原选择，可直接重试。
3. 先查看设备数与检查数，再展开需要处理的设备。每项检查显示规则类型、拟配置内容、限制原因和必要提示。

检查数按每台设备编译后的检查项统计。同一规则作用于两台设备会分别计数；合并后的规则不会按原草稿条数重复统计。

| 结果 | 含义 |
| --- | --- |
| 受限 | 当前设备或能力条件不支持，或相关条件暂不可用 |
| 待核验 | 信息缺失、未核验、过期或状态尚不能确认 |
| 支持条件满足 | 此项检查条件满足，仍未执行设备系统管控 |

三个结果数量互不重叠。没有检查项的设备不代表全部通过。

## 查看应用核验

展开设备后，应用核验仅属于该设备及当前注册。另一台设备的核验结果不能代用。

“应用身份已核验”只表示身份记录符合当前读取条件。页面同时显示报告时间、核验时间和有效期，并保留“系统控制尚未确认”说明。核验缺失、过期、上下文不符或记录冲突时，页面给出下一步；预览页面本身不授予刷新或执行权限。

## 保存配置

“仅保存配置”沿用现有确认和近期多因素认证要求。提交前会重新核对权限、设备组版本和预览有效期，服务端还会重新计算当前事实。

- 预览已到期：关闭窗口后重新预览。
- 工作空间或权限已变化：原结果自动隐藏，在当前工作空间重新打开。
- 核验或设备信息发生变化：重新查看影响后再保存。

保存配置不会使设备系统策略生效。真实系统执行需要正式设备适配器和执行回执。

## 本阶段交付边界

此改动完善管理端预览与只读应用证据展示。浏览器模拟数据用例不代替真实设备、真实多因素认证、外部提供方或部署验收。具体原生退出码、验证次数与源码摘要记录在本阶段验证证据中。
