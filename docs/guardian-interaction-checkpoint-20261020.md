## 本阶段改进

| 入口 | 具体行为 |
| --- | --- |
| 工作台 | 按当前状态给出下一步操作；隐藏与主操作完全相同的快捷按钮，保留同一页面的其他操作；处理中显示进度并阻止重复操作 |
| 工作台刷新 | 显示正在刷新状态，防止重复读取；有效摘要可保留至新读取完成；操作结束后重新读取，旧请求不能覆盖新结果 |
| 功能导航 | 支持退款、对账、规则、配对等常用词和组合搜索；唯一授权结果可按 Enter 打开；支持清除与继续输入 |
| 资源列表 | 搜索可一键清除并回到输入框；无匹配结果提供清除入口；分页失效保留已加载记录，引导刷新后继续查看 |
| 异常恢复 | 普通分页失败保留原游标供重试；刷新失败保留记录；未认证或失去权限时清除私有列表 |
| 表单及详情 | 账号、工作空间或权限变化后停止旧操作；异步成功只关闭原有窗口，避免关闭后来打开的其他窗口 |
| 审批、额度、所有权、设置 | 在实际读写派发前重新检查原操作范围，覆盖等待认证或网络返回期间的切换情况 |
