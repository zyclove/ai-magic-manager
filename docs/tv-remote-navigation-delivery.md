# Android TV：遥控器导航与长页阅读

更新：2026-10-15。基线 `e146a02`。本阶段补齐已连接电视的操作入口、焦点恢复、长页面阅读和返回路径；设备身份、规则、报告、帮助继续使用已有儿童端页面及服务接口。

## 操作约定

| 所在位置 | 遥控器操作 | 结果 |
|---|---|---|
| 进入已连接电视首页 | 无需先按 Tab 或点击屏幕 | 初始焦点落到菜单 |
| 左侧菜单 | 上下选择，确认切换 | 显示设备、规则、使用或帮助；焦点留在菜单，内容回到顶部 |
| 左侧菜单 | 向右，或确认当前页面 | 进入内容操作区；重新进入时恢复该区域保留的焦点 |
| 内容操作区 | 方向键、确认键 | 使用 Flutter 原有焦点遍历与按钮动作；不执行新的设备管理指令 |
| 内容操作区 | 返回键或“返回菜单” | 回到上次菜单焦点，不改变当前页面 |
| 长页面 | 聚焦“向上翻页／向下翻页”并确认 | 每次移动可视区域的 80%，保留上下文；到边界停止 |
| 带翻页键的遥控器/外接键盘 | Page Up / Page Down | 翻阅当前页面；文本编辑时不接管这些按键 |
| 弹窗 | 返回键 | 先关闭弹窗，保留原触发控件的焦点 |
| 菜单根位置 | 再次使用系统返回 | 沿用系统退出行为，不用界面逻辑冒充不可退出的设备管理能力 |

底部阅读操作条始终可见，文字区再长也可以通过遥控器阅读。状态显示“已到顶部”“可继续阅读”“已到底部”或“全部内容已显示”。翻页控件在边界保留焦点，重复确认不会越界；用户仍可直接返回菜单。

按钮至少 56 逻辑像素高，聚焦时使用明显描边。菜单字体继承应用主题；大字体时底部控件可以换行。关闭系统动画时直接跳到阅读位置，其余情况下使用短距离滚动动画。

## 实现与职责

- 新增 `apps/child/lib/ui/tv_workspace.dart`，复用 Flutter `NavigationRail`、`FocusScope`、`OrderedTraversalPolicy`、`PopScope`、`ScrollController` 和 Material 按钮；没有新增依赖或自研遥控协议。
- 菜单和内容拥有各自的焦点作用域。页面切换复位滚动位置；离开组件后释放焦点、滚动控制器与监听。迟到的布局回调检查组件生命周期。
- `child_app.dart` 仅在已连接且原生宿主确认 `tvMode` 时装配该组件，并将滚动控制器传入既有内容容器。手机/平板保留底部导航；未注册和等待确认等页面保留原流程。
- 仅在内容区域、非文本编辑状态处理返回和翻页快捷键；弹窗保留其自己的焦点与返回处理。音量、媒体等按键不由该组件处理。
- 未修改后端、设备凭据、应用权限、规则执行或退管接口。菜单切换和翻阅不增加管理权限，不能成为跨应用拦截、重启常驻或防卸载的证据。

## 验证方法

隔离副本 `.local/child-tv-remote-20261015` 从 `e146a02` 与本阶段精确文件构成，不包含并行的家庭辅助执行、扫码及商业功能开发。共享 `child_app.dart` 的其他未提交改动保留在工作区，提交时只纳入本阶段布局接线。

先在原实现复现：连接电视后仅发送“向下＋确认”，无法进入“我的规则”，专项失败。新增导航后，同一路径通过，验证不是仅靠鼠标点击或检查组件类型。

`tv_remote_test.dart` 包含 8 项专项：

1. 实际 `ChildApp` 的初始菜单、纯遥控规则/帮助切换，以及菜单与内容往返。
2. 无交互控件的长页，遥控聚焦翻页、返回后恢复原焦点、顶部/底部边界。
3. 系统返回先回菜单，随后允许系统退出。
4. 弹窗优先消费返回，关闭后恢复原控件焦点。
5. 文本输入不被翻页或返回快捷键抢占。
6. 返回后切换菜单，复位滚动且不触发页面业务动作。
7. 960×540、正常字号的控件可达性。
8. 960×540、两倍字号的控件可达性与无溢出。

当前 Flutter 测试工具没有 Go Back 的 Android 物理扫描码推导，因此该条逻辑按键采用显式测试扫描码注入；另通过 `handlePopRoute` 独立检查系统返回链路。不能由此推断某台电视的遥控器物理按键映射已通过。

中文 1280×720 渲染图保存于 `.local/child-tv-remote.png`，使用本机字体进行检查，不作为产品内资源。外部设计服务此前不可用，本阶段沿用既有 Flutter Material 设计与真实组件渲染。

最终证据：儿童端完整 `test` 目录 **186 项全部通过**，含上述 8 项遥控器专项；专项另以中文字体独立执行通过。修改的页面、接线与测试静态分析无问题。隔离副本的 Android `:app:compileDebugKotlin` 成功，包含 Flutter 编译与原生插件接线。日志分别为 `tv-regression.log`、`tv-remote-green.log`、`tv-analysis.log` 和 `tv-native-build.log`。原始失败保留在 `tv-remote-red.log`。组件测试的身份、存储和网络使用显式夹具，不冒充真实设备或新后端联调；本阶段没有修改后端。
