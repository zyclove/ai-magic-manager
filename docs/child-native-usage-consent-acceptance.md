# Android 真实使用摘要授权与撤回验收

## 本阶段打通的流程

上一阶段仅证明设备没有系统许可和监护人同意时，使用报表返回 `NOT_AUTHORIZED`。本阶段复用正式 `ProductionChildRuntime`、Android Pigeon 系统来源、观察代理、Spring 授权服务与报表服务，在同一已注册设备上完成了真实的“同意 → 系统许可 → 聚合采集 → 上传 → 查看 → 撤回 → 清理”闭环。

监护人通过正式管理接口携带近期 MFA 测试身份、强 `If-Match` 和幂等键，将使用摘要授权从版本 0 改为 1。专用 Android API 34 调试模拟器只为本应用临时授予 `GET_USAGE_STATS`，并打开系统设置形成真实前台活动；客户端通过正式 `UsageStatsManager` 读取系统聚合，观察代理在读取当前云端授权后上传。儿童设备报表与监护人报表均返回 `OBSERVED`。监护人随后通过正式接口撤回为版本 2；服务端删除摘要批次与回执头。即使设备系统许可在撤回验证阶段仍临时允许，客户端也不再采集旧摘要，报表返回 `NOT_AUTHORIZED`。

系统特殊访问的临时授予仅属于测试宿主；普通用户产品仍需在设备系统设置中明确操作。成人 OIDC/MFA 是 Spring 测试夹具，设备注册、签名配置、系统来源、网络请求、数据库和报表处理均为正式实现。

## 产品与技术边界

- 使用时长是 Android 系统聚合、设备代理上报且尚未独立校准的证据。应用列表只覆盖当前用户可见应用；查询区间可能与系统日聚合边界不同。不能据此进行精确计费或声明强制额度已执行。
- 该旅程通过测试宿主授予特殊访问，验证了真实系统许可状态和采集；并未替代家庭实际用户在系统设置中的授权操作验收。云端监护人同意和系统特殊访问必须同时满足；撤回云端同意后即使系统许可仍在，也停止新增采集并删除服务端摘要。
- 本次只覆盖一台专用 API 34 调试模拟器，没有实体手机、Android TV 厂商矩阵、长期重启常驻、DPC/EMM 系统级执行或跨应用防强停证明。
- MySQL 临时库兼容性已实测，不能外推为 OceanBase 认证。真实身份提供方、区域隐私规则、容量和生产升级仍是发布门槛。
