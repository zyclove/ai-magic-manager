# 家庭 P0：国内通知与手机号共同监护

继续执行已批准的中国大陆家庭首发计划。本轮优先完成家长通知客户端、真实异常与会员到期提醒、手机号共同监护邀请，复用家庭四入口与既有设计，不改订阅价格或开启收费。

## 用户可完成的流程

1. 在“我的→消息提醒”主动开启设备通知，逐项选择申请、设备异常、会员/作息到期；没有系统权限、服务未开放或离线时给可恢复说明。
2. 点击提醒进入当前家庭消息收件箱，重新核对权限与事实。锁屏仅显示通用文案，不显示孩子姓名、手机号码或申请理由。
3. 在“家庭成员”输入家人的大陆手机号，完成近期验证后复制邀请链接；对方登录该手机号、确认成人监护声明后加入。链接不携带手机号或孩子数据，发送/分享由家长操作。
4. 申请、撤销、移除及接受遇到未知结果时保留原操作，不自动另建；账号、家庭、前后台改变使旧确认失效。

## 技术与边界

- 沿用阿里云移动推送，真实 SDK 能力由构建开关和移动应用凭据控制，服务商及 worker 默认关闭。前台明确授权前不初始化采集或请求系统通知权限。
- 服务端使用数据消息，包含opaque event/delivery/installation ID；原生按当前安装授权检查后本地展示，切家庭/账号、撤权或退出先停止本机展示再注销旧安装。厂商离线通知绕过本机校验的问题保留为发布验收缺口，不通过自动展示通知掩盖。
- 真实健康/心跳和不可变商业来源产生提醒；持久去重与有界多实例扫描，恢复状态抑制未发送旧提醒。推送受理不等于终端送达。
- 手机号邀请复用Keycloak可信验证声明与成人监护声明。客户端加密保存随机邀请ID、原secret和请求；服务端仅保存secret/目标手机号摘要与脱敏目标。OWNER可邀请/移除共同监护，GUARDIAN只读，接受必须匹配已验证目标手机号。
- 主体删除目录同步新增存储分类，成员撤销复用现有清理事件。沿用未发布1.0初始化基线，隔离数据库验证，不迁移或清空本机数据。
