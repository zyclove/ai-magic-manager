# 短信与微信管理配置及联调入口

用户要求：继续补齐短信、微信的管理端界面化配置与联调入口，保留已有改动，界面简洁易用。沿用已确定的供应商管理契约，不改变家庭端账号流程、机构 MFA、设备规则或购买门禁。

## 本轮可观察结果

1. 独立平台入口“短信与微信”，无家庭工作空间的平台管理员也可使用；普通家庭角色没有配置权限。
2. 独立 `identity-config:read/manage/test` 权限，服务端按既有平台近期 MFA 验证。客户端重新登录不能替代 MFA 事实。
3. 短信与微信以两张卡显示状态和下一步。配置表单只写入新密钥，空输入保留现有值；STS 清空必须明确选择。保存、退出、重新认证及会话变化后清除临时密钥。
4. 不可变配置版本、基础版本冲突检查、固定客户端操作 ID。断网或未知结果仅查询原操作，不能自动重发秘密或发送短信。
5. 非秘密项与秘密分开读取。秘密使用供应商管理专用外置密钥环加密，不复用报表／导出密钥，不进入通用幂等日志、审计、响应或前端存储。
6. 格式检查与真实验收分别展示。配置保存不代表身份服务生效；准备发布仅产出受限目录内加密包。部署侧工具解密为新的固定版本目录及受控部署说明，不覆盖已有部署，不自动重启，不打开消费者或销售开关。
7. 联调入口绑定配置版本、环境别名及 APK/JAR 摘要，展示固定十二项真实检查与正常 App 操作入口说明。不提供粘贴微信 code 或人工勾选 PASS，不以 `SendSms OK` 宣称收码。
