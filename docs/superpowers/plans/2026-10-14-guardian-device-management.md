# 设备详情原地核对与操作恢复（1.0.0）

## 目标与已确认范围

承接用户对流程简单、界面清楚、全部功能稳定可用的要求，在既有设备流程内完成详情、能力、应用清单与安全操作的衔接。沿用 Flutter Material 3、现有认证与后端接口，不增加历史迁移。普通配对、云端撤销、本地退出和系统规则执行继续分别表达。

当前设备详情仍是通用字段弹窗。它没有使用会话单调世代；能力与应用清单返回后会连带关闭父详情；读取拒绝仅追加错误仍显示旧资料；云端撤销未知结果没有原地只读核对。这些问题已由源码复审确认。后端对同一设备的已撤销状态直接返回，不能将重复请求描述为必然重复产生副作用。

## 设计

- 一个设备窗口，概况、能力、应用清单在原地切换。显示最近实际读取时间、注册状态、连接观察与建议下一步；设备编号等信息收在次要区域。
- 隐私、诊断、导出、支持授权和设备退出复用已有专用流程，子窗口返回后保留设备窗口并重新读取事实。退出与记录合并一个入口，紧急云端撤销放在单独的安全操作区域。
- 固定账号、工作空间、角色与会话世代。所有请求和返回都检查原范围；账号或范围变化后隐藏旧资料，旧范围回到同名值也不能恢复旧窗口。
- 给 Api 增加可组合的范围绑定。绑定同时覆盖 send/page/all 和借出的 raw HTTP client；后者用流式请求包装连接现有 OAuth 底部守卫，不提前缓冲任意请求体，不关闭共享登录客户端。待刷新令牌的旧范围业务请求不得进入实际传输。
- 读取 401/403 清除全部旧资料和动作；网络故障保留上次成功读取的数据并明确提示尚未更新。响应字段、设备/注册身份和分页/集合上限均验证。
- 撤销需要明确确认。POST 成功后重新读取设备；网络或服务端结果未知时提供“核对结果”，不自动重放 POST。读取仍为 ACTIVE 不证明原写入失败；只有读到 REVOKED 才结束未知结果核对。确认过程中切换身份、关闭或已有写入时不发请求。
- 设备详情及其诊断、导出、支持、隐私和退出子流程都使用同一强度的世代与实际 HTTP 发送保护。组件的隐藏不能替代请求保护。

## 文件与执行分工

1. Api / HTTP 范围绑定与测试由独立代理负责，先提交测试和可编译 RED 壳；根代理串行执行 SDK 门禁。
2. 新 `core/device_management.dart` 提供不可变模型、现有接口适配及串行控制器；新专用窗口使用纯 Flutter 接口，独立于浏览器 Session。
3. `console_pages.dart` 只替换设备详情入口；既有专用子流程增加世代绑定，原配额、家长/儿童配对、审计和部署工作不混入候选。
4. 真实 Spring ↔ Dart HTTP 验证覆盖设备、能力、清单、权限拒绝与撤销后只读核对。测试身份和 H2 夹具不证明真实 MFA 或硬件执行。
5. 专项 RED→GREEN、完整管理台、静态分析、正式构建、独立复审、明确标注模拟数据的桌面/手机视觉检查。冻结候选后不修改输入；发布前保留当前 1778d46 对应运行环境和账本。
6. 精确提交、推送与运行文件回查；不把未通过门禁的共享改动当作发布来源。

## 验收

覆盖关闭/晚响应、A→B→A、OAuth 刷新等待中切范围、raw SDK 请求、读 403、瞬时失败保留、原地切换、子窗口返回、双击、确认取消、撤销提交后断连、ACTIVE 未知不解锁写入、REVOKED 核对完成、390 宽与放大字体。测试至少验证实际调用次数和 HTTP 请求，不仅检查提示文案。

## 整体目标仍待推进

本包不缩减完整产品目标。当前擦除审计确认生产幂等 execute 共 47 处，其中 34 处仍默认 UNCLASSIFIED、13 处显式归属，另有 9 处恢复读取。后续应整体补齐归属、200 主体容量与实际处理器清理后拒重放，再完成公开编排、其他处理域、外部副本及真实备份恢复。不得因本设备窗口完成而开放尚未完成的删除功能或宣称整体已完成。
