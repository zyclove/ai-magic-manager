# 手机策略草稿编辑：阶段交付

日期：2026-10-13。适用于 `apps/parent` Android 监护人客户端。首发区域继续为中国大陆，机构合同优先；本次扩展机构管理员/监护人的日常配置入口，不改变商业权益或设备管理资质。

后续进展：手机新建草稿/模板及模板复制已在[创建恢复阶段](parent-policy-creation-delivery.md)接入；下文保留本编辑阶段原始范围与验证记录。

## 产品流程

策略中心 → 草稿详情 → 编辑草稿规则 → 添加/修改规则 → 保存草稿 → 重新读取最新修订 → 选设备预览 → 单独确认配置发布。

- 采用项目现有 Flutter Material 表单、独立规则页面和返回导航。表单显示原修订、规则数和保存影响，名称最多 100 字、规则最多 100 条。
- OWNER、GUARDIAN、ORG_ADMIN 可编辑；审计员没有写入口。后端逐请求确认当前成员权限、租户和目标，不依赖前端按钮判断。
- 草稿和模板均能编辑；新建策略、模板复制、应用登记和日程维护目前仍在完整管理台完成。
- 添加/修改规则只暂存在当前页面，点击“保存草稿”才提交。规则移除和放弃修改均需确认，未写入的修改不跨进程保存。
- 每次退出编辑都重读草稿并清除详情原来的预览、设备选择和发布展示，包括用户取消编辑或保存结果不明的情况。返回中心刷新列表名称及修订。

## 规则能力

| 规则 | 字段/选项 | 边界 |
|---|---|---|
| 启动、安装 | 当前租户应用；允许/拒绝 | 应用目录记录不是已安装验证；仍需设备预览 |
| 卸载 | 当前租户应用；允许/禁止卸载 | 不承诺普通 BYOD 可防卸载 |
| 运行时权限 | 当前应用、服务端 schemaVersion=2 目录；系统默认/拒绝 | 不提供自动授予；目录缺失/格式异常停止编辑 |
| 特殊访问 | 使用情况、悬浮窗、通知读取、无障碍、VPN；默认/拒绝 | 不提供自动授权；实际能力由预览说明 |
| 每日额度 | 可选应用、1–86400 秒 | 配置项不等于跨设备共享额度已执行 |
| 使用时段 | 可选应用、当前租户时间计划 | 时区、跨午夜和例外日期沿用计划，手机不修改计划定义 |
| 网站访问 | 完整小写 ASCII/Punycode 域名；允许/拒绝 | 不接受协议、路径、通配符或 IP；不代表读取 HTTPS 内容 |
| 连续使用提醒 | 可选应用、1–86400 秒 | 提示规则，不产生摄像头或行为数据采集 |

可选应用为空表示所有适用应用。每条规则可设置“必须支持/可选执行”。未修改的规则保留原字段；不支持编辑的历史动作提示在完整管理台处理，不静默转换。应用/计划目录最多按既有 API 客户端边界读取 10000 项，超过边界报错；大机构远程搜索选择器为后续改进项。

## 并发、恢复和权限

1. `PUT /api/v1/tenants/{tenant}/policies/{id}` 带读取草稿时的 `If-Match`，正文只有 `name` 和 `rules`。服务端修订冲突拒绝覆盖，客户端不会读取新版本后自动重提旧正文。
2. 成功响应须匹配原策略 ID、原修订 + 1 及规则列表。未知传输、5xx 或非法响应不能显示成功；停止编辑并提示返回核对最新草稿，不自动重发。
3. 412 后同样锁定原表单，需要返回读取当前草稿再重新编辑。确定的业务校验错误允许调整表单，保留关联问题编号。
4. 取得令牌可能涉及异步刷新。新编辑请求通过 `ParentApi.send(isCurrent: ...)` 在令牌返回后、发送前再次检查账号、租户、角色及当前认证状态，避免跨工作空间提交。此守卫为可选参数，本次只覆盖新编辑写流程，不能推定其他调用全部覆盖。
5. 账号、工作空间或角色变化会关闭编辑器及嵌套规则页面，忽略旧异步结果。普通返回在保存期间禁用；服务端仍负责实际访问控制。
6. 保存只变更草稿，不向设备执行限制，不替代单独预览、近期认证和 `CONFIGURE_ONLY` 发布流程。草稿写入无需额外 MFA，与现有后端契约一致。
