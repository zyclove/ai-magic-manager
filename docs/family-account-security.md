# 家庭账号与安全

2026-10-17 后续新增供应商管理页面、加密配置与联调待办入口，见 [短信与微信管理配置](family-identity-provider-admin.md)。下方初轮记录保留当时验证状态；真实供应商及收费门禁仍未通过。

本轮沿用统一 Keycloak 账号，补齐手机号换绑、账号恢复、微信绑定与解绑。始终修改原用户身份，家庭、设备、订单和会员继续关联原来的用户 ID。

## 家长操作

- 「我的 → 账号与安全」查看脱敏手机号、微信绑定状态；每次变更先说明影响，再打开安全验证页面。
- 更换手机号：输入并验证当前手机号，再验证新手机号。新手机号已被其他账号使用时拒绝，不自动合并。
- 原手机号停用：从登录页「找回账号」使用已绑定微信验证，再验证新手机号。没有原手机或已绑定微信时，页面说明需要求助，不承诺自动找回。
- 绑定微信：微信授权并验证当前手机号。微信已属于其他账号，或当前账号已经绑定不同微信时拒绝。
- 解绑微信：验证当前手机号后解绑，保留手机号登录。完成账号变更后，其他设备上的旧登录会失效。

手机号验证只证明手机号持有权，家庭开户的成人及监护声明继续由原开户流程记录。

## 中断与恢复

App 在打开验证流程之前，保存加密的操作引用，只含操作类型、随机操作 ID、预期账号与身份版本、创建时间。验证码、手机号、微信授权码与访问令牌不写入该记录。

关闭浏览器不等于操作未生效。App 先向身份服务读取当前状态，只有匹配原操作 ID、类型与账号的回执才显示完成。重新打开页面不会自动重放换号或解绑。

确认尚未打开安全验证页面的本机失败可以安全结束。已开始的未知操作，只有重新核对身份已更新，或在流程结束/恢复后保守等待 30 分钟、再成功读取当前状态，才提供明确结束本机引用的入口。结束引用本身不表示原操作成功。

身份服务的操作截止时间固定为首次开始后 30 分钟，手机号和微信持有权证明另有短时效。到期后重新发起验证，不延长旧操作。

## 服务边界

- 身份服务处理全部手机号验证码与微信授权码交换。OIDC/PKCE 仍由 AppAuth 处理，App 不获得身份管理权限。
- `GET {issuer}/consumer-account/status` 只返回当前有效消费会话的脱敏状态、能力与最近操作回执，禁止缓存。
- `consumer_identity_revision` 是身份服务受保护属性与签名声明。账号变更递增版本，撤销旧在线和离线会话；刷新旧身份声明时拒绝签发。
- 已启用的业务会话校验在 JWT 验签之后、进入业务控制器之前调用可信身份接口，不缓存放行结果。旧会话返回 `ACCOUNT_SESSION_STALE`，身份服务不可用返回 `ACCOUNT_SECURITY_UNAVAILABLE`。
- 机构 MFA 与儿童设备身份链路继续使用原安全策略。儿童端已有离线规则和必要恢复功能不依赖此接口。
- 微信身份按移动应用 AppID 隔离，不按昵称或未经验证的 UnionID 合并。
- 首发使用 realm 数据库行锁串行化短身份写事务，原注册、首次微信绑定和账号变更共用这一边界；供应商请求和错误验证码不占锁。手机号、微信身份和用户属性采用锁定当前读取，避免数据库隔离级别和旧缓存影响版本判断。此方案优先保障首发一致性，规模扩大后再评估锁竞争。

## 配置与发布

默认不开启真实账号修改。部署环境使用同一 `FAMILY_ACCOUNT_SECURITY_ENABLED=false` 同时控制身份服务账号修改与业务 API 当前会话校验。家长安装包使用对应 `--dart-define=FAMILY_ACCOUNT_SECURITY_ENABLED=true` 才开放操作；服务端仍独立决定是否允许。

正式开启前，需要完成：

1. 在隔离身份域安装本轮 provider，核对受保护的手机号、身份版本与最近操作属性，验证原用户和 AppID 均保留。
2. 配置真实短信与微信移动应用凭据，验证换号、旧手机号丢失、微信冲突、解绑、取消、重复提交和跨设备旧会话失效。
3. 核验业务端可信身份状态地址、国内网络和故障恢复；身份服务故障时不能绕过当前会话校验。
4. 在真机检查安全浏览器返回、微信安装/未安装、短信接收与大字布局。

已有身份域不能用初始化脚本覆盖。先导出和备份，再在隔离副本用 `merge-consumer-realm.ps1` 合并配置，核验后按受控发布流程升级。此轮不修改已有本机身份域、数据库、销售开关或供应商账号。

开发与验证记录：`docs/superpowers/plans/2026-10-16-family-account-security.md`，本轮私有证据目录 `.local/family-p0-account-security-20261016/`。
