# 本机管理工作台

入口：<http://localhost:18101/>。管理员账号为 `admin@super.com`，使用已配置的密码。

在本项目目录执行以下命令即可检查服务、恢复已配置环境并打开浏览器：

```powershell
pwsh -File scripts/start-console.ps1
```

仅检查，不启动服务或打开浏览器：

```powershell
pwsh -File scripts/start-console.ps1 -CheckOnly
```

此入口依赖本机 Docker Desktop 和忽略提交的 `.local/console-launcher.json`。它优先选择已经运行的受支持项目；全部停止时，使用最近成功切换记录或默认的已验证环境。它使用该发布源码自己的启动、校验脚本和原数据卷，不执行数据库或独立账本初始化。新项目须有成功切换记录才能被选中；如果旧环境不健康且新项目已创建容器、但尚未确认切换完成，入口会停止并提示等待更新，避免争用端口。其他聊天完成同一 18101 入口的新版本切换后，入口可继续识别新项目。

2026-10-23 已恢复 Docker 和六项现有服务。启动入口只读检查通过：首页、登录回调、OIDC 发现、匿名 API 和后端数据库健康均符合预期。启动记录按 `schemaVersion=1`、`state=COMMITTED`、项目及 `publicUrl` 核对；对应 8 项元数据回归通过。本轮没有重新执行管理员登录、已认证业务流程或真机验收。

当前入口运行已经登记的发布版本；工作区后续代码需要完成验证、构建和发布，才会进入运行环境。本入口只选择已确认发布，不触发未完成候选的部署。

设备注册和策略发布等敏感操作需要管理员先在“设置 → 账户与验证器”绑定本人的验证器并完成安全验证。Android 客户端不在本次启动范围内。
