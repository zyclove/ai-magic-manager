# 设备执行记录

## 操作路径

- 机构所有者、机构管理员：设备 → 设备详情 → 执行记录。
- 审计员：Android 管理 → 查看儿童端关联 → 执行记录，只读查看。
- 从儿童端关联进入时，所有角色均为只读；需要管理时从当前设备详情进入。

列表支持状态筛选、刷新和按需加载。选择“查看进展”可阅读当前状态、创建/更新时间及版本时间线；内部编号默认折叠。

“设备已应用”表示服务端已收到设备反馈。等待、提交或结果待核对均不能当作设备应用成功。历史注册记录只读显示。

## 取消与核对

允许取消时，详情显示“取消后续执行”或“登记取消并复核”。确认窗口说明该操作对现有策略和设备状态的限制。

- 取消确认绑定当时选择的记录版本，重复点击不会并发提交。
- 服务端记录已变化时，先读取最新进展，原确认失效；再次操作需要重新确认。
- 需要安全验证时，由用户选择“重新安全验证”；认证完成后不自动提交取消。
- 请求结果不确定时，同一窗口内只能“核对结果”。返回列表、切换筛选或刷新不会重新开放取消入口。
- 时间线已显示更高版本时，先刷新详情再决定后续操作；读取失败不会抹去已观察到的更高版本。

## 权限与生命周期

窗口绑定账号、租户、角色、会话代次、设备、注册及父页面生命周期。上下文失效后隐藏私有内容，迟到响应和旧回调不能恢复内容或发起操作。关闭期间同样清除私有内容。

沿用现有 `DeviceSubflowScope`、认证、HTTP 客户端和 Material 3，不增加依赖，不扩大设备页及设备档案的审计员读取权限。
