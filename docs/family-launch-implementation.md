## 仍需补齐的 P0 软件工作

按影响收费交付的先后排列，**以下不是已经完成的能力**：

1. **国内通知送达验收。** 原生在线消息、系统许可、偏好、失联/权限异常/会员边界事件及手机号协作已实现；阿里云首次同意后初始化、杀进程与厂商离线通道仍须真机联调。当前关闭离线转通知，避免绕过当前安装授权核验，不承诺厂商离线送达。
2. **账号售后。** 已验证手机号邀请、监护声明、接收/撤销与成员移除已实现；换号恢复、敏感绑定/解绑及相应售后界面仍需补齐。手机号登录不能代替这些恢复能力。
3. **商业运营验收与配置。** 自动关单、日账单校验、差异调度、售后人员操作界面已补齐，设备容量沿用服务端目录配置。仍需正式商户的跨日账单、真实付款与退款到账、生产 MySQL 并发、异常告警和人工值守验收；不能按构建成功开放收费。
4. **AI上线工程。** 固定模型版本、真实中文质量评测、数字依据核验、云授权撤回设置、过期建议清理与成本监测仍待完成；当前云请求持有较长业务事务，正式负载前需改为持久预约与事务外调用。

## 必须补充的外部验收

- 至少8台、3品牌实体设备及72小时连续运行；分屏、画中画、应用分身、撤权、强停、重启、省电、升级、离线与安全退出验证。目前没有连接真实设备。
- 已审核的短信签名/模板、微信移动应用AppID/正式包签名/商户绑定，真实手机注册、微信登录、交易、通知丢失补查和原路退款到账。
- 中国内地部署、正式签名、备案与目标渠道准入、恢复演练及受支持型号证据；发布材料不能由开发包构建代替。
- 普通家庭10户可用性测试、约30户14天试点、首次连接成功率；真实模型案例评测达到计划要求后再开放对应能力。

销售开关保持关闭。完成这些软件工作与外部验收后，才能把当前基线升级为可收费交付版本。
