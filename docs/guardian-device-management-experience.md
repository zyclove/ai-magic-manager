# 设备管理与操作核对（1.0.0）

## 日常使用

登录管理台并选择工作空间，在“设备”中打开一台设备。一个窗口内可切换“概况”“能力与限制”和“应用清单”；不同角色只会看到获准使用的入口。

- 概况展示注册、管理模式、连接观察和最近实际读取时间。设备编号等资料放在可展开区域。
- 能力页面同时说明设备上报、授权和可信程度。普通代理的上报不代表系统级控制已验证或执行已生效。
- 应用清单可以在本地按名称或包名筛选。清单只包含设备允许上报的可见应用，空清单不能证明没有安装应用。
- 隐私、诊断、导出、限时支持和“退出管理与记录”继续使用各自的专用流程。返回后仍保留设备窗口，并重新读取设备事实。

## 刷新和异常恢复

网络暂时不可用时保留最近成功读取的资料，提示哪些内容尚未更新，并提供重试。读取权限被拒绝、账号或工作空间变化时，旧资料和旧操作入口会隐藏；重新打开当前范围的设备即可继续。

“紧急撤销云端访问”放在独立安全区域，提交前说明后果并明确确认。请求成功后读取最新状态；如果回复丢失或结果暂时未知，只提供“核对结果”，不会自动重复提交。再次读到仍为已注册，不代表原提交必然失败。

云端访问撤销不会向设备发送本地清理命令，也不能证明其他应用已被阻止或本地资料已删除。正常退出与代理资料清理需在“退出管理与记录”中另行核对。

## 界面与权限边界

沿用 Flutter Material 3 与现有认证、后端接口。设备窗口、确认框及专用子窗口绑定打开时的账号、工作空间、角色和会话世代。离开后再回到同名范围，也不会恢复旧窗口的操作权限；关闭后晚到的响应不能重新显示资料。

窄屏可滚动查看导航与内容，长名称保留完整无障碍语义。放大字体和搜索键盘占高有专门的布局检查。截图预览使用明确标注的本地模拟资料，不会在实际业务库中创建示例儿童或设备。

## 交付证据

构建、组件、浏览器、前后端联调和运行更新结果以本阶段最终验证记录为准。测试 JWT、模拟多因素声明及 H2 注册夹具不证明真实身份提供方、OTP 或 Android 硬件执行；本包不开放尚未完成编排的全量数据擦除功能。
