# 家庭订阅 P0 阶段交付（2026-10-21）

本阶段保留此前 Parent、Child、后台及身份扩展的家庭功能，将运行所需依赖一起纳入源码记录。目标仍是大陆家庭手动订阅；消费者真实联调与正式收费尚未开放。

## 本轮修复

- **儿童端状态可信。** 本机原生检查超过 5 秒未返回时显示状态未知；过期请求、旧异常和页面释放后的回调不再覆盖新状态或继续上报。此调整只影响观察和显示，不停止本地规则。
- **关门后停止发新付款参数。** 旧 READY 尝试的幂等重放也检查门禁，查询旧尝试在门禁关闭时隐藏参数；微信准备请求返回后再次核对。既有订单、查单、退款、关单及日账单对账仍保留。原生微信启动和客户端返回都不能直接开通会员。
- **家长端恢复可运行。** 修正已安装 Flutter 版本不接受的按钮参数及多余空断言；授权确认用例先将目标滚动到可点击区域，仍检查只写入一次和清除原恢复记录。新增关闭销售后的重建恢复回归，沿用原订单与原支付操作编号，不打开微信。
- **家庭签名构建入口。** 构建脚本增加显式家庭验收模式，编入手机号、微信和账号安全功能，核对正式证书及构建前后的源码提交。清单始终标记待验收、不可销售；完整操作见[安卓预检说明](family-android-acceptance-preflight.md)。

## 管理员实际操作

1. 打开「平台管理 → 短信与微信」，按页面提示配置、受控发布并核对生效版本。
2. 使用「家庭验收模式」生成正式签名包，保存实际 APK、来源清单与只读预检报告。调试包、预检准备成功都不能计为真机通过。
3. 在独立受限成人试点中，按「准备 → 手机完成 → 核对结果」完成十二项真实账号验收。验证码、完整手机号、微信 code 和密钥只留在受限页面或构建环境，不进入管理台验收记录。
4. 正式短信、微信、安卓型号、支付退款和发布准入均取得可信证据后，另行完成受控开售。本阶段没有手工标记通过或绕过收费门禁的按钮/API。

真实短信、微信和账号流程仍为 **0/12**。正式签名构建、真实安卓设备、目标 MySQL 8.4 联合验收、真实支付退款与分发准入仍待完成；没有操作已有部署或数据库。本机 H2、HTTP 测试夹具、离线 JVM 和浏览器合成账号不能替代上述验收。
