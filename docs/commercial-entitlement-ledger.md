# 商业权益账本（阶段交付）

## 当前可用范围

后端新增 V28 商业来源账本与 `GET /api/v1/tenants/{tenantId}/commercial-entitlements`。当前接口只读，要求当前租户 OWNER、GUARDIAN、ORG_ADMIN 或 AUDITOR；CHILD/TEACHER 和外租户成员无权读取。响应禁用缓存，展示权益版本、有效来源数、基础设备名额、加购设备名额、合计名额与功能键。`technicalCapabilityIndependent=true` 明确提示：已购权益不等于设备系统权限、型号兼容或实际策略执行。

Flutter 管理端已接入商业账户导航、真实接口读取模型、仓储及响应式页面，校验租户绑定、容量算术、已知功能键及工作空间切换，丢弃异常或超大响应。页面明确展示当前付费名额与设备执行能力的区别，不提供尚未开通的购买按钮；购买流程仍待完成。

**尚未接入支付/合同核验和产品发布目录，因此当前没有购买、自动开通或对外售卖入口。** 未有核验事实时返回版本 0、付费容量 0、无付费功能；现有基础安全与正常退出流程不受此接口影响。服务内部 `CommercialLedger.apply` 只接收由后续合规渠道适配器核验后的标准化事实，目前没有公开写入 API，普通用户不能提交“购买成功”请求自行加权。

## 事实与合并规则

- 每个事实绑定租户、来源系统、来源引用、单调来源版本、产品键、有效期、基础/加购类别、名额、功能键、状态、核验主体和核验证据 SHA-256 摘要。数据库只存来源引用的 SHA-256 键，不存支付令牌、原始合同、儿童数据或渠道密钥。
- 同一来源同版本同内容重放不改写账本；同版本异内容或旧版本拒绝。更高版本在同一事务更新当前来源、写不可变事件、递增租户权益版本并审计。
- 有效条件为 `ACTIVE` 且 `activeFrom <= 现在 < expiresAt`。撤销/退款采用来源新版本写 `REVOKED`，只重算该来源，不覆盖其他仍有效来源。
- 多基础档位设备容量取最大值；明确 `ADD_ON` 来源的容量求和，且只有有效、名额大于零的基础档位时计入合计。基础来源的功能键取并集；加购来源的功能键仅在上述基础档位有效时并入。过期来源不借用其他来源的期限。
- 该阶段**不以付费状态禁止基础家长控制、紧急恢复、设备安全退出或查看自己的安全记录**。新增高阶资源的商业准入应在后续业务入口显式校验权益与技术能力两道条件，并提供欠费/降级影响预览。

## 下一步接入门槛

1. 发布有版本、地区、渠道、币种、价格、设备模式认证和下架状态的正式产品目录；未完成法律/商店规则核验的地区不得显示购买按钮。
2. 选定适用支付渠道并使用其官方服务端 SDK 验签、查询原始交易、订阅状态和退款事件；合同/私有许可证使用独立双人审批与有效期核验。禁止仅凭客户端回调或截图发权益。
3. 建立渠道事件去重、签名密钥轮换、补漏对账、乱序事件重查、退款与取消、欠费宽限和订单争议操作；财务证据与租户权益事件可追溯但分权读取。
4. 把设备占位、换机释放/预留、机构容量和高阶功能入口与权益版本绑定；不得因降级抹掉已存在的安全恢复通道。
5. 接入 Flutter 的商业账户、可售状态、购买恢复、取消影响预览及机构合同页面，完成真实渠道沙箱、MySQL/OceanBase 和跨区域验收。

## 验证

`CommercialLedgerJourneyTest` 使用实际 Spring HTTP 权限链、事务与 Flyway 迁移，检查默认零付费权益、外部/教师成员拒绝、基础/加购合并、来源版本冲突、精确重放、撤销、过期、审计、并发来源写入及审计失败时整体回滚。2026-10-10 在 H2 MySQL 模式及独立 MySQL 8.4.11 临时库各通过最终版本的 6 项，均执行 V1–V28 迁移；临时库和账号在验证后删除。Flutter 模型/仓储、角色导航及桌面/手机组件专项 11 项、管理端全量 215 项通过，静态分析无问题。它证明本地账本与读界面行为，不证明支付核验、OceanBase 或真实销售可用。
