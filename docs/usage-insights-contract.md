# 使用趋势建议：首个可解释交付切片

## 目标与边界

管理端在已授权的使用报表中，为单个应用的趋势生成一条可解释建议。计算发生在当前浏览器会话，使用已经返回并校验的报表，不新增上传、画像库、模型服务或设备权限。儿童账号即使有权查看自身报表，也不能据此修改策略；建议仅供有权限的成人决定下一步。

这不是跨应用总屏幕时长、健康诊断、成瘾判断、身份识别或自动处罚。不同应用及设备可同时运行，不能将各项时长简单相加。原始设备汇总未经独立验证，不作为严格额度结算或系统执行证据。

## 判定契约

输入为当前授权报表中**单个设备、单个应用资料组合**的日/周区间、时区及服务端给出的使用下界和上界。沿用 `usageTrendComparison`：只选最后两个完整、连续、等长的日/周；未完整时段不参与比较。按上下界相减，只有差值下界大于零才提示增加，只有差值上界小于零才提示减少；两界均为零显示持平。任何范围重叠、无证据、时段不连续或不足两期都提示先核对数据，不猜测趋势。

| 判定 | 展示 | 成人下一步 |
|---|---|---|
| 可证明增加 | 建议回看使用安排，并展示差值范围 | 与儿童讨论原因，可自愿调整提醒或作息 |
| 可证明减少 | 近期使用有所减少，并展示差值范围 | 继续观察，不推断健康状态 |
| 持平 | 继续观察 | 避免用单次比较说明长期习惯 |
| 不确定 | 先核对数据覆盖及原始报表 | 核查连接、授权和缺失时段 |

页面同时显示比较的时段、差值范围和数据限制；不产生后台任务、消息推送或策略变更。筛选应用类别只影响当次可见结果，刷新报表、退出页面、切换工作空间或权限变化后按现有报表生命周期清除旧内容。

## 后续智能辅助门槛

本阶段是确定性、可解释的建议入口。独立建议草稿、成人确认发布、长期趋势、深夜使用和摄像头本地识别仍未实现。后续如引入模型，需分别完成监护授权、儿童告知、用途与保留期限、地区审核、模型许可证、误报复核、撤回清理和功耗/质量验证；摄像头默认关闭，不能以模型结果单独处罚儿童。

## 当前验证边界

代码由 `usage_reporting` 的纯判定函数和 `usage_report_ui` 的趋势卡片组成，无新依赖或数据库迁移。静态分析与构建结果应记录在阶段提交中；浏览器交互、真实设备观察与长期准确性仍需按发布验收计划验证。
