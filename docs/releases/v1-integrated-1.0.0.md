### 本阶段发现和处理

首次整合构建中儿童端 123 项有 12 项失败。原因是旧测试假定启动和回前台不会自动同步，或在启动后台任务占用会话时立即触发另一操作；这与既有 `child-host-contract` 的自动同步约定不一致。

测试现在等待后台任务空闲后触发独立操作，并检查启动、回前台及五分钟自动同步，保留身份拒绝、关闭失败、后台隐藏内容和销毁保护断言。实际签名接收器仍检查 401/403 被持久记录、缓存不公开且不被删除、旧请求不能封锁新凭据。新增定时器在后台和销毁后停止的检查。最终完整构建重新执行并通过，没有跳过失败项。

一次独立最终复核已通过：Critical / Important / Minor 均为 0。复核核对了源码归属、发布摘要、备份权限、测试保护和五张截图。
