# 设备执行结果恢复：实施记录

基线：`c2bdf441c9b0f0ccc084bc9cd82a477c9bfd4036`。范围：后端设备回执恢复；Android 验证按用户要求延后。

## 实施契约

1. 复用执行日志的数据库时间、租约、版本检查和退避，只领取 `ASSIGNMENT_UNKNOWN` / `WAITING_DEVICE`。SQL 筛选和加锁后复查均须限制状态；不得消耗待写入任务的次数或占有其租约。
2. Spring 定时任务默认关闭，每轮最多处理 1–25 条，逐条领取以避免整批租约在排队时过期。只调用连接器 `readDeviceState`，无策略写入、分配或自动重发。
3. 每次查询前验证有效租约及可观察状态；查询后由日志再次检查租约、策略资源、精确版本、管理模式和合规状态。取消、超时或租约被替换后的结果不得写回。
4. 连接器不可用时不领取任务；查询失败复用有界退避。日志仅记录本地任务 ID 和失败类别，避免提供方资源和异常正文泄露。单个设备失败不阻断其他设备。
5. 事务仅用于短检查点，远程读取在事务外。被外层事务包裹的调用应拒绝。
6. 无新增数据库结构、依赖、业务权限或公共接口；不修改其他任务持有的 `PolicyService`、V1 和 UI。

## 验证与交付

- 先运行新功能行为失败用例，再实现并运行定向回归；仅在明确取得 SDK 使用权后运行。
- 用真实 H2 数据库验证状态选择、租约/取消/到期、版本匹配、退避和批次边界；模拟连接器验证无远程写入、事务边界及异常隔离。
- 所有新快照和临时文件置于 `.cache/execution-recovery/`；进程临时目录局部覆盖。证据记录快照散列、命令原始退出码和测试计数。
- 完成后独立检查本阶段差异，再获得 Git index 交接，仅提交本阶段文件至 `dev`。

## 范围决定

完整策略写入恢复还需要冻结设备配置参数和远程策略资源归属证明。本阶段专注已发起分配的设备状态核对，`POLICY_WRITE_UNKNOWN` 不由本任务处理，作为后续专用恢复/人工复核接入项，不根据内容相同就自动继续分配。此决定避免将读取成功误作写入授权。
