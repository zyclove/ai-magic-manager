# 异步使用报表契约（候选）

适用于大范围设备报表。当前后端候选已实现，管理端任务页面和真实客户端联通仍在接入；本机运行版本尚未部署本功能。

## 范围与数据含义

- 保留现有 [使用报表](usage-report-contract.md) 的日历分桶、区间上下界、重叠处理、未授权／无记录区分及设备自报未验证语义。
- 一次明确选择 1–200 台设备，窗口最多 32 个实际日，周期 DAY／WEEK。默认源数据只保留 30 天，异步任务不会创造更早记录。班级／儿童范围是所选设备的约束，不把所选集合说成全班所有设备。
- 每台设备生成一个独立结果，单片最多 8 MiB，任务全部片的明文累计最多 128 MiB。各片有独立生成时间，任务不是跨设备原子快照；配置状态表示该片生成时的当前配置及设备自报回执。
- 任意一片超限或最终失败时整个任务失败，已生成片不作为部分成功下载。后台每次只生成一台设备，进度明确给出完成数／总数。

## API

路径前缀：`/api/v1/tenants/{tenant}/usage-report-jobs`。所有响应禁止缓存并区分 Authorization。

| 方法与路径 | 用途 |
|---|---|
| `POST /` | 创建，返回 202；必需 Idempotency-Key |
| `GET /?limit=20&cursor=...` | 仅列出自己的任务，limit 为 1–50 |
| `GET /{id}` | 查看当前状态，重新检查范围并在失效时清除产物 |
| `POST /{id}/cancel` | 取消队列／运行／已完成任务，删除加密产物；终态重复取消无副作用 |
| `GET /{id}/parts/{ordinal}` | 读取已完成任务中的一台设备报表，重新强认证及当前范围校验 |

创建字段：`deviceIds`、`from`、`to`、`timeZone`、`period`、`scope`。scope 沿用 `DEVICES`、`SUBJECT`、`CLASS`（含当前版本）结构。未知字段、重复设备、无效范围和超过设备上限拒绝。

同一个幂等键和相同规范化请求返回原任务的当前状态；不同请求复用键返回冲突。未来查询末端在首次创建时截断到当时，随后不会随着重试延长。

返回任务包含 id、state、createdAt／updatedAt／expiresAt、totalDevices／completedDevices、byteCount、failureCode、冻结 selection 及 parts。每片包含顺序号、设备／注册／档案标识、授权版本／是否启用、生成时间和明文大小；队列片的时间和大小为 null。没有公开存储密文、操作者标识或凭据。

结果片直接使用已有 schemaVersion=1 的单设备报表结构，可继续使用严格类型客户端；下载文件名由服务端固定产生。下载只在整个任务 READY 时允许，不能利用单片接口绕过未完成、撤销或失败状态。

## 权限与生命周期

- OWNER／GUARDIAN／ORG_ADMIN 只能创建和读取自己的任务；当前成员关系仍由数据库决定。同租户其他管理员也不能读取该任务。教师、审计员、儿童不新增异步私有观察权限；儿童仍使用自身同步报表。
- 创建和结果读取要求已有近期多因素认证；缺失返回 401 `REAUTH_REQUIRED`。不能用客户端布尔值替代认证事实。
- 创建冻结成员版本、设备／注册／档案、观察授权版本、启用事实和范围版本。中间片只核对自身设备，最后一片生成前与每次下载都会在事务锁内复核全部选择；任一项变化，任务 REVOKED，不发布或读取旧结果。未 READY 的中间密文从不提供下载，避免为每片重复读取全部设备带来的平方级授权查询。
- 锁顺序为当前成员 → 报表租户互斥头 → 任务 → 班级（如适用）→ 排序档案 → 排序设备 → 观察授权／配置。公共 observation 授权快照只读取当前设备／授权，不预载全部观测载荷。
- 状态为 QUEUED、RUNNING、READY、FAILED、CANCELLED、EXPIRED、REVOKED。创建后 24 小时到期；到期后拒绝读取并删除密文，终态元数据 30 天后清理。
- 工人持有 60 秒租约和随机声明令牌；在独立、最长 10 秒的事务里校验并发布一个设备片，租约失效不能发布。成功片和进度原子提交；进程中断后从下一片继续。
- 临时失败按 30 秒乘当前尝试次数退避，连续三次未成功则失败。每个成功片重置尝试计数；明确容量不足直接失败。取消和终态清理删除全部密文，不假装已生成数据从未存在。
- 每人每分钟最多一个新任务，每人同时最多 3 个有效任务，每租户同时最多 20 个；原幂等请求重试不消耗新的任务额度。

## 加密与运行配置

复用已有外置 JWE 密钥环 `AUDIT_EXPORT_KEY_FILE`／`AUDIT_EXPORT_ACTIVE_KEY_ID`，采用独立保护头 purpose `usage-report-v1` 与 A256GCM；审计导出仍使用原 purpose。租户、任务、选择哈希、成员版本、有效期及分片绑定均参与认证，密文不能交换到其他任务或分片。

`USAGE_REPORT_WORKER_ENABLED` 默认 true，`USAGE_REPORT_WORKER_INTERVAL_SECONDS` 默认 5。未配置密钥时不接受新任务，工人不生成明文替代产物；到期清理不依赖密钥可用性。生产日志只包含安全错误类别，不记录密钥、令牌或报表正文。

## 当前验证边界

新增旅程覆盖 21／200 台设备完整分片流程、非空聚合、加密篡改、原请求重试、取消、失权、归档、重注册、成员版本变化、租约恢复、双工人、退避及容量拒绝。200 台用例采用无观测记录设备，不代表 200 台全部达到单片上限的极限负载。真实 OIDC／OTP、管理端任务页面与最终部署尚不能由这些测试推定；后续证据记录在 [异步报表实施记录](usage-report-jobs-plan.md)。

## 管理端操作

- “使用报表”即时生成最多 20 台；“后台生成”支持最多 200 台。选择器按名称、设备或档案标识搜索，显式选择筛选结果；超过上限会禁用批量选择，不截断数据。提交前确认冻结的设备数量、日期、时区和日／周方式。
- 提交结果不明确时，对话框使用相同条件和请求标识重试，也可在“报表任务”检查已有任务。创建要求安全验证时，同页签只保存待确认条件与请求标识，最长十分钟，绑定账号、工作空间和角色。回跳后重新确认，不自动提交；退出、换空间或身份不匹配时丢弃草稿。
- 任务列表支持分页、实际进度、刷新、取消确认和按设备读取。仅前台刷新，错误提示保持到明确重试；打开结果前重新检查任务与当前设备注册／档案，读取后仍检查有效期。结果设备支持名称搜索和键盘／辅助技术操作。
- 授权、空间、后台状态或有效期变化时清除已打开结果；后台停止轮询。已保存结果使用“生成时的规则与下发状态”，不把过去快照称为最新配置。无数据、未授权、生成失败与过期分别展示。
- 真实 Spring／MySQL → 生产 Dart 客户端旅程已覆盖创建、原键重试、列表、轮询、分片、近期 MFA 拒绝、同租户成员隔离与取消。其身份认证使用测试解码器，不能作为真实 OIDC／OTP 或浏览器操作的证明。
- 结果页支持下载本设备 JSON。下载重新读取当前任务和设备绑定、检查近期认证及有效期，并再次通过完整报表解析；类别筛选不裁剪下载文件。保存的是规范化 JSON 内容，浏览器下载交接成功不等于用户已保存磁盘文件。线上任务取消或到期不会删除已经下载的副本。
