# 当前设备应用身份核验

更新：2026-10-16。状态：纯领域核验已实现，115 项定向回归全部通过。此文不代表设备级执行已经可用；本轮尚未部署到运行服务。

## 解决的问题

提供方返回的安装和签名事实必须与当前本地注册、受管绑定和应用定义共同核对。设备重新注册、管理员撤销关联、应用定义改变或报告过期后，先前的报告不能继续授权新的操作。

此步骤接在[应用报告读取](managed-application-report-contract.md)之后，为后续证据存储和策略编译提供纯领域核验器。它不读取数据库、不调用网络，也不替代服务端当前授权检查。

## 输入与作用域

- `captured`：发起提供方读取前，从服务端受信记录构造的上下文。
- `current`：外部读取完成后，在短事务中重新授权并加载的当前上下文。
- `report`：提供方连接器返回的 `ManagedApplicationReport`，不得采用儿童端自报清单。
- `retrievedAt`：平台实际获取报告的时间，不接受客户端填写。

上下文包含租户、设备、本次注册、注册密钥指纹、绑定及其版本、提供方、提供方设备资源、企业关联版本、连接器修订、应用 ID、身份定义摘要、包名、允许的签名集合、管理模式与证据起算时间。两份上下文必须完全一致且当前有效。

调用方负责当前 RBAC/设备范围权限、机构合同、注册密钥、企业关联及绑定有效性。`active` 只能根据服务端这些有效记录构造；传入 `true` 本身不是授权证据。不得将这些类型作为面向设备或管理员的请求 DTO。

应用目录当前不可变，后续服务应基于规范化身份字段生成稳定摘要（平台、包名、声明用户空间、排序后的签名集合）；名称修改不应改变身份。核验器只比较从可信记录产生的摘要，不替目录生成不存在的数据库版本。

## 签名与时间规则

1. 提供方设备资源、包名和管理模式必须精确匹配当前上下文。
2. 只接受明确 `INSTALLED`；未知、缺失、移除状态均不当作已安装。
3. 报告签名集合非空、无重复，每个摘要均为规范小写 SHA-256，并全部属于管理员明确配置的允许集合。允许集合最多 8 项，与现有应用目录契约一致；不能仅匹配其中一个摘要就通过。
4. `evidenceNotBefore` 取当前注册、绑定核验和身份定义生效时间的最大值。报告和平台获取时间均不得早于它。
5. 报告允许的时钟偏差同时相对于获取时间及当前时间检查；平台获取时间不能在当前时间之后。
6. 有效期为 `min(报告时间 + 最大报告年龄, 获取时间 + 最大复用时间)`。重复获取同一报告可以刷新短期缓存，但不能越过报告的硬期限；在到期时刻即失效。

核验器使用调用方配置的 `Duration`：最大报告年龄为正且不超过 1 小时；最大复用时间为正且不超过 5 分钟；时钟偏差为 0–30 秒。回归夹具使用 10 分钟、2 分钟和 30 秒；这些夹具值不表示已新增生产配置项。

## 输出及后续接入

成功结果保留上下文、已匹配签名集合、报告时间、获取时间和到期时间，集合不可变，诊断文本不泄露稳定标识。用户空间仍明确为 `UNKNOWN`：现有应用报告不能证明本地 PRIMARY/WORK/SECONDARY，身份匹配也不是系统执行能力或设备已应用回执。

后续短事务服务需要保存与当前绑定关联的最小结果，并在预览和发布时重新校验代次及有效期。外部 HTTP 请求不得放在数据库锁内；未确认的 profile 和动作能力仍按具体原因阻止执行。当前尚未新增这些存储、接口或策略编译接入。

## 错误码与后续界面语义

| 错误码 | 含义 |
| --- | --- |
| `MANAGED_APPLICATION_CONTEXT_INVALID` | 当前有效上下文或签名信任配置不完整，不能核验 |
| `MANAGED_APPLICATION_CONTEXT_CHANGED` | 读取期间设备、注册、绑定、提供方或应用身份定义已变化，需要重新预览 |
| `MANAGED_APPLICATION_REPORT_MISSING` | 暂无目标应用报告，不能据此推断卸载 |
| `MANAGED_APPLICATION_REPORT_INVALID` | 报告身份或时间格式不符，或时钟偏差超出范围 |
| `MANAGED_APPLICATION_INSTALLATION_NOT_CONFIRMED` | 报告不能确认已安装；未知状态与明确移除仍由原报告区分 |
| `MANAGED_APPLICATION_SIGNER_UNTRUSTED` | 应用签名缺失、重复、格式错误或不在允许集合中 |
| `MANAGED_APPLICATION_REPORT_STALE` | 报告/获取时间早于当前绑定，或报告及缓存已到期 |

异常只包含稳定错误码，没有原始报告或底层解析异常。以上尚未新增管理端展示或 HTTP 接口；后续界面按[报告状态展示约定](managed-application-report-contract.md)提供原因和下一步操作。
