# 策略预览的设备目标选择

## 当前行为

管理端策略预览允许管理员分页挑选最多 50 台设备。机构 OWNER/ORG_ADMIN 还能从一个活动设备组一次选取当前活动成员；成员总数超过 50 台的组不能一键选为单次目标，仍可手动选择明确设备。非活动成员被排除并显示数量。家庭监护人只看到本人有权限的设备列表，儿童和教师无策略入口。

设备组选择采用“读取组版本 → 读取成员页 → 再读组版本”；两次版本不一致即拒绝。预览前和确认保存配置前再核对当前组版本。管理员手动增删选择后，来源标记清除。服务端策略预览仍只接收明确设备 ID 列表，并验证当前设备状态和规则能力；返回目标若与请求不一致，客户端停止发布。

这是**一次性目标快照**，不是动态设备组策略。设备组后续增减成员不会自动改变已发布的配置；组版本检查也不能替代事务性、服务端持久化的组来源与范围哈希。真正按组发布还需在策略域记录组 ID/版本、统一解析批量目标、冲突预览、逐设备执行回执和变更后对账。当前 `CONFIGURE_ONLY` 发布不会执行系统级应用限制。

## 交互与错误处理

选择器同时展示已选数量、组来源版本、排除设备数和明确的非动态边界。设备列表、组列表均分页，最多选择 50 台；空态、网络失败和权限变化有可见处理。切换工作空间、角色或账号时关闭选择器并废弃旧结果，已打开的发布预览立即隐藏旧范围内容。组过大、空组、归档组或版本变化都要求重新选择；发布前仍由管理员核对预览规则及设备，再完成近期多因素认证。

## 验收缺口

当前只完成静态分析与 Web 构建；还需浏览器窄屏/键盘检查、真实机构账号操作、组增删并发、设备撤销、旧注册周期、50 台上限和策略预览/发布 HTTP 流程。不能把 UI 版本检查或构建成功当作系统执行证明。
