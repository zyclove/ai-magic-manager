# 监护人 Android 客户端：阶段交付与剩余门槛

更新：2026-10-13。此文档区分已提交代码和生产可用状态。目标区域为中国大陆，首发机构合同优先；现有 Web 管理台仍承担平台运营、批量策略、合同和诊断流程。

## 当前实现

| 流程 | 手机端行为 | 服务端接口与授权 |
|---|---|---|
| 登录与会话 | AppAuth 系统浏览器发起 Authorization Code + PKCE；内存访问令牌、加密存储刷新令牌；到期自动刷新、退出清除本地凭据 | Keycloak 公共客户端 `ai-manager-parent`；`GET /api/v1/me` |
| 工作空间 | 读取当前成员可见的家庭/机构，切换时重新核对成员角色；儿童角色没有成人操作入口 | `GET /tenants`、`GET /tenants/{id}/membership`；后端仍做逐请求鉴权 |
| 今日概览 | 服务端授权范围内的儿童、已注册设备、待审批和求助计数；儿童仅展示前 5 条；标明“在线/权益”不等于执行 | `GET /overview`、`GET /subjects?limit=5` |
| 访问申请 | 服务端筛选待处理项并在授权结果中附儿童、应用、包名和设备名称；成人在卡片及确认弹窗核对对象后批准/拒绝并再次认证；提交带版本及幂等键，连接中断后查询原申请且不自动重发；批准窗口不超过申请时长，提示需等待设备实际执行 | `GET /access-requests?state=PENDING`、`GET /access-requests/{id}`、`POST /access-requests/{id}/decisions`，`If-Match`、`Idempotency-Key` 和服务端近期认证 |
| 申请记录与交付 | 申请页可分页查看授权范围内的历史，处理成功后直达原申请状态；详情同时核对申请版本和交付摘要，分开展示审批、文档交付、设备自报及系统执行。设备收到或保存文档不显示成限制已解除 | `GET /access-requests`、`GET /access-requests/{id}`、`GET /access-requests/{id}/delivery`；服务端逐次校验当前成员及儿童范围 |
| 求助 | 展示未确认求助，成人确认已看到；传输结果未知时查询原记录并保持联系孩子的提醒，明确不是紧急服务 | `GET /help-requests?state=OPEN`、`GET /help-requests/{id}`、`POST /help-requests/{id}/acknowledge`，`If-Match` |
| 设备 | 分页展示注册状态和管理模式；点开设备可看连接观察及逐项能力证据、限制原因，提醒另查策略执行回执 | `GET /devices`、`GET /devices/{id}`、`GET /devices/{id}/capabilities` |
| 设备配对 | 分页选择儿童与 Android/TV；近期认证后先保存随机注册请求编号，再生成 BYOD 一次性凭据；响应丢失或进程重启后可按原编号查询、不回显秘密；儿童端认领后刷新状态、输入物理设备配对码再次认证确认；可取消 | `POST /enrollments`（`Client-Request-Id`）、`GET /enrollment-creation-results/{id}`、`GET /enrollments/{id}`、`POST /enrollments/{id}/confirm`、`DELETE /enrollments/{id}` |
| 正常退出 | 复用 Web 管理台 `device_operations` 组件；先预览后果、近期认证、带版本和幂等确认；网络结果未知时保留恢复记录，云端撤权与本代理清理回执分开展示 | `GET /devices/{id}`、`/devices/{id}/deprovision` 路由；只开放当前 BYOD 注册，服务端逐请求鉴权 |
| 商业账户 | 在“我的”只读显示已核验的设备名额和功能权益；无购买、合同自授权按钮，明确与设备系统能力区分 | `GET /commercial-entitlements`；服务端限成人管理员/审计员 |

手机端复用现有 `/api/v1` 后端契约，采用独立 Flutter 工程，避免 Web 专有 `dart:html`、浏览器存储与 URL 回调渗入原生客户端。依赖锁定在 `apps/parent/pubspec.lock`：`flutter_appauth 9.0.1`、`flutter_secure_storage 10.0.0`，分别用于原生 OIDC 与安全存储；升级需按 Flutter 版本和 Android 兼容矩阵审查。Android 仅声明网络权限，不声明相机或无障碍权限。

完整管理台入口由构建时 `CONSOLE_URL` 指向已部署的 HTTPS Flutter Web 站点，仅在当前工作空间具有成人管理角色时显示，使用 Flutter 官方 `url_launcher 6.3.1` 在系统浏览器打开。移动端不会把访问/刷新令牌放入链接，也不绕过 Web 管理台自身的 OIDC、权限和近期认证；未配置时隐藏该入口。手机端 API 请求禁用自动重定向并限制单次响应为 1 MiB，避免携带令牌的跨源跳转和异常大响应。

今日计数由服务端授权范围内的聚合接口计算。申请、求助和设备列表一次只读 50 条，用户主动加载下一页；重载和账号/租户/角色改变会使旧页面与未完成响应失效。分页响应要求唯一记录 ID 和单调前进的游标，避免重复结果混入当前列表。

设备能力详情只呈现服务端按当前成员范围返回的证据投影；切换账号、租户或角色时立即关闭旧设备详情。`reportedSupported` 是设备自报，`effectiveSupported` 是服务端可用性判断，两者均不代表某条规则已执行。当前 BYOD 注册仍是有限能力，管理端须进一步核对该规则的交付与执行回执。

当前 Android 最低 API 24、编译 API 36、NDK `27.0.12077973`、Java/Kotlin 17，沿用仓库已安装的 Gradle 8.13 工具链。此组合已完成 debug APK 构建；构建时的示例 HTTPS 域名仅用于编译配置，不代表真实身份联调或生产地址。

## 流程与异常

1. 部署管理员提供可在真机验证的 HTTPS Keycloak 和 API 地址；身份管理员把公共客户端、精确重定向 URI、API audience 与允许的 scope 纳入现有 Realm。当前本地 `localhost` Compose 不能直接作为 Android 真机身份环境。
2. 成人在系统浏览器验证身份；移动端收到 code 后由 AppAuth 完成 PKCE 交换，再从服务端加载 `me`、可见工作空间和当前成员资格。没有工作空间则显示引导，不假造“已受保护”。
3. 工作空间切换先查询目标 membership，成功后替换页面实例；请求仍由后端按租户与角色授权。审批前以 `max_age=0` 重新走系统浏览器；取消、操作者改变、工作空间改变均停止写入。
4. 读取失败保留错误与重试入口；版本冲突或网络结果未知时，成人刷新原申请/求助，不自动重复批准。审批成功后可从申请页查看原申请及当前交付摘要；如果两次读取期间审批版本改变，详情要求重新查询。API 错误保留 correlation ID 供诊断，但不在日志中写令牌。
   审批 POST 带新 UUID 幂等键。发送前按租户和操作者保存申请编号、版本、决策、幂等键及时间，并等待 Android 安全存储持久化确认；确认失败就停止提交。响应丢失或进程重启后显示待核对提醒，查询原申请的当前状态，提示成人核对，不把网络异常误报为“未批准”。客户端不自动重发审批；同一申请版本存在待核对记录时也禁止再次点击批准或拒绝。记录仅由成人确认后在本机清除，不会撤销服务端决定。跨会话同键自动重试尚未实现。
5. 登出先清除本地刷新令牌和内存状态，再尝试结束浏览器 SSO；后者失败时本地会话仍已清除。设备遗失时还须在身份系统撤销会话/刷新令牌。
6. 设备配对只允许 `BYOD`。完整 JSON 注册凭据与儿童端现有解析格式一致，仅在创建响应后留于内存；复制操作由成人触发，Android 剪贴板不是安全存储。成人从物理设备读取 8 位配对码并确认。创建前先把非秘密的 UUIDv4 请求编号存入安全存储并随请求发送；网络结果不明或进程重启时按此编号查询服务端，不自动重发创建。已创建但尚未认领的注册若丢失 token，只能取消再创建；不能通过管理查询恢复一次性秘密。
7. BYOD 正常退出由复用的 `device_operations` 控制器核验精确租户、设备、注册周期、当前版本和预览后果；手机端 HTTP 适配器每次发送前取当前令牌并禁止跨源重定向。取消系统浏览器重新验证不会自动提交写入。恢复日志只存请求键及绑定元数据，不存凭据；云端撤权不证明设备本地已完成清理或系统级解除管理。

## 尚未完成

- 真机安装、系统浏览器回跳、Keycloak 近期 MFA、令牌轮换/吊销、TLS 与 Android 生命周期恢复的端到端验收；当前不能称为已可生产发布。
- 临时访问申请已显示授权范围内的儿童、应用、包名和设备名称；审计角色不额外获得这些展示资料。跨进程待核对提醒已接入 Android 本地安全存储，但真机进程回收和存储故障演练仍未完成；超长列表虚拟滚动、推送通知和离线只读快照仍待完善。当前列表经服务端按持久化 `PENDING` 筛选后每次加载 50 条；主体/设备生命周期可能在读取时使申请失效，客户端按响应实际状态隐藏这类项目。名称是帮助成人核对的目录资料，并非应用安全性或设备执行证明。
- 政策编辑/预览/发布、日程/额度、机构班级与合同确认等完整成人工作流仍由 Flutter Web 管理台承担；需设计和实现手机端后续页面并逐项确认无 Web 专属依赖。设备配对已具备原编号恢复查询，但令牌跨设备安全传递、扫码输入与 TV 遥控体验仍需专门验收。
- Android 受管 EMM/OEM 连接器、Android TV 型号认证、摄像头可选识别和真实设备系统策略执行均未由本客户端实现。没有提供方资格时，客户端不显示“不可绕过”的承诺。
- 已补齐 Android release 签名的构建门槛与 [发布规程](parent-android-release.md)，但尚无真实密钥及正式签名产物；供应链/SBOM、无障碍和字体缩放检查、低网速/断网/进程回收演练及客户试点签收仍待完成。

## 生产准入

安全、客户端、后端和机构客户共同确认：同一成人/不同成人/儿童越权；跨租户切换；取消重新认证后无写入；申请过期、版本冲突和重试；求助已读语义；刷新令牌撤销；设备离线时显示执行未知；Android 设备模式差异；登出后内容清除。只有真实 HTTPS + IdP + API + Android 实机链路通过，才可将应用标为交付安装包。
