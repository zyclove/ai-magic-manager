# 家庭账号验收入口与收费门禁

供应商凭据和正式签名真机尚未准备，本轮先完善验收准备、版本绑定和服务端收费保护。真实短信、微信及账号流程仍为 **0/12**，消费者入口和购买保持关闭。

## 管理员怎样使用

从「平台管理 → 短信与微信」进入，完成配置检查、受控发布和生效核对后，按验收卡的三个步骤操作：

1. **准备环境**：查看当前缺口。建立登记时自动使用已确认的配置、发布操作和 APK/JAR 摘要，不再手工填写摘要。没有当前确认版本或仍有发布进行时，先处理页面提示的一步。
2. **手机完成**：由部署管理员另行准备受限成人试点环境，使用正式签名家长 App 完成登录、换绑、恢复和微信绑定解绑。发布状态 `APPLIED_CLOSED` 只说明关闭入口的配置已加载，不能直接用于正常消费者登录。账号操作沿用 App 的「我的 → 账号与安全」，验证码由接收人输入。
3. **核对结果**：查看十二项待办和最近五次登记。当前页面没有手工通过或开售按钮；准备齐全、配置已加载和安卓预检通过均不计作真实验收通过。

管理台不收集手机号、验证码、微信授权码或 token。刷新失败时停止使用旧状态建立登记；提交结果不明时，使用原操作编号查询，不自动重发。原编号恢复的是原记录，不能延长有效期或换成另一版本。

## 当前登记怎样失效

登记冻结环境、配置版本、已确认发布操作、运行修订、APK/JAR 摘要和 24 小时有效期。配置变化、发布进行中、运行目标变化或登记过期后，需要重新核对并建立新登记；旧记录保留供查阅。

旧接口创建的未绑定清单仍可查询，但不会自动变成当前有效登记。页面区分「尚未准备」「待真实联调」「登记已过期或目标变化」，不会把历史记录当成当前结果。

## 收费保护

服务端独立检查身份供应商验收、正式安卓设备验收、微信支付退款验收和发布准入。`manager.family.sales-enabled` 只表达开售意图，不能单独开启付款。

本轮尚未交付可信的真实验收采集和正式启售机制，生产门禁固定关闭。微信支付适配器在判断付款可用及发起付款时均检查门禁；检查异常也拒绝新付款。未付款订单草稿仍可登记，不能据此获得支付参数或会员权益。

查单、支付通知验签、自动关单、退款和日账单对账继续保留，避免关闭新销售影响既有售后。管理端展示门禁原因，不能提交 `allowed=true`、通过标记或绕过证据要求。

## 安卓只读准备检查

使用 [安卓预检说明](family-android-acceptance-preflight.md) 检查实际 APK 包名、签名、调试属性和本机设备准备情况。工具不安装或启动 App、不调整权限、不调用短信或微信、不修改开关。

调试包、没有已授权设备、证书不匹配或仅声明 AppID 都不能完成正式设备验收。预检报告始终保持 `acceptanceStatus=BLOCKED`、`salesAllowed=false`，设备别名仅供本次检查使用，不保存原始序列号。

## 接口与部署边界

前缀 `/api/v1/platform/identity-providers`：

| 接口 | 用途 |
| --- | --- |
| `GET /acceptance-status` | 当前准备状态、下一步、十二项真实待办及收费门禁 |
| `GET /acceptance-runs` | 同环境最近五条登记 |
| `POST /acceptance-runs` | 建立绑定当前已确认发布操作的登记 |
| `GET /acceptance-runs/{id}` | 按原编号恢复登记结果 |

新建请求在原五字段之外成对提供 `releaseOperationId` 和 `expectedRuntimeRevision`。服务端加锁核对当前目标；接口继续要求独立平台权限、近期 MFA 和禁止缓存。

新增三项可空登记列仅在未发布 1.0.0 初始化基线及全新隔离数据库验证。未修改既有部署、身份域或数据库；已有库接入须另行制定备份、向前迁移和恢复方案。

真实案例与证据要求见 [供应商联调验收](family-identity-provider-acceptance.md)，受控部署与回退见 [受控发布说明](family-identity-controlled-release.md)。

## 下一阶段的开放条件

- 使用[家庭验收构建模式](family-android-acceptance-preflight.md#后续正式验收缺口)生成并核对正式签名包及来源清单，准备供应商受限配置、已授权成人接收人和真机。构建入口已提供，实际签名构建尚未验收。
- 在独立试点中完成十二项真实联调，建设可信服务端证据核对和独立受控启售流程。本轮没有可绕过这些条件的开售 API。
- 完成目标 MySQL 8.4 与实际身份服务的联合验收。本机 MySQL 8.0.41 的 SQL 验证不能替代目标版本准入。
- 修复并行管理界面的待办详情回归和编辑页分析提示，完成全端发布验收。账号功能交付与这些既有缺口分别记录。
