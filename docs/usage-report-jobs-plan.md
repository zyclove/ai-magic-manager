# 异步使用报表实施记录

承接已批准的 RPT-01 与 usage-report-plan。上一轮儿童端页面／真实 HTTP 联通属于实际进展；当前目标保持全产品范围。本阶段沿用已配置 Spring JDBC、事务、调度、幂等和 Nimbus JWE，不引入新的任务服务。

## 设计裁定

- 任务处理最多 200 台显式选择的设备，日／周与最多 32 个实际日的窗口沿用现有聚合合同。默认观察保留 30 天，不因异步处理承诺不存在的长期历史。超过容量必须明确失败，不截断成成功。
- 每个设备为一个独立加密结果分片，单片沿用 8 MiB 上限，任务总明文上限 128 MiB；客户端按片读取与查看，避免一次下载或一个事务承载全部结果。每片提供生成时间，任务不声称所有设备是同一瞬间的原子快照。
- 只有 OWNER／GUARDIAN／ORG_ADMIN 创建并读取自己任务，创建和结果下载要求近期强认证。儿童保留已有本设备／自身同步页面；教师、审计员不因异步任务扩大私有观察权限。
- 创建冻结成员版本、班级版本、设备／注册／档案／观察授权版本及查询窗口。生成每片与读取每片时重新检查，变化后不暴露旧结果；授权关闭作为 NOT_AUTHORIZED，而不是零使用。
- QUEUED → RUNNING → READY；取消、撤权、过期、不可恢复失败均删除已生成片。任务租约与声明令牌阻止重复发布，短事务分批执行并记录实际进度；中断后从已完成分片继续，临时故障退避重试。
- 结果使用已有密钥环及 A256GCM，但新增固定 usage-report-v1 purpose，认证附加信息绑定租户／任务／选择／分片。审计导出原 purpose 和接口保持兼容。
- 明确前台任务列表、进度、取消、原请求幂等重试、按设备打开结果和过期恢复；候选完成整个阶段后统一最终独立审阅和部署。

## 顺序与证据

1. 新建任务契约与失败测试；实现授权快照、V25 持久化、创建／列表／状态／取消。
2. 实现租约工人、分片加密、重新鉴权读取与清理；覆盖并发、故障恢复、容量、撤权、过期、篡改。
3. 管理端大范围选择与任务 UI、类型解析、真实 HTTP 旅程；检查手机／桌面、后台停止轮询、角色变化清理。
4. 真实 MySQL／非空迁移、完整回归与构建、整个报表阶段一次最终独立审阅，修复后再部署。

固定测试候选使用 `.local/report-backend`，儿童与 SDK 继续固定 e72f556 报表覆盖版本。工作区中其他任务的在途修改不混入验证。旧阶段冻结清单和 Git 索引不改。
