# Android TV 儿童端界面阶段

## 已实现

- Android 宿主通过 `UiModeManager` 报告电视模式，Flutter 不再仅凭屏幕宽度推断电视；设备识别结果不授予管理权限。
- 电视已连接时使用大字侧边导航，保留设备、规则、使用和帮助四个现有页面；手机和平板继续使用底部导航。方向键及遥控器确认键沿用现有 Flutter 焦点映射。
- 电视未连接时保留监护人发起的注册凭据和八位配对码流程，并提示使用系统键盘或外接键盘输入。儿童端不能更改服务地址、管理员、设备模式或策略。
- 页面继续明确：配置验签/保存不表示系统已限制其他应用；设备当前仍是个人设备能力范围，商业权益也不能扩大 Android 权限。

## 交互与异常

| 场景 | 界面行为 | 后续责任 |
|---|---|---|
| 已连接电视 | 侧边导航可聚焦，选择后同一内容区切换；顶部留白和内容宽度适合远距阅读 | 真机确认焦点顺序、遥控器按键映射及文字截断 |
| 未连接电视 | 显示部署服务地址、完整凭据输入及帮助；凭据仅在当前前台持有 | 监护人从管理端创建并确认设备；未来提供更省输入的可信配对方式 |
| 网络中断/回执待发 | 保留现有本地已验证状态和错误提示；不会把离线当作规则解除 | 后续增加受管模式的重启对账与持久后台调度 |
| 不支持的系统控制 | 明示限制能力缺失，不显示“已禁止其他应用” | 需合规 EMM/厂商能力及真实 TV 兼容认证 |
