# 限时加密诊断包实施契约

承接诊断计划第 4 步，本文件记录正在实施的边界，不代表已通过验收或部署。继续复用 Spring 事务／调度、Nimbus JWE、Flyway、现有诊断允许列表与 Flutter Material。

## 使用场景

- 管理员可为当前 ACTIVE 设备创建完整诊断包，绑定自己当前成员版本、档案及设备注册周期。需近期 MFA、设备 If-Match 和幂等键。
- 合格支持接收人可从现有限时授权创建诊断包，只包含该授权允许的类型；绑定接收人、授予者成员版本及授权版本。需近期 MFA 和幂等键，不能扩大授权范围。
- 任务和下载仅供发起账号；管理员不能因为同属租户读取其他账号的产物。客户通过撤销原支持授权停止支持接收人后续下载。
- 包有效期为创建后最多 30 分钟，支持场景不得超过原授权截止时间。幂等重放不延长截止时间。

## 任务与产物

状态为 QUEUED、RUNNING、READY、CANCELLED、EXPIRED、REVOKED、FAILED。独立短事务领取任务，使用有期限的租约和随机领取令牌隔离旧执行者；最多重试三次。一次任务仅处理一台设备，完整 JSON 上限 512 KiB，不提供部分产物。

产物采用独立配置的 256 位密钥环及 Nimbus JWE `dir`／`A256GCM`，用途固定为 `device-diagnostic-v1`，并绑定租户、任务及不可变范围摘要。密钥缺失时明确报告不可用，不降级明文保存；配置文件不得为链接，限制大小及密钥数量。任务记录只保存密文、长度及 SHA-256，不保存诊断明文或 JWT。

下载通过当前认证请求解密返回 JSON 附件，禁止缓存，没有公开链接。下载前后检查权限、注册、期限与内容摘要；撤销不能收回已保存到用户电脑的副本。任务列表只含必要元数据，不含原配对码、密文、诊断或姓名／自由文本。

## 并发及生命周期

锁顺序为授予权限的成员行 → 租户任务容量行 → 档案 → 设备 → 支持授权（如有）→ 任务 → 配置读取。管理员自己的诊断包以其成员行为授权来源；支持包以原授予者成员行为来源。幂等容量检查在同一事务中完成，每租户最多 100 个有效任务、每发起账号最多 10 个，终态不能被重试复活。

生成和下载复核当前授权，设备注销、注册周期变化、档案归档或授权成员版本变化使任务失效。后台定期复核和清除到期／撤销产物；下载权限立即失效不依赖清理任务完成。任务元数据与审计继续保留用于追踪，终态不保留产物。

## 验收要求

先验证密钥配置、篡改、用途和绑定隔离，再覆盖两类真实接口旅程、近期 MFA、跨租户／跨账号、幂等重放／冲突、并发领取与容量、崩溃租约恢复、部分不可下载、权限和注册变化、撤销／到期清理、重试耗尽、事务回滚、最大产物及非空 V28→V29 迁移。随后完成生产 Dart HTTP、下载与进度界面、手机及真实后台切换验收，并对完整诊断阶段执行一次独立审阅。

当前服务及业务数据库保持原版本；此源码开发不解除此前部署审批阻挡。

## 配置与接口

`DIAGNOSTIC_PACKAGE_KEY_FILE` 指向仅后端运行账号可读取的独立 JWK Set。最多 8 个密钥，均为 `oct`、256 位、`use=enc`、`alg=dir`，具有唯一 `kid`。多个密钥时必须通过 `DIAGNOSTIC_PACKAGE_ACTIVE_KEY_ID` 指定当前写入密钥。轮换时保留旧密钥直到依赖它的产物已过期并清除；更换同一个 `kid` 的密钥材料会使旧包无法解密。配置错误中不会包含密钥正文。

`DIAGNOSTIC_PACKAGE_WORKER_ENABLED` 默认为 true；`DIAGNOSTIC_PACKAGE_WORKER_INTERVAL_SECONDS` 默认为 5。每轮最多检查 25 项清理记录并生成 2 项任务。多个实例通过数据库锁及领取令牌协调，任务和密文均保存在同一业务数据库的 V29 表中。

| 操作 | 管理员入口 | 支持接收人入口 |
| --- | --- | --- |
| 创建 | POST `/api/v1/tenants/{tenant}/devices/{device}/diagnostic-packages` | POST `/api/v1/support/grants/{grant}/diagnostic-packages` |
| 列表 | GET `/api/v1/tenants/{tenant}/diagnostic-packages` | GET `/api/v1/support/diagnostic-packages` |
| 详情 | 上述列表路径加 `/{id}` | 上述列表路径加 `/{id}` |
| 取消／清除 | POST 详情路径加 `/cancel` | POST 详情路径加 `/cancel` |
| 下载 | GET 详情路径加 `/content` | GET 详情路径加 `/content` |

所有入口要求近期 MFA。创建携带幂等键，管理员请求体包含设备 `registrationId`，并携带设备 If-Match；取消使用任务 If-Match 和幂等键，READY 状态也可取消并立即清除服务端密文。返回结果的 ETag 来自当前任务版本。分页默认且最多 25 项，列表始终限定当前发起账号及访问模式。

下载未准备好返回 `DIAGNOSTIC_PACKAGE_NOT_READY`，到期返回 `DIAGNOSTIC_PACKAGE_EXPIRED`，密钥缺失／密文损坏返回 `DIAGNOSTIC_PACKAGE_UNAVAILABLE`；越权返回既有 `SCOPE_DENIED`。错误不带原始异常、SQL 或诊断。临时生成失败最多尝试三次，外部仅展示已知失败代码。
