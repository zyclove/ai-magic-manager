# 使用报表契约（实现中，尚未部署）

## 当前范围

候选实现提供设备／儿童／班级范围的使用观察日／周查询、应用与系统资料明细，以及管理员声明分类的结果内筛选。来源仍为已有 Android UsageStats 汇总；不新增采集权限。当前运行版本仍为 V22 审计导出版本，不能将本文件当作已经上线的功能清单。

`GET /api/v1/tenants/{tenantId}/usage-reports`

| 参数 | 约束 |
| --- | --- |
| `deviceId` | 重复参数，1–20 个不同的设备 UUID |
| `from`, `to` | 毫秒时间戳，左闭右开，正数、递增，最大 32 × 24 小时 |
| `timeZone` | 服务端支持的 IANA 时区，不接受固定偏移替代 |
| `period` | DAY 或 WEEK，默认 DAY；周一开始周 |
| `scopeKind` | DEVICES（默认）、SUBJECT、CLASS |
| `scopeId` | SUBJECT 为儿童档案 UUID，CLASS 为班级 UUID；DEVICES 不传 |
| `scopeVersion` | CLASS 必填当前名册版本；其他范围不传 |

返回 `Cache-Control: no-store`。末端取请求末端与生成时刻中较早者。日历分桶遵循指定时区，包括夏令时和被跳过的民用日期；首尾桶允许不完整。

## 权限与快照

- 当前 OWNER、GUARDIAN、ORG_ADMIN 可读；CHILD 只能选择自己的设备。TEACHER、AUDITOR 无此私有观察权限。
- 事务依次锁定当前成员、按 UUID 排序的已激活设备和当前观察授权，覆盖源读取、聚合及序列化大小预检。撤销成员或修改相关设备、授权，与报表计算串行化。HTTP 网络传输不保持数据库锁。
- 每条数据匹配当前设备注册周期和保留边界。关闭使用观察返回 NOT_AUTHORIZED，不返回历史明细。有效授权但没有相关保留记录返回 NO_DATA。
- JSON 中的报告标识、序号、授权版本必须与关系字段一致，且授权版本不能晚于当前版本；损坏数据返回 503，不输出部分报表。
- SUBJECT/CLASS 在成员锁之后取得当前范围：班级需机构 OWNER/ORG_ADMIN、未归档且版本一致；名册使用锁定读取，避免 MySQL 已建立的一致性快照返回旧成员。只锁选中档案，再按设备顺序锁定；档案归档或设备归属变化不能混入成功结果。
- 响应 `scope: {kind,id,version}` 与已应用查询一致；班级版本变化、移出学生或设备绑定变化返回 409 `REPORT_SCOPE_CHANGED`，归档班级返回 CLASS_ARCHIVED。儿童账号可以查询自己的 SUBJECT 范围，不能通过 CLASS 扩权。
- 范围仍包含显式选择的设备，不能将“班级内已选设备”称为班级全部设备。范围内超过 20 台时前端要求明确选择，不自动截取；大范围异步报表仍待实现。

## 证据与用量范围

整个响应明确标识 `OS_AGGREGATE`、`AGENT_REPORTED_UNVERIFIED`。系统资料 PRIMARY、WORK、SECONDARY、UNKNOWN 分开；UNKNOWN 不能解释为已认证的儿童身份。

每个设备／系统资料／应用，按最新序号优先选择互不相交的完整源区间。同区间仅保留最新值，其他相交区间全部排除并返回计数。这是保守选择，不代表重建了逐事件时间线。

对区间长度 d、记录时长 t、与桶交集长度 i：下界 `max(0, t - (d - i))`，上界 `min(t, i)`。桶下界累加所选区间下界，上界累加所选区间上界后加未覆盖时长。

| 桶状态 | 含义 |
| --- | --- |
| NO_EVIDENCE | 没有区间证据；上下界为 null，不能显示成零 |
| REPORTED_RANGE | 只能推导范围；上限包含缺失时段的可能用量 |
| REPORTED_TOTAL | 所选汇总可给出相同上下界；仍为未经独立验证的设备报告 |

周桶直接从所选源区间计算，不相加日桶上界。应用或设备之间可能并发，不把累计值称为儿童唯一在线时长，不写入硬额度账本。

`queryCoverageMillis` 是设备查询区间的并集；它不证明连续监测、应用可见性或全部应用完整上报。应用桶 `coveredMillis` 是保留证据区间的覆盖长度，与该查询指标不同。

## 容量与错误

- 全请求源 JSON 默认上限 32 MiB，可在 1 KiB–32 MiB 内配置；读取前按字节预检。
- 每设备最多 1024 批、100000 应用样本；整份报表最多 2000 个设备／资料／应用组合、8 MiB 序列化响应。
- 任一容量超限返回 413 `USAGE_REPORT_TOO_LARGE`；不能将部分成功伪装为全量结果。
- 非法选择/范围返回 400；撤权返回 403，设备非激活返回 409；源数据异常返回 503 `USAGE_REPORT_DATA_UNAVAILABLE`。

## 当前规则与配置交付状态

- 每个设备新增 `configurationState`：独立的 `checkedAt`、固定 `DELIVERY_ONLY_NOT_EXECUTION` 和当前配置列表。这是查询时的配置与回执，不是所选历史时段的执行记录，也不证明使用变化由规则造成。
- 复用 delivery 公共只读来源。调用方先在报表事务内获得当前成员、范围及设备授权；读取仅针对当前注册标识。按注册标识排序锁定已有交付头，以当前锁定读读取 streams、载荷大小与配置，并保持到最终响应序列化预检完成。不创建交付头，不复用旧注册周期记录。
- 每设备至多 100 份当前配置，整份报表配置 JSON 来源至多 2 MiB、2000 条解析后规则；响应仍受 8 MiB 总上限保护。容量超限返回 413，异常来源返回 503，不静默截断。
- 配置包含当前发布序号、版本、交付动作／阶段、服务端签发与设备自报回执时间，以及设备范围内的规则描述。没有 JWS、签名摘要、管理员信息、其他设备信息或虚构的执行效果。能力状态和限制说明属于发布时判断，不能冒充当前系统执行情况。
- 待签发、等待拉取、已提供、设备报告已接收／已保存／已拒绝分别展示。交付过期且没有保存回执、也未被拒绝时显示“过期待拉取”；已经保存的配置不因交付信封到期就被描述为规则失效。移除配置回执同样不证明实际撤销已经执行。
- 前端严格校验字段集合、标识／版本、回执时序、已知状态、配置唯一性与不可变列表。拒绝不一致或自称已执行的响应。现有未部署候选同步更新前后端契约；不能把旧客户端与此新响应混合验收。

## 前端候选

- Material 日期范围、时区、日／周、最多 20 台设备选择；点击生成后才应用新条件，失败重试使用原查询。
- 日期换算复用 timezone 0.9.4（本机已有缓存、IANA 2024a），服务端 Java Time 为数据分桶依据。前端校验实际桶边界与本地时区库一致；规则不一致时拒绝展示，不能静默显示成另一个日期。后续时区库维护仍需纳入升级治理。
- 响应有界读取，校验设备／注册／档案、查询条件、范围、覆盖、状态、桶连续性和日历边界。超过上限或不一致时隐藏结果。
- 设备选择数据在展示前检查设备／注册／档案标识、可读名称和重复设备；异常时显示可重试错误，不打开含有异常数据的选择器。已加载选项保存为不可变列表。
- 丢弃工作空间/角色变化后的异步结果；权限失效关闭本页设备选择和日期弹窗。失权不会通过界面产生额外服务器权限。
- 范围选择支持自由设备、儿童及机构班级；班级名册解析失败时不退回自由设备查询，不自动提交。刷新设备与范围会重新取得名册版本，旧请求重试仍保留原条件。
- 显示授权关闭、无记录、有记录但无应用明细、无证据和可推导范围；时长显示向外舍入，避免缩小范围。
- 应用报告附带当前 classification，精确核对平台／资料／包名，来源只接受 NONE 或 ADMIN_DECLARED。来源、类别、版本和更新时间可见。结果内类别筛选不重新查询，不改变设备覆盖率；无匹配不显示成零使用，未分类仍是独立选项。来源维护和权限见[应用分类契约](application-classification-contract.md)。
- 趋势图按每个应用的日／周桶展示：横条为下界至上界，圆点为汇总值，无证据不画零值；超过 7 个时段可明确展开全部。每行提供完整日期与时长的无障碍文本，手机布局保持可读。
- 趋势仅比较最后两个连续、完整、实际长度相同的时段，差值为 `[当前下界−上期上界, 当前上界−上期下界]`。只有整段差值大于或小于零才判断增减；范围覆盖零时说明无法确定，相同精确值显示相同。未完整时段可展示但不参与比较；最新完整桶缺证据时不跨过它寻找旧数据。夏令时产生的不同长度日／周不直接比较。差值向外舍入并保留两端单位，不能把分钟与秒混用。

## 本设备只读接口与共享 SDK

- `GET /api/v1/device-api/usage-report` 使用当前设备不透明凭据，仅接受唯一的 `from`、`to`、`timeZone`、可选 `period=DAY|WEEK`。设备、租户、档案及范围由认证上下文决定；额外或重复参数拒绝，不接受客户端选择其他设备。
- 在同一事务中重新核对当前档案、设备生命周期、注册周期与有效凭据，再读取当前观察授权。档案 → 设备 → 凭据 → 授权及配置头的锁保持至最终响应容量检查。认证后发生撤权也必须拒绝；关闭使用观察返回 `NOT_AUTHORIZED`，不输出旧用量。
- 响应沿用管理端严格报表结构，范围固定为单设备 `DEVICES`，标记 `Cache-Control: no-store`、`Vary: Authorization`。聚合、分类来源、当前配置交付状态、容量与未验证证据语义完全一致。
- `packages/usage_reporting` 提供纯 Dart 的不可变模型、查询/日历校验、分类、配置交付状态与趋势计算。管理端从此公共包读取模型，API 适配器将 `UsageReportFailure` 转为原有中文错误提示，不保留另一份解析实现。
- `packages/device_reports` 的 `DeviceUsageReportClient(transport, target, current)` 接收宿主当前 `UsageReportTarget`；必须从可信宿主绑定提供 deviceId、registrationId、subjectId 和实际 ANDROID/ANDROID_TV 平台。`load(from:, to:, timeZone:, period:)` 返回已核对绑定的 `UsageReport`；不能直接把 transport 的原始 JSON 展示给用户。
- `current` 必须在身份、前后台可见性或观察访问授权变化时失效。调用 `dispose()` 会拒绝新请求并丢弃在途结果；该客户端不持久化报表、不自动重试、不关闭宿主共用 transport。界面仍需在会话失效时清除已经显示的数据，并以请求代数丢弃被新查询替代的结果。
- 设备请求复用既有 HTTPS/回环限制、每请求取凭据、超时、中止、禁止重定向。报表读取的独立上限为 8 MiB，即使宿主为其他操作配置更大上限也不能放宽；若宿主设置更小上限则遵守较小值。
- 真实 Spring → 生产 Dart 类型客户端已覆盖当前用量和规则，以及凭据撤销后的拒绝。儿童端页面及会话接入见下节；跨语言联通不等同于真机采集或全产品已完成。

## 儿童端本设备页面

- `packages/usage_report_ui` 复用 Material 组件和同一套类型模型，提供设备页面、趋势与配置状态组件。管理端也从此包使用趋势和配置组件，避免两个入口对范围、无证据和设备回执作出不同解释。
- Android 儿童宿主底部“使用”入口仅展示当前设备。进入时读取近 7 个日历日；提供日／周、近 7／14／30 天、自选日期、IANA 时区、结果内类别筛选、可搜索的应用／系统资料选择，以及时段来源和当前规则详情。
- 修改查询条件立即隐藏旧结果，点击“查看报表”才应用新条件。刷新失败不保留过时结果；“按原条件重试”使用原先已应用的起止时间、时区和周期。恢复前台不自动重新展示旧报表。
- `DeviceChildReports` 每次先检查 ChildSession 当前身份、凭据可用性和前台状态，再检查原生设备解锁状态；通过真实设备 access-context 接口取得当前认证档案，核对租户／设备／注册周期，随后使用类型化报表 SDK。平台来自原生检查的 Android／TV 标识，界面不能自由指定设备或档案。
- 请求使用新读取的设备凭据，不使用成人账号。取消、页面退出、身份变化、失权和进入后台会关闭本页网络请求并拒绝迟到结果；已显示结果及日期／时区／应用弹窗随失权关闭。宿主观察授权版本变化会重建本页。报表不写入磁盘或本地缓存。
- 无记录、未授权、有记录但无应用明细、类别无匹配、网络失败及连接失效分别呈现。未知时段不按零处理，设备报告已保存不等于系统规则已执行。服务器版本缺少报表接口时显示明确不可用提示。
- 正常 Web 入口不创建设备报表接收器。独立 `tool/report_preview.dart` 只在显式 `REPORT_PREVIEW_FIXTURE=true` 构建时使用内存身份与隔离接口夹具，不能作为真实设备连接或生产报表证明。
- 真实 Spring → ChildSession → ChildApp → DeviceChildReports → 类型 SDK 的 Flutter 联通旅程已覆盖非空用量／规则和实际凭据撤销后的 401。Android 主入口 APK 构建通过；此证据尚不包含 Android／TV 真机上的报表操作与原生采集。
