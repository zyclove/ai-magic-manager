# 儿童端正式运行链与 Android 联合验收

## 范围与结果

本阶段将儿童端正式入口的身份、签名配置、临时访问上下文、申请、系统观察来源和儿童报表放在同一运行链中验证。`ProductionChildRuntime` 仍是唯一业务工厂；新增的存储端口仅为专用 Android 验收安装提供隔离目录和加密绑定键，不替换签名验证、HTTP、申请日志或服务端业务。

冻结候选以 `6848f8effb6bf0ca6b5714648de08eb4d764a445` 为已提交基线，叠加已审阅的报表源码与本阶段变更。候选共 515 个源码文件；输入清单、每阶段源码摘要、APK 摘要、驱动和构建日志摘要详见 [机器验收记录](releases/stage-child-production-joint-verification.json)。本地原始日志位于 `.local/production-joint-h2-scoped.log`、`.local/production-joint-mysql.log` 和冻结候选的 `backend/.local/android-child-http-*/native-*`，不作为含有运行标识的发布材料。

阶段中的签名密钥由 Spring 测试进程在私有目录生成，仅公开验证环交给 Android；私钥不进入客户端。成人身份与 MFA 使用 Spring 测试夹具，不能据此宣称真实 OIDC 上线。单独中断的首轮 MySQL 尝试只完成 7 阶段，未计入通过结果；该隔离库在确认测试进程退出后核对 V1–V25 并精确删除。其留在专用安装中的键由同一官方驱动补跑该运行标记的 `cleanup` 阶段，复查加密上下文键为零，随后恢复普通 APK。

## 可复核的边界

- 策略是 `CONFIGURE_ONLY`；`systemEnforced=false`。没有 DPC、EMM、锁定任务、跨应用阻止启动、抗卸载或抗强停的系统级证明。
- Android 原生观察来源和应用清单已接通，但 UsageStats 授权与监护人采集同意均未在该旅程打开；本次没有采集、上传或证明真实使用时长。
- 只在一台专用 API 34 调试模拟器验证；尚未验证实体手机、Android TV 厂商差异、设备重启后的系统执行、iOS、Windows 或 macOS。
- MySQL 的独立库和迁移已实际通过；不能外推为 OceanBase 兼容认证或百万设备容量通过。
- 客户端和后端产物可构建，仍需真实生产身份提供方、设备管理资质、区域隐私门槛、容量和故障演练后才能发布。

下一阶段应先完成明确的监护人授权与设备特殊访问引导，再在可撤回授权下验证真实 UsageStats 采样、上传与报表闭环；机构受管模式需单独通过 EMM/DPC 资质与设备矩阵验证。
