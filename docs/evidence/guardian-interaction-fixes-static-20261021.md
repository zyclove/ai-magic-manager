## 修复内容

| 问题 | 源码处理 |
| --- | --- |
| 同租户重新读取成员身份，角色变化但仍能进入同一列表时，旧 Key 和恒定 API 实例不能撤下原权限范围的记录 | 通用资源入口按路径、账号、租户根路径、角色和会话代际绑定 Key；变化后创建新列表。读取使用捕获的原作用域，并接入现有 API 在等待认证、请求派发和响应后的检查；迟到结果不能写回旧列表 |
| 列表作用域失效或服务端返回 WORKSPACE_CHANGED 后仍可能保留旧数据、旧按钮回调 | 失效视图隐藏记录；清除失效响应对应的记录和游标；操作入口及异步返回后核对原作用域，不刷新或操作新范围 |
| 手机顶栏按屏宽减固定常数分配工作空间下拉宽度，遗漏快捷按钮所需空间 | 窄屏下拉采用 Expanded 和 Align 接收行内实际剩余约束，移除固定减法和多余 Spacer。保留桌面布局、280 宽度上限、按钮触摸目标；名称单行省略 |
| 导出请求未返回且权限已失效时，界面提示关闭但关闭按钮和返回仍被禁止 | 只在“忙碌且当前作用域有效”时阻止关闭；失效立即可退出。绑定原仓库、查询和变化通知，永久记录失效，迟到成功或权限恢复不触发旧回调；安全验证继续要求明确点击 |

沿用现有 Flutter Material、API 作用域检查和请求标识机制，没有新增依赖、自动重新提交或真实业务写入。代码未部署，当前服务不包含本阶段修复。
