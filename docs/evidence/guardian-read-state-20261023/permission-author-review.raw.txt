## 状态表达

| 输入 | 候选展示 | 约束 |
| --- | --- | --- |
| 父 inventoryEnabled=null | 应用清单授权状态未知；引导刷新上方观察状态 | 不再提示已关闭或先开启；没有新增父参数/刷新回调 |
| 父 inventoryEnabled=false | 保留原“先开启应用清单授权”与原操作引导 | 仅已知 false 进入该分支 |
| 父 true，独立 settings=null，busy=true | 正在确认权限观察授权，请稍候 | 覆盖首次读取和授权更新等待，不声称已关闭 |
| 父 true，独立 settings=null，busy=false | 权限观察授权状态未知；引导“刷新权限状态” | 读取失败保留既有 error/适用重认证入口，不补造 false |
| 父 true，settings.enabled=false | 保留原“权限观察尚未授权”文案 | 仅已知 false 进入该分支 |
| 两授权 true，inventory=null，busy=true | 正在读取可见应用 | 父 false→true 会清 inventory 并 load，旧 settings=true 也不会误显示空成功 |
| 两授权 true，inventory=null，busy=false | 可见应用清单状态未知；引导“刷新权限状态” | 不用空列表替代尚未读取到的对象 |
| 两授权 true，成功读取 inventory 对象、applications真实空 | 保留原“暂无可选应用”及“空列表不表示没有安装应用” | 不把 empty/UNKNOWN evidence 解释为没有安装应用 |
| 两授权 true，inventory对象非空 | 原选择/读取/设备代理证据内容 | 原结果、分类、授予标志与未核对系统执行的说明均不改 |

Panel顶部 settings=null 同样区分 busy“正在确认授权状态…”与非busy“授权状态未知”；已知 false 改为准确“已关闭”，不再把任何已知false状态一概说成“默认关闭”。仅使用状态文字和 EmptyView，没有叠加新的 Notice 警告。
