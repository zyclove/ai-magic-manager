## 依据

本机 Flutter `widgetWithText` 调用 `byType`；后者按精确运行时类型匹配，不包含子类型。带非空 icon 的 Material 按钮工厂生成相应私有子类。标准 `bySubtype<T>()` 已由当前 SDK 提供，不需要新增 helper、依赖或查找框架。

`DiagnosticPreviewView` 的刷新按钮为 `FilledButton.icon`。原失权检查只遍历精确 `FilledButton`，可能没有检查到该刷新按钮。诊断包隐藏断言以及预览页面的只读断言也应覆盖图标按钮子类型，才能表达原本的“没有该类按钮”意图。

这证明静态匹配覆盖不足，不证明产品当前保留了可用的越权按钮。视图正确销毁或隐藏时，零按钮是合法结果；候选没有强制增加数量断言，也没有改变权限逻辑。
