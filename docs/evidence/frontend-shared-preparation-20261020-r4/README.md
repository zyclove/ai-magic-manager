运行入口哈希只固定 Python、Dart、Flutter 工具快照和 Chrome 四个文件。它们不构成整个 SDK、引擎及 Pub 缓存内容的冻结。依赖解析元数据也不是依赖源码哈希。后续分析、测试与构建之前，须固定并复核实际解析出的依赖内容，不能只因原生命令返回 0 就宣布完整验收。
