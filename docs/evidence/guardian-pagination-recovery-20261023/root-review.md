# Root review: catalog, contract and help pagination recovery

Root read the original list loaders and UI recovery entries, both complete proposed patches, the Help after source, author pins and both independent reports. The changes cover two concrete static findings over three production files. No application compiler, formatter, analyzer, test, browser or rendered layout was run.

Catalog and contracts now retain the actual failed read mode. Each new read and successful result clears the corresponding old error and mode. A retry checks mounted/current, the current error and both loading states before using that mode; it cannot silently change an append retry into a first-page refresh or issue another read after success. Append is blocked while a first-page load is pending. Explicit and write-triggered first-page refresh retain the original generation replacement semantics, so the concurrency guard does not discard necessary write-after-read refreshes. Current identity, scope, details, history and write protocols were not changed by these patches.

Help append failures have a separate pageError. Ordinary retry retains the cursor and accumulated rows, and no longer clears an unrelated acknowledgement error or the uncertain-result set. The original fresh-success clear remains unchanged; no complete solution to all existing fresh-read/acknowledgement races is claimed. A known rejected cursor is cleared and offers an explicit guarded refresh with one notice. Held retry/refresh callbacks check their current failure state, loading and permission; a first-page refresh replaces an older append through the original generation checks. The append error UI retains its 401 reauthentication action. The acknowledgement method, item version, scope and row action guards remain byte-identical.

Both independent reviews found no static blocker in these fixed candidates. Root also checked the complete patch contents against the requested failure paths. Existing route, confirmation and concurrency behavior outside these deltas is not certified by this source review.
