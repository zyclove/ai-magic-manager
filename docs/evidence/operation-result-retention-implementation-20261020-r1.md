## 本阶段的流程简化

查看当前策略、请求或审计属于只读核对，**不要求先清理本机待办，也不为查看额外弹出清理确认**。终态页面直接提供有权限的当前记录入口，继续保留原终态待办；另有独立的“结束本机核对”动作，用户明确确认一次后才原子清除敏感恢复内容并保留防重标记。这次确认不取消远端业务，也不自动创建新的预览或请求。

此安排取代上一阶段 Guardian 设计中“清理并查看”绑定在一起的步骤，减少核对所需操作，并把只读查看和本地清理的含义说明清楚。

R4 是前一阶段已有交互的静态准备材料。它的清单、规格、执行器和审阅记录保持原字节；新生产源码修改后，R4 的 Main 哈希不再描述当前实现，不得执行旧规格来认证新代码。待本阶段来源稳定后另建完整新候选。

本阶段不运行 SDK、格式化、分析、测试、浏览器、构建、服务或数据库操作。现有假实现如需适配接口，仅按明确的新类型和终态协议接合，不增加测试声明或移除原断言；Parent 八处既有期望调整逐项保存。静态审阅不能证明事务、IndexedDB、并发或真实设备行为已经通过。

新读取截止逻辑要在全端终态协议和后端验证完成后才能部署；只关闭物理清理作业不能避免读取行为变化。当前运行服务和数据库不接入这些未验证改动，物理清理默认保持关闭。
