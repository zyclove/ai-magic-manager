# 受管应用控制证据：实施计划

基线：`2acf8d8`。属于完整执行链路第 2 步，目标是将可信的逐应用控制证据从提供方读取、校验、持久化到策略预览，随后由发布与写入准入复用。只有身份签名的旧证据继续保持不可执行。

## 证据来源与语义

- 新增服务端 `ManagedApplicationControlReport`，包含同一提供方观测中的应用身份报告、设备事实、明确用户空间及设备厂家/型号/系统构建标识。此对象不接收儿童客户端上传，也不增加请求体中的“已认证”开关。
- 提供方通过 Gateway 显式声明报告读取能力和解释版本。支持时一次读取完整报告，并在读取前后继续验证现有注册身份；不将两个可能来自不同应用实例的独立报告简单合并。
- 部署中以受信 Spring Bean 提供经过验收的 `ManagedControlQualification`。资格严格匹配提供方、报告适配版本、编译器版本、厂家、型号、系统构建、API 级别和管理模式；包含验收引用、版本、有效期间与逐操作集合。默认空目录，未验收的型号不能因 API 级别足够而自动通过。
- 逐操作区分应用启动允许/拒绝、安装允许/拒绝及具体运行时权限的拒绝/恢复询问。不会使用一个布尔值授权所有操作，不支持自动授予运行时权限。

## 实施顺序

1. 先建立报告、资格和操作契约，增加失败用例，实际执行后再实现校验。校验覆盖身份、注册上下文、PRIMARY 用户空间、设备事实时效、精确型号/构建、资格撤回/过期、适配版本和操作范围。
2. 使用现有应用证据刷新接口和前后事务/CAS 边界。增加可空控制证据文档字段；旧提供方继续使用现有身份报告路径。刷新失败、重新注册或授权变化均清除或拒绝旧控制能力。
3. 读取时重新校验当前配置、绑定、应用定义及有效期；预览仅使用本地持久证据。对外返回最小操作集合和用户可理解的状态，不返回提供方资源、密钥、原始硬件报告或验收内部资料。
4. `RuleCompiler` 只对证据中明确包含的应用操作给出 `SUPPORTED_PENDING`，仍不设置有效效果。保留安全应用、平台、日程、管理模式及自动授权限制。未获证明的控制继续明确拒绝。
5. 实际 HTTP/数据库回归覆盖刷新→读取→预览，跨租户、权限撤回、重注册、错型号、错用户空间、报告超时、资格变化、重复刷新及过期。继续验证已有 661 项及相关绑定/预览回归。

## 分工与数据迁移

`PolicyService.java` 和 V1 正由协作任务持有。本阶段先提交精确数据库接合片段并协调后实施，不覆盖家庭业务改动；发布入口保持现状，直到执行准入、资源归属及写入编排全部接通。当前 V1 是未发布基线，不能据此宣称已部署数据库可直接升级。

拟拥有文件：新增公开契约及内部资格校验类；修改 `ManagedAndroidGateway`、`ManagedApplicationEvidenceService/Store`、`ManagedPolicyEvidenceAccess`、`RuleCompiler` 及对应测试；数据库片段单独交接。客户端展示由管理端任务接入，先保持已有字段兼容。

最小数据库接合提案：在 V1 的 `managed_application_evidence` 表中，`signing_digests_json` 后增加可空字段 `control_evidence_json TEXT`。不修改既有键、状态枚举或家庭表。应用层限制文档 UTF-8 大小至 16 KiB 并严格解析，避免扩大 MySQL 行内 `VARCHAR` 容量；真实 MySQL/OceanBase 验证仍另行执行。清除/重新刷新身份事实时同时清除此字段，沿用现有绑定级联删除和保留流程。

同时需要在 `retention/subject-data-stores.json` 的 `managed_application_evidence.columns` 中登记 `control_evidence_json`，保留 `DERIVED_COPY` 分类。该清单也有协作中的改动，必须与 V1 一并交接最小片段，不能整文件覆盖。

存储文档记录报告与当前资格版本，读取时必须重新验证，不能把 JSON 存在视为有效证明。受控资格目录和编译器版本加入上下文指纹，使型号资格、提供方解释或编译语义变化立即使旧事实失效。现有身份-only 状态保持兼容；新增的最小逐操作列表只描述可尝试执行的范围，不能代表已执行。

## 完成条件与剩余工作

本阶段完成需有实际端到端预览证据及对失败路径的回归结果，不以只有接口定义或纯函数测试作为整阶段完成。生产资格目录仍须由真实合作方验收后提供。完整产品还需要发布事务、执行资源归属、远程写入/分配与真实 Android/TV 验收；这些任务继续保留在完整执行链路计划中。
