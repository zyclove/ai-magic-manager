# 1.0.0 初始化与开发约定

2026-10-11 用户明确要求：目前尚未上线，不考虑历史兼容和数据迁移，按照 1.0.0 初始化和开发。该约定覆盖此前按 V22、V29、V30 等开发阶段进行升级兼容的安排；历史验收记录仍是当时构建的证据，不作为首版的升级承诺。

## 版本

- 后端 Maven、管理端、儿童端、内部 Dart/Flutter 包、Helm Chart 统一为 1.0.0；应用构建号可独立递增。
- 第三方依赖、数据库/Keycloak 镜像、协议 schemaVersion、凭据版本、业务乐观锁和策略版本有各自含义，不随产品版本改成 1.0.0。
- 商业目录、报表、诊断等既有功能直接进入首版基线。整理初始化结构不能以丢失已有功能或约束换取简化。

## 全新数据库

继续使用已有 Flyway 执行全新建库、校验初始化文件及防止重复初始化：

1. `db/migration/V1__initial_schema.sql`：完整业务表、字段、索引和约束。
2. `db/vendor/{mysql|h2}/V2__event_publication.sql`：Spring Modulith 事件发布表的数据库适配。

这两个顺序号是同一次首版建库的脚本执行顺序，不是两个产品发布版本。旧的逐阶段 SQL、历史数据回填及升级专用测试已合并或移除。新增字段/表在首版尚未发布期间直接更新初始化基线及存储清单。

受管 Android 的企业绑定、绑定事件、注册意图和意图事件也直接属于 V1；开发中新增的 V3/V4 建表已原样并入，不作为首版升级链保留。初始化回归同时检查这些表及注册清理字段。

权限观察设置、应用权限快照、速率记录及受管注册的供应方到期扫描索引同样直接属于 V1。公共目录新增的 V2 索引脚本曾与数据库事件表 V2 重号，已合入基线并移除增量文件；全新初始化检查三张空表和三个索引。权限观察的 23 列已人工分类到删除覆盖清单，三个存储纳入观察域处理器，见 [实施计划](permission-observation-initialization-plan.md)。权限观察开关仍默认关闭，初始化和删除验收不代表设备采集、授权交互或部署已完成。

初始化面向新的空业务数据库。已有本机开发库不由构建或初始化脚本隐式清空，也不提供原地升级到此基线的承诺。需要新的开发环境时使用独立数据库或独立 Compose 项目；身份服务数据库与业务数据库保持分离。

工作台汇总所需的主体归档、设备心跳和待审批请求三个组合索引同样进入 V1，不保留独立 V3 升级脚本。初始化检查核对其索引列顺序；该整理不更新既有运行库，也不改变工作台查询逻辑。

## 初始化与验证

从空环境按 `scripts/initialize-deployment.ps1` → `scripts/build-deployment.ps1` → `scripts/initialize-erasure-ledger.ps1` → `scripts/start-deployment.ps1` 创建、构建、显式初始化独立账本和启动，具体凭据与身份初始化参见部署手册。账本初始化只执行一次，普通重启不得重建。构建产物带有 `applicationVersion=1.0.0` 的清单。

验收覆盖全新 H2/MySQL 初始化、再次启动不重复建库、完整表/列清单、模块边界及业务流程。删除前检查覆盖清单不能代替业务测试；H2 成功不能代替 MySQL、OIDC、设备与外部服务的实际验证。

## 数据删除与备份恢复

取消旧版本数据升级迁移，不取消产品所需的隐私删除和灾难恢复能力。已接受删除的数据在恢复备份后不能再次公开，这是主体删除功能的要求，与版本兼容不同。

当前数据删除模块仍在开发：已实现存储清单、前置检查和短期准备；独立账本的持久化与读取检查见 [账本实施记录](erasure-ledger-plan.md)，持久恢复作业和租约见 [恢复作业实施记录](erasure-recovery-jobs-plan.md)，运行期全局工作许可与排空保护见 [运行期许可实施记录](erasure-runtime-admission-plan.md)。观察数据、审批/额度/通知、支持授权/诊断及设备身份附属数据的内部域处理器已实现，分别见 [观察数据处理记录](erasure-observation-plan.md)、[审批、额度与通知处理记录](erasure-access-quota-plan.md)、[支持与诊断处理记录](erasure-support-diagnostics-plan.md)和[设备身份处理记录](erasure-device-identity-plan.md)。正式删除提交、目标级隔离、完整处理编排、完成判定、安全许可回收及管理端交互尚未完成，不应显示为可执行删除。源码阶段验收不代表现有运行服务已经更新。
