# 管理端短信与微信：受控发布、生效核对与回退

本页延续“短信与微信”的两张配置卡，增加一张“发布与生效”卡。普通家庭导航与登录入口不增加工程操作。

配置编辑、发布、回退和实例核对分别授权。仅有编辑或联调权限不能发布或回退；发布管理员可以自动读取当前配置最新的已准备记录，无需同时取得编辑权限。

## 日常流程

1. 配置管理员保存并检查短信与微信配置，再生成发布准备。
2. 发布管理员刷新本页，查看自动读取的配置准备，选择“发布此配置”。确认窗口展示明确版本、环境和正式产物，填写安装包及身份扩展产物摘要后确认。
3. 卡片显示“等待部署执行”。受限执行器领取任务并部署，页面不自动重启任何服务。
4. 任务允许核对时，联调管理员选择“核对生效状态”。服务器向固定身份实例获取新鲜进程证明，全部核对后才显示“配置已加载，登录入口待验收”。
5. 继续完成正式签名真机、真实短信和微信授权等联调清单。配置加载确认不会开启消费者登录或购买。

发布期间的“最近确认配置”是历史事实，页面突出“当前部署待确认”，不把历史记录当作当前实际配置。

## 回退与恢复

“回退到已确认版本”只展示服务器允许的历史候选。先选择版本，再查看回退影响，最后确认创建新操作。草稿和账号数据保留，回退仍需部署执行和全部身份实例核对。

尚未被执行器领取的任务可以明确确认后取消。已开始或结果未知的任务不能在界面取消，也不能被另一个发布或回退覆盖。

如果提交后掉网，页面先提示“核对原操作”。浏览器只保留操作类型和随机编号，通过查询原编号恢复，不重新发送配置、发布、回退、取消或实例探测。仍在进行的原检查继续查询同一记录，终态确认后才解除待核对状态。账号变化会关闭确认窗口，状态刷新失败会禁用失效的发布操作。

## 交付边界

界面与受控发布协议的自动测试使用合成资料。真实部署、生效确认和回退还需要受限执行器、固定实例清单、独立机器密钥及正式产物；真实短信送达、微信授权、账号恢复和收费验收分别完成。

技术字段与权限见 [受控发布合同](superpowers/plans/2026-10-17-provider-runtime-contract.md)，原配置准备见 [管理端配置说明](family-identity-provider-admin.md)。本轮最终回归与产物哈希由交付记录单独列出，不用历史通过数替代当前源码验证。
