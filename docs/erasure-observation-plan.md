# 1.0.0 使用观测与报表副本删除处理器

承接主体删除契约及运行期排空屏障，本阶段实现真实数据处理，不开放尚未闭环的正式删除按钮。沿用 Spring JDBC、业务事务、独立账本和现有 fencing 租约；所有结构直接进入首版初始化。

## 处理范围与原子性

- 处理 `usage_report_jobs`、`usage_report_parts`、`usage_observation_batches`、`usage_observation_heads`、`application_inventory_snapshots`、`device_observation_settings` 六个存储。其他域、审计、通用幂等、事件、诊断和外部副本仍由后续处理器覆盖；本阶段完成不代表整份主体删除完成。
- 每批重新核对业务作业租约及独立账本的不可变接受记录，锁住作业行后在同一业务事务清理数据、更新步骤检查点；提交前再校验租约。失联、过期或范围不一致全部回滚。
- 以账本中租户、主体和不可变设备注册代际作为范围。当前属于目标的注册、报表历史中的目标注册必须包含在已接受范围中；同一代际出现其他主体绑定时拒绝。重新注册后的其他主体设备不按旧 device ID 擦除。
- 报表按任务 ID 有界扫描，核验选择摘要、设备集合、分片数量和注册归属。含目标主体的一份共享报表连同全部分片删除，其他主体的原始记录保留；现有任务缓存可重新生成，不能留下包含已删主体的旧副本。
- 观测记录通过租户、设备和注册三元组选择，先读取最多 25 个主键，再按完整条件删除；不会仅按当前设备列表或宽泛字符串匹配删除。
- 步骤保存处理器版本、阶段、非个人内容的扫描游标、累计删除行数及批次计数。报表每批最多 25 个任务、每任务最多 200 个分片；观测每批最多 25 行。步骤完成不推进任何全局已应用水位、不开放业务流量。

## 验收

- [x] 失败用例、带 fencing 的原子批次和首版步骤结构。
- [x] 六个存储的真实清理、共享副本、历史代际、他主体/他租户隔离及可重复执行。
- [x] H2、独立 MySQL、全新初始化/目录覆盖、全后端回归与一次最终复核。

Ruling：删除包含目标的一整份共享报表，而不修改其中某个已签发片段 — 报表选择、摘要和完整性绑定需要整体失效，其他主体的原始数据保持可重建；代价是同份缓存中的其他主体片段需要重新生成。

Ruling：使用已接受账本范围执行内部处理器，不从用户输入接收 SQL、表名或任意处理器标识。正式受理、用户确认、保留政策、目标级隔离与完整完成判定继续按主体删除契约推进，不能用本步骤替代这些要求。

Ruling：将同期已提交设备组的 V3 建表内容合入 V1 并移除 V3 — 用户明确要求首版全新初始化、无历史迁移；同时将组定义归为 SHARED_CONFIGURATION、精确注册成员归为 DEVICE_DATA。组名称可能含个人引用，不能将其分类为无关数据；本阶段观测处理器不删除组定义或成员，后续设备/共享配置处理器必须覆盖。

## 验证过程

- 批次原语缺失时 6 项失败；补齐事务后通过。处理器缺失时 11 项失败；首轮实现只有重复调用应返回本批删除 0 行的测试预期不当，修正为同时检查累计行数、批次数不变及本批 0 行。
- 新增“回调途中独立账本身份改变”用例先复现未拒绝提交；修复为执行前、提交前均核对接受记录，并在最后检查数据库时间租约。
- 集成 H2 定向回归 67 项全部通过：处理器、批次、既有恢复作业、前置检查、准备、空库初始化和模块边界。包含真实等待使 5 秒租约在事务中到期、并发处理、不同租户相同标识、历史/新注册代际、检查点写入失败回滚、未知结构及计数耗尽。
- 独立 MySQL 处理器/批次/恢复作业 42 项全部通过；单独新空库初始化 1 项通过，两步初始化且再次启动执行 0 条建库脚本。所有专用临时库及账号已清理。
- 同期设备组旧增量脚本在最新已提交版本快照中触发首版断言 `expected 2, actual 3`；合入 V1 后 H2/MySQL 初始化均通过。已有开发库未升级或清空，现有 18099 运行服务未替换。

- 最终完整后端回归共 643 项，635 项通过、8 项条件跳过、0 失败、0 错误；单次最终只读复核未发现可复现 P1/P2。复核的 8 个源码文件与最终验证源码逐一核对一致，删除的 V3 基线内容也已核对。
- 全量运行中的 TenantJourneyTest 报告耗时 5773 秒，31 项均通过；耗时异常原因尚未确认，不能据此作性能结论。本次进程正常结束，未因观察超时重启。

上述初始化验证不等于新增设备组 API、权限或浏览器流程验收；设备组功能的独立证据仍以其契约为准。完整后端基于 `710c5eb` 加本阶段源码的冻结快照，客户端互操作使用已有冻结夹具；同期后续提交及未提交改动不在此次验证范围。结果与源码摘要见 [阶段验证记录](releases/stage-erasure-observation-verification.json)。本批为源码阶段完成，尚未部署，不表示整体主体删除或全部产品功能完成。
