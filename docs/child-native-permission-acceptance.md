# 儿童端原生应用权限观察验收

更新：2026-10-14。此阶段验证 Android 儿童端的应用权限观察链路：监护人独立授权、设备读取自身已安装应用的权限事实、儿童端上报、监护人 API 查看，以及撤回后的设备清理和服务端删除。该能力用于透明的设备安全诊断，不授予或修改其他应用的系统权限。

## 产品流程

监护人先在设备详情中单独开启“应用权限观察”。该授权与应用清单、使用时长授权分开保存并分别版本化。儿童端刷新授权后才显示可观察的应用；设备只读取 Android PackageManager 能提供的权限声明和状态，并提交最小快照。监护人可以查看数据新鲜度、证据来源和权限事实；撤回授权后，设备停止扫描、清除本地快照与待提交报告，服务端同步删除已有快照。

儿童端仅展示当前授权状态及受限原因，没有策略修改或授权管理入口。应用权限观察与 UsageStats 特殊访问彼此独立；本验收在关闭使用时长采集时完成了权限快照上报。

## 验收结果

| 环节 | 结果 | 证明范围 |
| --- | --- | --- |
| 管理员授权 | 通过 | 监护人 API 独立开启权限观察，版本从 0 增至 1；设备只在刷新到已授权状态后读取 |
| 原生读取和上报 | 通过 | 专用 Android 34 模拟器上的正式 Flutter 组合调用 PackageManager，读取 `com.aimanager.child.debug` 并经真实 HTTP 提交 |
| 管理端读取 | 通过 | 后端受监护人身份和设备范围保护的读取接口返回 RECENT；证据标为 `AGENT_REPORTED_UNVERIFIED` |
| 权限撤回 | 通过 | 管理员将授权版本从 1 增至 2；重启应用后设备清空本地结果、不再生成报告，服务端删除快照并返回 NOT_AUTHORIZED |
| 授权隔离 | 通过 | 撤回权限观察后，应用目录授权仍有效，使用时长授权仍关闭 |
| 既有设备旅程 | 通过 | Android 注册、正式配置、应用清单和使用摘要、提交/恢复、取消后恢复、到期、离线、凭证撤销、策略阻止和清理等阶段均通过 |

本次基础调试包的实际权限样本只有 `android.permission.INTERNET`，其分类为 OTHER、授权状态为 UNKNOWN。测试没有伪造相机、位置或其他危险权限，也没有授予这些权限。清单事实由设备代理报告，服务端不会将其误称为 Android 系统已认证证明。

## 隐私与执行边界

- 这是“读取并展示权限事实”，不是远程授予、撤销或拦截其他应用权限；Android 普通应用不拥有这些系统级控制能力。
- 不读取或保存其他应用数据、屏幕内容、视频或音频；本阶段不启用摄像头、面部识别或行为推断。
- 设备包名用于选择单个应用；服务端读取需监护人身份和设备范围授权。撤回后删除服务端快照；离线设备在下一次联网同步撤回状态前，无法即时接收新策略。
- `AGENT_REPORTED_UNVERIFIED` 表示设备代理上报，不代表设备完整性证明、硬件背书或不可伪造证据。设备被篡改、系统不返回完整清单等情况需在产品界面展示为证据限制。
- 适配非 Android 平台时，必须重新评估对应系统 API、应用商店规则和权限边界，不能复用 Android 能力声明。

## 验收环境与复核

使用独立 Android 34 AVD `AIManagerPermission20261014`、标准 `com.aimanager.child.debug` 调试安装、Spring Boot 集成测试服务和临时 H2 内存库。验证期间不连接业务数据库，不更改共享模拟器、设备全局设置或 Docker 服务；runner 校验 AVD 名称、包 UID 和首次安装时间，并在结束时删除本次临时设备测试资料。

复核入口：

- JUnit：`backend/src/test/java/com/aimanager/AndroidChildSubmissionJourneyTest.java`
- Android runner：`apps/child/tool/run_submission_android.py`
- 设备端原生集成：`apps/child/integration_test/production_http_test.dart`
- 申请和恢复集成：`apps/child/integration_test/submission_http_test.dart`

最终回归结果：Maven 1 个旅程测试通过，15 个阶段全部完成，0 失败，运行时间 22 分 23 秒。Android 模拟器和后端服务时钟实测相差约 4.7 秒，因此到期时间的设备侧邻近断言采用 10 秒容差；服务端 `EXPIRED` 状态、原始绝对截止时间、撤销和防止离线延长等断言保持不变。

## 后续产品化事项

1. 在监护人页面提供单独授权说明、扫描范围、最近同步时间、上报证据等级和一键撤回；儿童页面说明收集目的与状态。
2. 对未授权、授权撤回、系统 API 不支持、清单过大、设备离线、报告过期和部分读取分别呈现可理解状态，不将未知状态显示为“安全”。
3. 限定快照字段、保留周期、审计用途和儿童/监护人数据导出删除流程；通过隐私评审后再扩大采集范围。
4. 在真实厂商设备及不同 Android 版本做兼容验收；模拟器结果不代表所有 ROM 或电视设备能力。
5. 增加自动化 UI 验收，验证监护人撤回操作、儿童侧说明和失败恢复的可用性；本阶段端到端测试验证 API 与设备链路，不代表生产部署或商店审核已完成。
