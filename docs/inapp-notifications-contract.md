# 站内审批通知

## 用户操作

管理端顶部铃铛与“通知中心”导航进入当前工作空间的个人收件箱。顶部每分钟刷新一次未读数量，页面恢复前台和已读操作成功后也刷新；同步失败显示不可用提示，不把故障显示成零未读。

支持全部/未读筛选、每页 20 条、上一页/下一页/返回首页、逐条已读与“将本页标为已读”。后者只处理当时明确选中的未读通知，网络重试仍使用相同 ID；不会把后来到达的新通知一并标记。已读状态属于个人，不改变审批或其他成员的阅读状态。

“查看当前申请”先标记这条通知已读，再读取最新申请与交付状态。通知正文是发生时的事实，旧批准通知打开后可能已经撤销或失效。批准不表示设备已执行；设备回执和执行状态仍由申请详情单独显示。工作空间或角色变化后隐藏旧通知及已打开申请详情。

## 权限与隐私

- OWNER、GUARDIAN、ORG_ADMIN：当前工作空间内、当前主体授权范围内的审批通知。
- CHILD、TEACHER：还必须是本人提交的申请，并满足当前主体/班级授权。AUDITOR 不提供此处理入口。
- 每次服务端读写都核对数据库内的当前成员事实；界面角色只用于导航，不授予权限。
- 通知只存申请、主体、设备标识、版本、状态、发生时间与申请人不可逆键。用户响应不含申请人键、私人理由、邮箱、原始 OIDC 身份或令牌。
- 后加入的有权管理员可看到保留期内的历史事实；范围丢失后不再可见。按当前范围投影，未向全部成员复制申请正文。

## HTTP 契约

路径前缀为 `/api/v1/tenants/{tenantId}/notifications`，使用已有 Bearer 登录和当前成员授权。已读属于个人偏好，不要求修改审批所需的近期 MFA。

| 方法与路径 | 输入 | 输出 |
|---|---|---|
| GET 前缀 | `limit` 默认 20、1–50；`cursor`；`unreadOnly` 默认 false | `items`、`nextCursor` |
| GET `/unread-count` | 无 | `count` 0–1000、`capped`；超过 1000 时显示 1000+ |
| PUT `/{id}/read` | 规范小写 UUID | `id`、首次 `readAt` |
| POST `/read` | `{"ids":[...]}`，1–50 个、不重复 | `items`，每项 `id`、首次 `readAt` |

列表项字段：`id`、`requestId`、`subjectId`、`deviceId`、`requestVersion`、`state`、`occurredAt`、`readAt`。时间均为 UTC epoch 毫秒，未读的 `readAt` 为 null。

状态来自真实申请枚举：PENDING、APPROVED_PENDING_DELIVERY、DENIED、CANCELLED、EXPIRED、REVOKED、INVALIDATED。按发生时间和通知 ID 倒序，游标绑定两个排序字段；新到达记录通过刷新首页读取。收件箱和未读总数是独立读取，发生并发处理时不承诺两者来自同一个数据库快照。

批量操作先按固定顺序锁定并核对全部通知，再写个人已读状态。混入一项跨空间/失权 ID 会使整批失败。成功重放保留首次阅读时间。没有无界“全部已读”、删除历史申请或修改审批决定的副作用。

## 持久化与升级

V21 创建 `notification_events` 和 `notification_reads`；每个工作空间/申请/版本唯一。申请状态、审计及精简通知在同一领域事务内完成；事件重放读取已提交的最新记录，避免 MySQL REPEATABLE READ 旧快照导致误判。

V21 仅为存量申请的当前版本回填一条事实，保留原更新时间，不补造已经缺失的中间状态。默认保留 30 天：`INAPP_NOTIFICATION_RETENTION_DAYS` 可设置 1–365；定时任务每 300 秒处理最多 100 条，可配置开关/间隔/批量，批量上限 500。删除通知会同时移除对应已读记录，申请与审计历史保持独立。

## 本阶段证据与边界

- 完整后端 269 项、零失败/零跳过；含四项真实 Spring/Dart HTTP 互通。
- 最终管理端 70 项、静态分析无问题、HTML release 构建通过。
- 真实 MySQL 通知 13 项与教师 11 项联动通过；另在独立库验证完整 V1–V20 非空升级到 V21、再次迁移不重复。
- 桌面 1440×1000、手机 390×844 浏览器隔离响应流程覆盖已读原样重试、旧批准打开当前撤销申请、分页、未读空态、服务错误、撤权、审计角色禁入。隔离操作不计作真实业务写入。
- 执行记录、源码/产物指纹、独立审阅及运行更新见 [实施计划](inapp-notifications-plan.md)。邮件、短信、系统移动推送、其他安全通知与真机控制效果属于后续产品范围。

验收日志保存在忽略目录 `.local/notification-*`，凭据仅位于本机忽略运行目录，文档和浏览器输出不记录密码或令牌。
