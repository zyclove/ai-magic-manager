# 儿童端临时访问接入实施记录

承接 device_access、儿童身份/基础配置宿主及有序 V20 交付。完整目标包含接收、恢复、状态界面、原期限刷新、撤回与设备生命周期、设备申请入口和经认证的系统执行；这些步骤逐段验收，不把组件保存等同于真正解锁。

## 产品与实施顺序

1. 可信上下文：独立设备凭证读取租户/档案/设备/注册绑定，禁止从未验证 JWS、粘贴内容或 UI 输入推导档案；不开放成人资料或编辑入口。
2. 本地持久化：复用 Sembast 事务、PointyCastle AES-GCM 与 FlutterSecureStorage 密钥保护。加密密钥缺失、错误、记录损坏均明确失败并保留数据；禁用 Sembast 默认 neverFails 清空恢复。
3. 儿童宿主：基础配置重新验签后同步临时配置，精确匹配版本/应用/规则；设备身份失效停用缓存，前后台/原截止刷新，不无限延长或后台隐蔽采集。
4. 交互：沿用既有儿童设计。区分已保存/待确认/已失效/需要处理，显示实际原截止、错误恢复与配置模式；禁止儿童改变授权、密钥、服务地址或系统执行声明。
5. 真实检查：组件 RED→GREEN、文件库重开/损坏、Spring/Dart HTTP、儿童完整回归与原生构建；最后专用设备流程和可视交互，按证据分别报告能力边界。

## 决策

- Ruling: 设备档案通过认证只读 access-context 获取 — 现有 DeviceIdentityView 没有 subjectId — 成本是部署需要同步支持新端点，缺失时停止访问接入。
- Ruling: 使用成熟库提供的 AEAD 与事务，不自研加密算法/日志协议 — 访问文档含儿童关联范围及时间，需防明文落盘 — 仍不承诺 root、防回滚、断电和硬件不可导出。
- Ruling: 打开库显式 DatabaseMode.create，损坏时抛错 — Sembast 3.7.2 默认 neverFails 文档明确可删除损坏库 — 不允许为让检查通过而重建用户记录。
- 当前先完成上述必要前置，再接宿主/界面；通知/V21 由并行任务维护，不修改其文件或迁移。

## 宿主阶段实施顺序

1. SDK 增加签名记录只读状态快照（保存/待回执/拒绝/基础变化/到期/撤回），并在同步结果中提供已观察请求 ID，避免界面把旧记录误当新授权。
2. 可信上下文通过已有 Android 安全存储保存，绑定安装服务/签发者/设备身份。联网核对前先持久化 CHECKING；只有完整验证结束才恢复 VALID，明确拒绝或中断保持不可离线使用。首次上下文请求暂时离线且原记录 VALID 时可恢复原记录，不延长截止。
3. 单个儿童访问宿主拥有数据库和网络生命周期；每轮重新验签基础配置，匹配策略/版本/应用/规则。单请求问题持久保留为待核对，成功重新观察才清除；401/403 等整体身份问题停用全部旧状态。
4. 接入 ChildSession：身份变化关闭旧范围，后台取消网络/到期刷新，回前台先隐藏旧画面并恢复/核对；前台定时按原截止重读本地状态，不自动重发业务命令。
5. 规则页面增加临时访问区：状态、原截止、同步与续页、可解释失败、只读详情；沿用 ChildNotice/Material 焦点和大字设计。设备申请专用授权另行实现，不能用设备凭证冒充成员。
6. 真实签名/文件、终端恢复、会话生命周期、窄屏/大字/遥控键交互、原生构建与跨进程存储验证；冻结验收后阶段提交。

Ruling: 中断同步后的 CHECKING 不自动恢复离线授权 — 网络中断前可能已看到撤回/不一致证据，不能丢失诊断后恢复旧状态 — 需要再次在线完成同步才能恢复展示。

Ruling: 仅扩展 SDK 只读状态和已观察 ID，不由 Flutter 直接读取其私有表 — 保持日志完整性检查与业务显示边界 — 新增小型公开状态契约和相应回归。

## 宿主与交互阶段记录

- 已接入 SignedAccessReceiver、Android 上下文安全存储、ChildSession 生命周期及“我的规则”临时访问区。详细契约见 [儿童宿主与交互](access-child-host-contract.md)。
- 核对真实 ConfigurationDocument 后发现下发的是编译 RuleEvaluation；旧编辑字段夹具无法证明互通。将夹具改为 sourceRuleIds/predictedEffect 后实际出现两项失败，修正匹配并增加真实 Spring → Flutter 子进程流程。
- 畸形重复源 ID 测试先实际接受了不应匹配的配置，后改为整体拒绝匹配；异步创建途中切后台测试先发现实例未关闭，后在创建返回时重新检查前台/身份/存活状态。
- 只读状态、已观察 ID、接收器、存储、会话、页面各有针对性回归；全部儿童测试包含实际规则导航与同步按钮接通。
- Chrome 实际移动端/桌面组件状态、详情和同步已检查。检查器初次未识别 Flutter 合并按钮内的状态文字，按实际无障碍结构修正；截图等待弹窗动画完成，公开合成夹具不含真实身份。截图与结果位于 `design/child-access/`。
- 本次提交边界为前台宿主与交互、真实 HTTP 跨进程文件恢复及原生编译。Android 新上下文/密钥路径的跨进程安全存储、设备申请入口、系统执行与后台/启动调度继续单独实施，不能以本次文件夹具或构建替代原生验收。

Ruling: 使用编译规则组的 sourceRuleIds 与 predictedEffect — 真实签名交付契约与编辑模型不同 — 增加真实基线 HTTP 接收，歧义/畸形分组拒绝匹配，effectiveEffect 仍不得表示执行成功。

Ruling: 接收器异步创建完成后再次检查生命周期 — 初始化可跨越切后台、销毁或身份变化 — 晚到实例必须暂停并关闭，不能恢复记录或继续联网。
