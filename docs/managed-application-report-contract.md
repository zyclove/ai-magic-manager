# 受管应用报告读取契约

更新：2026-10-16。状态：Google SDK 应用报告读取已实现，53 项定向回归全部通过。本阶段没有新增设备系统执行能力，也未部署到当前运行服务。

## 目的

普通目标应用不需要集成本平台的绑定反馈协议。绑定反馈用于关联平台设备注册和提供方设备；应用报告用于读取目标应用的安装及签名事实，两者分开建模。

现有 `readAgentEvidence` 继续服务绑定证明。本阶段新增服务端连接器边界：

```java
boolean supportsApplicationReports();
Optional<ManagedApplicationReport> readApplicationReport(
    String enterpriseId, String deviceId, String packageName);
```

默认连接器声明不支持并抛出 `ManagedAndroidUnavailableException`。Google 读取实现已通过官方 SDK 与本地 HTTP 回归；接口存在不表示设备已经能够执行策略。没有新增面向儿童端或管理端的 HTTP 接口。

## 返回值及使用边界

| 字段 | 含义 | 下游仍须验证 |
| --- | --- | --- |
| `deviceName` | 提供方设备资源名 | 当前租户企业、设备注册及有效绑定是否仍指向该资源 |
| `managementMode` | 提供方报告的管理模式 | 此模式是否支持本次具体动作，不从模式推断全部能力 |
| `packageName` | 请求目标应用的包名 | 与当前应用目录定义相同；包名不是签名信任证明 |
| `applicationState` | 提供方原始安装状态 | 必须显式满足动作要求；缺失或未知值不能按已安装处理 |
| `signingCertificateSha256` | 规范化为小写十六进制的 SHA-256 摘要列表 | 全部签名是否符合当前允许集合及轮换策略；空列表不能通过验证 |
| `deviceReportedAt` | 提供方记录的设备报告时间 | 时间格式、未来偏差、有效期，以及是否早于当前注册和绑定 |

对象对证书列表做防御性复制；`toString()` 不输出设备标识、包名或证书。该类型没有“已核验”“可执行”等字段，不能直接存为应用目录的全局认证状态。

空 `Optional` 的含义是“尚无目标报告”。它不是“已卸载”，也不是“验证通过”。设备报告需要相应上报开关；缺失可能来自配置或上报延迟。[官方设备报告契约](https://developers.google.com/android/management/reference/rest/v1/enterprises.devices#ApplicationReport)

此报告没有可证明本地 `PRIMARY / WORK / SECONDARY` 用户空间的字段；下游不能补写默认 PRIMARY。签名使用提供方的现代 SHA-256 字段，不将旧 SHA-1 指纹升级为 SHA-256。[官方签名字段](https://developers.google.com/android/management/reference/rest/v1/ApplicationSigningKeyCert)

## 读取流程与维护约束

1. 在发起请求前校验企业、设备资源标识与包名（最多 255 字符）；无效输入不发 HTTP 请求。
2. 使用已配置的官方 SDK、认证及传输参数，只请求设备资源、管理模式、报告时间和应用包名、状态、SHA-256 字段；不请求绑定反馈、事件、显示名称和注册材料。
3. 共用 `GoogleApplicationReportReader` 对解码后正文限定 2 MiB，应用项最多 3000 个、签名最多 8 个。错误响应不解析为业务对象，日志只保留操作名、状态码及异常类型。
4. 设备资源必须精确匹配请求，目标应用只能出现一次。缺少目标返回空；重复目标、损坏证书或身份冲突抛出脱敏异常。
5. 原绑定读取继续要求有效的 keyed feedback；共用读取工具不改变其证明要求。普通应用读取不依赖该反馈。

所有输出仅为原始事实。报告时效、目录签名信任、租户和当前绑定的核对在后续服务层完成；不能根据此读取结果直接放开发布或执行。

## 管理员操作与展示约定（后续界面接入）

保留“选择设备 → 预览影响 → 确认发布”三步，不要求管理员填写提供方资源名、签名摘要或内部绑定版本。系统在预览前准备证据；未满足条件的设备逐项解释，不把整批结果压成一个成功提示。

| 实际状态 | 面向管理员的文案 | 下一步 |
| --- | --- | --- |
| 连接器未配置或不支持 | 暂未接入设备管理服务 | 有权限的管理员前往接入设置；普通操作员联系管理员 |
| 提供方尚无目标报告 | 等待设备上报应用信息 | 展示最近检查时间，提供有频率限制的刷新入口 |
| 提供方明确报告 REMOVED | 设备报告该应用已移除 | 展示报告时间；是否允许具体动作仍由策略预览判断 |
| 报告存在，但尚未关联当前注册、绑定和签名 | 应用身份待核验 | 展开具体缺失条件；不能显示“设备已生效” |
| 提供方读取失败 | 暂时无法更新应用信息 | 保留旧信息及其时间，标明未更新；允许稍后重试 |
| 新注册、解绑或证据过期 | 设备信息已变化，请重新预览 | 旧预览不允许继续发布，返回当前设备选择 |

这些是接入时的交互要求，尚未表示上述状态已全部实现于界面。具体错误码和完整提供方诊断只向有权限的运维人员展示；普通用户看到原因与可执行的下一步。刷新只读报告，不触发应用安装、卸载或策略下发。
