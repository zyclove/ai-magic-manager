# 家庭 P0：提醒与手机号协作

日期：2026-10-16。本文记录本轮软件增量；实际真机、身份供应商、支付退款、厂商离线送达和发布渠道仍为收费门禁。现有数据库与已有未提交工作保留，继续采用未发布 1.0.0 初始化基线。

## 家长能使用的流程

- 在“我的 → 消息提醒”查看当前手机状态，主动授权后登记真实 SDK 设备标识，再选择申请、设备异常及到期提醒。进入页面不会自动请求系统许可或打开总开关。
- 锁屏只显示通用“家庭提醒”。点击后打开当前家庭的“消息与待办”，重新读取申请、求助、设备与会员事实。推送事件不选择账号、家庭或直接批准申请。
- 切换家庭、退出、关闭总开关或此手机提醒时先关闭本机显示和旧点击，再撤销服务端安装。服务器结果未知仍允许正常退出，原加密日志供原账号恢复；本机关闭失败会提示重试，不误报关闭成功。
- 在“我的 → 家庭成员”输入被邀请的大陆手机号。创建者完成近期手机号验证及监护声明后，主动复制链接给家人。链接没有手机号、孩子姓名或设备资料；服务端只保存密钥摘要。
- 对方使用目标手机号登录后，在“家人邀请了我”粘贴链接或由 Android 链接打开，查看家庭名称并明确确认监护声明。尚未建立家庭也可加入。编辑链接后旧预览和确认失效。
- 创建者可撤销待接受邀请、移除共同监护人。共同监护人只读成员目录。新邀请及首次加入需要有效试用或会员；会员到期不自动移除已加入的监护人，退出、撤销和必要恢复始终可用。
- 创建、接受、撤销和移除在加密日志确认落盘后才提交。网络未知使用原目标、版本和幂等键恢复；多个页面不能覆盖同一原操作。成功创建后移除本机原始手机号，保留可再次复制的邀请密钥，选择“完成分享”后清除本机密钥。

## 提醒事实及边界

设备提醒只面向当前有效的安卓家庭设备和未归档孩子。首次未授权、尚无规则或缺少健康证据不构造“异常恢复”。正常→故障按持久 episode 去重；旧或未知运行证据抑制发送但不重新武断地判为正常。设备退出/擦除后扫描不能重建已清理的记录。

会员提醒复用商业服务计算的真实覆盖区间、真实到期及七日保留设备窗口，不消费或重置试用资格，不修改免费设备选择。扫描延迟时不向刚开启提醒的人补发旧边界；发送前重新读取会员、设备、成员及偏好事实。

扫描按游标短批次执行，两个 worker 默认关闭。原成员可以使用账号级注销接口关闭自己的旧安装，无需重新取得已离开的家庭权限。注销要求明确 HTTP 204 才删除本机恢复记录，202 不视为完成。

阿里云移动端使用官方 SDK，服务端只发送严格四字段 `MESSAGE`（事件、投递、安装引用及严格链接），不传孩子内容。`AndroidRemind=false`、`StoreOffline=false`，禁止自动转成离线通知绕开客户端授权校验。在线消息能力不代表已完成国内厂商离线通道。

原生 SDK 只在明确本机同意后初始化；首次同意后的延迟初始化需真实设备验证。旧注册回调在撤权后不能重新打开通道。安装授权、点击匹配和去重存储加密；邀请 Intent 只在内存中接收，消费后清空 Intent data。

## 新接口与数据

|用途|接口|
|---|---|
|成员与当前声明要求|`GET /tenants/{id}/family-members`|
|邀请目录、创建|`GET/POST /tenants/{id}/family-invitations`|
|撤销邀请|`DELETE /tenants/{id}/family-invitations/{invitationId}`|
|移除共同监护人|`DELETE /tenants/{id}/family-members/{memberKey}`（版本及幂等键）|
|补充本人监护声明|`POST /tenants/{id}/family-guardian-declaration`|
|预览、确认加入|`POST /family-invitations/preview`、`POST /family-invitations/accept`|
|原账号关闭旧安装|`DELETE /notifications/push-installations/{installationId}`|

手机号预览和接受均校验服务端验证的目标手机号、严格随机密钥及当前邀请者权限；手机号验证不代表成年认证。邀请次数及成人成员容量在服务端控制。接收与撤销共用所有权锁；回放旧接受结果不会让被移除的成员重新加入。

新增五张表已纳入保留目录。主体擦除清理该注册周期的设备提醒记录及扫描游标中的设备引用；家庭成员、邀请、安全频控和商业到期边界按各自保留规则处理，不作为某个孩子的资料整体删除。
