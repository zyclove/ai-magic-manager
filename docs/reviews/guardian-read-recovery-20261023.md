# 工作台与版本冲突恢复改进

基于 `7cf2b2b`，本阶段只修改两个生产文件，沿用现有 Material 组件、权限及请求流程。

## 工作台

常用操作独立于统计读取结果：首次加载或读取失败时，有权限的入口仍可使用。刷新或读取失败时保留同一工作空间上次成功读取的统计与活动，明确标注“当前状态尚未更新”，保留原读取时间；没有数据时不构造零值。统计尚在刷新或已经失败时，不再根据旧数量产生主推荐。忙碌/刷新时的错误面板不提供重复刷新与重新验证入口，原宿主权限、代次和操作忙态检查保持。

## 编辑表单

HTTP412表示本次提交的前提或版本已失效。表单停止再次保存旧版本，保留本次实际提交的字段快照，以可选择文字展示字段及选项标签；提供“关闭表单”，明确说明关闭后刷新原页面、重开核对。关闭返回空结果，不冒充保存成功或自动刷新。

网络结果以 ApiFailure.status=0 或5xx表示时，原内容与请求标识重试规则保持。其他异常处理也保持原样；非 ApiFailure 原来会清空 pendingValues，不能把它描述成保留原内容的未知结果重试。作者原说明中的这处误述已随归档勘误。权限失效仍优先隐藏草稿，成功完成和关闭仍只结束所属窗口。
