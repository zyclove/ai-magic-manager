# 错误提示与恢复操作（2026-10-24）

本阶段按用户要求继续静态完善界面和操作流程。当前源码、测试源码与审查记录已准备；编译、运行及界面渲染验证仍待资源恢复。

## 展示顺序

错误提示先显示自然语言说明，再显示当前可用的“重试”和身份重验证操作。错误代码、追踪编号放入默认折叠的“错误详情”，需要排查时展开，内容仍可选择复制。

组件使用现有Flutter Material的ExpansionTile和PageStorage。故障代码或追踪编号变化时，旧详情重新收起；同一故障仅因恢复按钮暂时不可用而更新时，已展开的详情保留。局部存储隔离避免外层页面保存的展开状态覆盖新的故障状态。

原有重试和401／未知错误的重验证条件保持。没有可用恢复操作时省去空按钮区域；未知异常继续只显示通用说明，不显示原始异常内容。请求、权限、表单保存和业务恢复逻辑未变。
