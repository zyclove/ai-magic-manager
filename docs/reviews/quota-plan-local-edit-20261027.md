# 额度计划日期编辑与提交保护：静态阶段

基线：`89ad2a3902d1c9d0e1d1a3a978d54372b904cdfc`。本阶段沿用既有 Flutter Material、FieldSpec、DialogAccessBinding 和 OwnedDialogRoute；仅修改源码与规格，不增加依赖或更改后端协议、数据库及运行服务。

## 变化

- 日期例外支持直接编辑，已有60个仍可修改；分钟＋秒精确保留原值，允许0～86400秒，取消不改原值，超限可继续修改。日期使用公共 formDialog 的 canCommit=false，本地应用后才由完整计划保存。
- 周一／周六快捷复制保留源的精确余秒，不再把未修改的3661秒截为3660秒；手工改分钟才明确按整分钟替换。非法源输入不覆盖其他日期，保留值与提示同步更新。
- 提交前冻结正文、weeklyLimits 与 dateOverrides；408视未知，已有未知在近期认证要求后保持锁定。412或不可恢复结果停止旧请求，保留只读输入，旧保存回调不能重发。日历读取与保存的明确失权统一隐藏旧内容。
- 未知关闭先内联确认，并提示核对原列表。每次确认捕获独立标识，收起后再打开不能复活旧确认；关闭不取消已发出的服务端保存。
- formDialog 默认仍按远端写入保护，仅显式的只读／本地准备可以关闭该模式，且不能配置原结果查询hook。SPEC、额度契约和项目记忆同步。
