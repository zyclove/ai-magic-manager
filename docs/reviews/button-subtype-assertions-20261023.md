# 补齐按钮子类的回归断言

本阶段只修正四份既有测试的 14 个查找表达式，不增加测试、不改生产代码、测试名称或业务断言。

本机 Flutter 的 `FilledButton.icon`、`OutlinedButton.icon`、`TextButton.icon` 会返回对应按钮的私有子类。旧 `find.byType` 按运行时类型完全相等查找，会漏掉这些子类。改为现成的 `find.bySubtype<T>()` 后，断言也能检查带图标按钮。

- 设备子流程的两处查找保留原组件局部范围，用于检查失效操作是否禁用、旧导出操作是否消失。
- 策略预览的十二处否定断言补齐同类子控件，继续表达只读预览中没有写操作按钮。独立挂载的预览范围保持，展开条目不属于这三类按钮。
- 每份候选均从当前源码的声明替换重建，并能逐字反向恢复旧文本；全部测试名称、请求与业务断言保持。

本机缓存源码已静态确认该查找 API 存在，无需依赖升级。见 [应用与审阅记录](../evidence/button-subtype-assertions-20261023/application-receipt.json)。**尚未格式化、分析、编译或运行测试**；补强查找范围本身不表示发现了产品越权，也不表示新增断言已经通过。
