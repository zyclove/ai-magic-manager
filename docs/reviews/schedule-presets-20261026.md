日期：2026-10-26。状态：源码及规格已完成本阶段收尾；依赖解析与运行验证待恢复资源窗口。未推送或部署。

管理台原先只能手工设置时段，本批复用已有只读目录，增加「选择时间安排示例」。用户按需读取、查看实际星期与时间、填入本地草稿，再明确保存。已有每周时段先确认替换；取消不改草稿，名称非空时不覆盖，时区和日期例外保留。多时段示例按需展开，不增加默认请求或自动发布。

两端的目录校验集中到无第三方运行依赖的本地 `packages/schedule_contracts` 包。Parent 只保留类型与错误映射适配；宿主继续负责 HTTP 字节上限、请求期限、授权与写入恢复。模型严格校验字段、数量、星期和墙上时间，返回逐层不可变副本，不在错误中附带原始响应。Unicode 控制与格式字符按 SDK Unicode 正则类别拒绝，包含补充平面字符。

Guardian 使用既有有界 JSON 读取，最多 64 KiB、整段 25 秒期限；目录错误与保存错误分开，读取失败不进入未知写入恢复。加载中可取消整个编辑器，晚到结果不能回填。日期例外原有弹窗租约提取为 `leasedDialog`，供两个真实流程复用，保留原父路由、权限和自身路由检查。
