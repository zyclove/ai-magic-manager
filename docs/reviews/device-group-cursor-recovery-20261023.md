# 设备批量选择：分页失效后的直接恢复

本阶段修正批量选择窗口在分页信息被拒绝后反复重试同一位置的问题。

- 保留已加载设备和当前选择，仍可核对已选设备。
- 需要继续浏览时，可直接点击“重新加载并清空选择”，从首屏重新选择；操作影响在按钮及说明中明确呈现。
- 普通分页失败保留原位置和选择，可直接重试。
- 旧重试、重载和设备勾选回调仍须核对当前状态；工作空间、权限、路由、注册身份和单次 50 台上限保持原校验。
