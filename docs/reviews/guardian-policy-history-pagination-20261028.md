窗口内的 API 和校验谓词保持稳定，避免重建触发无关重读。每页在接收前完整核对版本与原策略归属，坏页不部分追加；打开详情前冻结快照。详情借用原列表操作租约，纯查看或回滚取消返回保留页和搜索；需要核对的回滚仍沿原信号结束旧历史和详情。明确失权隐藏私有历史，迟到的旧窗口拒绝不能撤销仍有效的其他窗口；近期认证保留既有入口。空态按当前写权限提供可执行的说明。
