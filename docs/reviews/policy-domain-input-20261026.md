# 域名规则输入与只读表单恢复

日期：2026-10-26。基于 `80b986c` 后的本批增量；没有更新运行服务。

## 交付

添加／编辑域名规则可直接填写中文或大小写域名。确认规则先经既有后端规范器校验，再将规范 ASCII 名称加入本地规则列表，供最终保存前核对；不需要预先保存空草稿。新接口只返回 `canonicalDomain`，遵循当前策略读取权限和 `no-store`，不要求写入幂等键、草稿版本或近期 MFA，不执行 DNS／网站访问，也不写业务记录。

复用现有 Material 编辑表单，新增 `EditDialog.canCommit`，默认 `true` 保持服务器写入的恢复语义。规则准备显式使用 `false`：只读格式校验失败仍保留可修改输入，不误锁定为未知写入；处理中仍防重复，原路由与权限失效后仍拒绝旧回调。模式中途改变永久撤销原表单，不能把正在恢复的服务器写入降级为只读。真正“保存草稿”的原请求、版本与未知结果恢复保持。

规范化请求另绑定规则子窗口；子窗口失效不会加入迟到结果，也不会把仅子窗口结束误当成整个编辑器失权。字段说明明确只匹配精确域名、加入规则不等于保存或执行策略。没有新增依赖、数据表或全局配置；相关文件同时采用现有 Dart 格式规范。
