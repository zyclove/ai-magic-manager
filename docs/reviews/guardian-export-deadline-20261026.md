# 审计下载的请求期限与资源释放

日期：2026-10-26。基于 `244ac33` 后的本批增量；共享工作树含其他会话改动，本提交仅交付下述审计下载相关文件，不更新服务。

## 实现

审计下载原先使用普通 HTTP 请求：25 秒到期虽返回网络错误，但等待响应头的传输没有收到中止信号，OAuth 内部刷新迟到后也可能继续发送。现在复用现有 `ScopeGuardedRequest` 和锁定的 `http 1.6.0` Abortable 协议，将本次请求的中止信号传到传输层；总期限仍覆盖身份准备、响应头与正文，不重置为每个阶段 25 秒。

到期同时取消已订阅正文；迟到响应只丢弃并清理，清理失败不覆盖原错误，也不关闭共享会话客户端。作用域失效仍映射为 `WORKSPACE_CHANGED`，不能将内部异常直接交给界面。保留禁止重定向、成功体 8 MiB／错误体 64 KiB 上限、内容类型／长度／租户／任务／选择／事件校验，以及原始成功字节和 MFA 拒绝反馈。
