# 共用日期显示的数值边界

基线：`40c95901a172ab9cecf7ccee400e462e11620a2b`。稳定性影响：P2；这是已确认的静态异常路径，尚无本轮运行验收。

根因是共用 dateLabel 将未校验数值直接 toInt 并构造 DateTime：非有限值可能在转换时抛出，小数会被截断，越界整数会由构造器抛出 ArgumentError。精确模式 `DateTime.fromMillisecondsSinceEpoch(value.toInt())` 命中该显示入口；进一步只核对设备最近心跳、成员邀请有效期和审计时间的实际调用，均直接消费响应字段。未扩大到全库日期审计。此前修订的策略版本领域解析已有独立构造校验，继续整页拒绝无效版本，不由显示回退代替。

修订先拒绝非有限或非整毫秒数值，再以原生构造器校验范围，异常数值显示“时间无效”。正常整数、整数double和ISO文本继续显示本地分钟，null保留“—”，无法解析的非数字文本保持原回退。此函数只呈现时间，不修改状态、权限或操作可用性。

在现有 access_delivery_labels_test.dart 增加一个聚合回归：固定本地时刻的整数／double／同瞬间ISO应得到相同文字；NaN、正负无穷、小数、正负越界值及极大有限数值均显示“时间无效”，并保留空值和文本回退。没有新增UI夹具、测试文件、扫描器或依赖。

本轮限定差异及调用边界经静态核对，空白检查通过。格式化、分析、纯标签回归及设备／邀请页面渲染均为 **NOT_RUN**；未重新采样资源、启动SDK、推送或更新服务。验证窗口恢复后先运行此既有标签测试文件，按失败或共享影响再决定是否扩大。
