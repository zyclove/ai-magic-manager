# 列表失败恢复：保留浏览位置并准确重试

本阶段修复产品目录、合同记录和求助记录中的两类分页恢复问题，继续使用现有 Flutter Material 组件与后端接口。

- 产品目录与合同记录按实际失败阶段重试：追加失败继续原位置，首屏失败仍重读首屏；成功后清除旧错误，避免误导用户再次刷新。
- 加载首屏时阻止旧“加载更多”操作；显式刷新与写入后的刷新仍能替代旧分页请求，迟到回复沿用原请求代次检查。
- 求助记录的追加失败保留已加载内容；读取错误与确认结果未定分开，加载另一页不会解除“请先刷新核对”状态。
- 分页位置被服务端拒绝时保留当前求助记录，提供明确的“刷新求助记录”入口；原 401 重新验证入口保留。
