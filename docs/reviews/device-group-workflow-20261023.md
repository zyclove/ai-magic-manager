# 设备组查找、复核与分页恢复

本阶段使用现有 Flutter Material 组件，修改批量选择器及设备组详情页。没有新增依赖或改变后端协议。全部运行检查仍待验证窗口，以下为源码改进与静态审查范围。

## 批量选择

- 可以搜索已加载的设备名称、设备编号和注册编号；清除搜索后回到输入框。
- 可以只看已选设备、清空选择，并分别查看已选、显示和已加载数量。筛选不丢弃跨页选择。
- “加载更多设备”独立于筛选结果，当前零匹配时也可继续浏览。页面明确搜索范围，不自动查询或加载未读取设备。
- 确认时重新核对最多 50 台、当前已加载设备和注册组合、加入模式的激活状态。后台原有组版本、设备注册和原子提交校验保持。
- 标准滚动对话框承载说明与筛选，设备列表有限高并按需构建；操作按钮位于独立操作区。小窗口、大字和软键盘仍需实际渲染验证。

## 明确复核整批设备

加入与移出确认页显示本次全部设备名称与缩写编号，不再只列前三台。确认正文可滚动；请求内容仍来自同一份已选列表，原请求编号、组版本和不确定结果重试逻辑保持。

## 分页恢复

- 加载更多失败时保留当前成员和分页位置，错误展示在成员列表内，点击“重试加载更多”继续该位置。
- 重试开始清除分页错误，成功后不会残留上一次失败提示；不会为了重试分页重做详情、统计和已加载页。
- 无效分页信息明确提示刷新设备组；刷新前保留已加载记录，避免重复提交同一个无效位置。
- 首次加载、变更操作错误与分页错误独立展示；打开另一组、切换状态、返回列表或失去访问权限时清空对应分页状态。
