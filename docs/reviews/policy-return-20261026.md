日期：2026-10-26。状态：实现、严格分析及静态复查完成，修复后的浏览器复验待窗口恢复。未推送、未更新运行服务。

普通取消编辑、模板复制或只读历史返回保留原详情与列表；保存、创建副本或回滚草稿后结束旧详情并刷新。回滚取消留在版本详情，确认回滚只修改草稿，仍须重新预览并发布。多层详情逐级回传是否需要核对列表，不把正常关闭或刷新信号解释为保存成功。

复制和回滚复用现有通用写入表单，统一未知结果、近期身份验证、版本冲突和原请求保护。结果未知时冻结原正文、防重复键及修订；明确关闭需就近确认，再返回列表核对。原详情、账户或权限失效后，子流程和迟到身份准备不能继续发送；关闭只结束自己持有的窗口，独立通知保持显示。

真实 POST 的 `409 IDEMPOTENCY_KEY_EXPIRED` 与既有不可恢复结果停止旧请求重试，保留可选中复制的只读输入。策略与时间计划复用相同判定；此判定只约束界面，不作为服务端执行证据、不解除持久化防重复保护。已有策略允许只读获取当前草稿核对；较新的修订及完整输入均匹配才确认保存，不匹配或查询失败继续停止写入。
