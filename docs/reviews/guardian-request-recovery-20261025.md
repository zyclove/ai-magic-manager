# 请求期限与申请表恢复

## 实现

- 通用 API 沿用 25 秒总期限，使用已锁定的 `http 1.6.0` Abortable 协议中止当前请求，作用域包装保留同一中止信号。初始身份准备与 OAuth 内部刷新完成后，发送/请求终结前均再检查期限；不关闭共享客户端。迟到响应头被丢弃，未知写入仍锁定原内容，不能把中止当作服务端撤销。自定义传输也需响应 Abortable；晚响应头兜底不构成任意自定义传输的全面取消认证。
- 申请表设备游标过期后可从首页重新加载，保留时长、理由和未出现在新首页的原选择。新页明确报告所选设备非 ACTIVE 时，清除设备及规则选择、作废旧规则请求并提示重选，保留草稿；普通网络失败仍重试原游标。
- `http` 最低约束对齐当前锁定版本；已缓存 `fake_async 1.3.1` 改为直接开发依赖。离线解析未改变包版本，70 个包路径和语言版本均保持相同，没有下载或升级。
