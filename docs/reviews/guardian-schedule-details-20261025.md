# 时间计划：同页检查与操作身份保护

时段计算结果改为直接显示在时间计划详情中，包含本次检查时间、允许状态和下一允许时间等信息。关闭计算结果的额外弹窗已移除，可在同一详情中重复检查；开始新检查时清除旧结果，避免把上次结果当成本次读取。结果同时说明，计划计算不代表设备已经实际执行。

主详情、计算请求和内联结果统一绑定打开时的账户、工作空间、角色及会话代次，并绑定来源页面的存续。切换后即使立即切回，旧窗口也不能继续操作，原内容隐藏。等待客户端的请求在发送前再检查身份，已发送请求的迟到结果不能进入失效窗口。

计算请求完成时只更新自己窗口中的内容，不创建新窗口或关闭覆盖通知。新的检查要求自己的详情位于最上层；已接受请求的守卫只要求自己的窗口仍活动，避免把正常的覆盖窗口误判为撤权。

服务返回工作空间变化、禁止访问或非重新验证身份的未登录错误时，原内容会隐藏。需要重新验证身份的提示保留恢复入口。实现复用已有 `DeviceSubflowScope`、`DialogAccessBinding`、`actionDetails` 和 Material 组件，未增加依赖或修改后端契约。

保留原策略详情用例，补写五项回归，覆盖重复检查和旧结果清除、账户及角色立即切回、等待客户端时失效、被通知覆盖时的迟到结果，以及权限拒绝与重新认证的区别。

本阶段只完成代码与静态审阅。新增回归、格式化和运行分析待原资源门槛及验证窗口恢复后执行；不以静态记录认定运行验收，不借用旧提交的验证结论。本轮未更新当前运行服务，也未推送代码。
