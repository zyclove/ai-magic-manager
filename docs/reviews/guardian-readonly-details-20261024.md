# 时间计划详情返回：保留列表状态

此前查看时间计划详情并关闭后，通用列表会重新读取首页，替换已加载的后续页。只读操作也会发起一次额外查询；网络此时中断，列表会显示与本次查看无关的刷新失败。

`ResourcePage` 现在支持明确配置详情返回后的刷新行为。时间计划内容不可变，详情及“检查此刻是否允许”均只读，因此该页面返回后保留已加载记录、搜索条件与后续页位置。创建操作和可编辑详情仍按原行为刷新，列表原有的操作锁、操作身份检查和旧回调检查保留。

同时，特殊日期的非空时段显示为 `09:00 – 12:00、14:00 – 18:00`，空时段仍显示“全天关闭”，避免直接展示原始列表结构。该调整只改变显示文字。

补写两项回归：加载后续页并搜索后，重复打开受操作锁限制，关闭后仍能继续打开及加载原下一页；读取详情后网络中断时，返回不会额外请求或显示刷新失败。保留原有编辑详情返回后刷新的回归。

本阶段未运行 Flutter、Dart、格式化、分析或测试。新增回归待原资源门槛和验证窗口恢复后执行；静态审阅不能替代运行验收。本轮未修改后端契约，也未替换本机现有运行版本。
