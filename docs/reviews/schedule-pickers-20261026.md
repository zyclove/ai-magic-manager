# 时间计划选择器生命周期：静态阶段

日期：2026-10-26。状态：源码和交互契约收尾，运行验证未执行。未推送或部署。

管理台的每周时间与「添加关闭日期」原先直接调用系统对话框，没有沿用日期例外的父路由/权限租约。父表单结束后，选择器可能留在上层；系统控件通过根 Navigator 返回时，也可能影响独立覆盖通知。本批将这两处入口接到既有受控流程。

日期例外已有的 `leasedDialog + 局部 Navigator + TimePickerDialog` 原样提取为 `pickLeasedTime`，继续使用 24 小时制、分钟输入和中文标签；每周开始/结束时间复用它。关闭日期复用日期例外日历，只调整标题，保持 1900–2200 年范围及本地全天关闭含义。独立覆盖时原选择器不能确认；身份、工作空间或父路由失效时，只结束原选择器，不修改旧草稿或关闭独立通知。

编辑器用同一个子流程准入检查，复用原权限、父路由和未知写入保护；选择中锁住重复操作与父表单保存，返回后再检查当前原表单才回填。选择器只返回本地值，最终仍由显式保存整个计划发送请求。
