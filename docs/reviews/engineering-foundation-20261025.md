## 初始化输入简化

统一入口只推导缺省的 URL/端口，预览与执行共用最终参数；本机改端口不再重复填写 URL。显式两项不被改写，外部 TLS 代理保留独立内部端口，推导端口也校验 `1..65535`。

仅运行新增定向用例：10 组计划参数（含原默认值、HTTP/HTTPS、显式值、代理开关真/假）和 URL 端口 0 拒绝，共 1 个用例通过，7.851 秒。先确认旧实现不能满足该行为，再修正；没有调用 SDK、初始化目录或访问服务。未重跑既有无关测试。

## 部署模式校验与审批契约核对

Helm 的固定 API 副本数校验现在仅在 HPA 关闭时要求至少 2；启用 HPA 时该固定字段不参与 Deployment 副本配置，运行上下限仍分别至少为 2，且保持上下界检查、类型和负数保护。默认部署值未改变。既有 Helm 测试复用非秘密 fixture，临时值仅放在仓库 `.cache`。

本批仅执行新增 4 个定向方法：HPA 忽略固定值、固定模式最低副本、非法固定值、HPA 上下限；全部通过，原生用例耗时 2.409 秒。使用已有本地 Helm，仅渲染模板，没有访问集群、安装或升级。[原始结果](../evidence/helm-hpa-20261025/result.json)、[输出](../evidence/helm-hpa-20261025/output.log)。未重复无关测试，模板通过不代表 Kubernetes 运行验收。
