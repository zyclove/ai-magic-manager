# 部署构建的 Flutter 链接入口

日期：2026-10-26。范围：构建工具路径解析；未执行真实 SDK 构建或更新运行服务。

原实现根据 PATH 链接所在目录推导 SDK，真实隔离构建回归复现了错误：即使提供正确 Dart，仍找不到 Flutter 工具快照。现在只读取文件元数据，最多解析 16 个文件符号链接，拒绝循环、悬空、非文件和不支持的重解析点。相对目标按链接目录解析，普通函数／别名或转发脚本不被猜测为 SDK。

全部 Flutter 调用、默认 Dart 及 Maven 互通参数使用同一解析入口，避免原 PATH 链接切换造成安装来源漂移。工具快照仍在依赖准备之后、Maven 之前检查，允许正常首次准备；没有提前跳过或放宽原来源／发布门槛。
