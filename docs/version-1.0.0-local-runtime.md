## 使用与重启

用户指定的管理员已在新身份服务建立，并验证真实授权码 + PKCE 登录。进入后是空工作空间，可根据实际用途创建家庭或教育机构；未预置演示主体、设备或合同。密码与身份服务 bootstrap 凭据只保存在本机受限文件，未写入仓库。

敏感操作仍要求真实近期 MFA。管理员尚未绑定验证器，本轮未声明 OTP 验收通过。平台合同签发方和销售开关保持关闭，页面明确显示尚未启用。

从仓库根目录重新启动该冻结环境：

```powershell
./.local/v1-release-source/scripts/start-deployment.ps1 -Directory .local/deployment
```

该命令保留数据库、账本身份与密钥；不要重新运行首次初始化来解决登录或启动问题。运行目录及三份数据库卷需保留；后续更新应建立新的已验收产物，不能直接把工作区修改拷入运行中的镜像。

## 保留的判定

- Ruling：用独立端口、数据库和凭据提供全新首版；保留旧服务与备份供回查。两个环境数据相互独立，使用旧入口看不到新环境内容。
- Ruling：复用生产源码逐文件一致的已验收后端，仅重新构建本轮管理台；不将该证据扩展为统一构建流水线、Android APK 或最新其他任务提交的验收。
- Ruling：MFA、真实外部签发方、实际设备执行、完整主体删除和恢复再删除均不作完成承诺；这些能力继续按总计划推进。启动与页面可用不能代替全部业务验收。
- Final: fixed：测试泄漏断言在失败时会输出原始材料 — 使用固定消息的布尔断言；新增用例先失败后通过，完整部署 10/10 通过。
- Final: Ruling：复核未判定的容器读取和重启已由本轮实际验证补足；历史密文重启解密、真实 MFA 导出/诊断流程和镜像内容扫描仍需独立证据，不能从只读挂载推出这些保证。
