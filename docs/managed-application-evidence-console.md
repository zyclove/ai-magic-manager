# 应用核验管理界面 · 1.0.0

状态：本轮前端已完成验收与生产构建；尚未更新运行服务。

## 操作流程

1. 在机构工作空间打开“机构受管 Android”，进入已核验设备的“关联儿童端”。
2. 在有效关联详情点击“应用核验”，搜索或加载应用目录，选择需要检查的应用。选择只查询现有结果。
3. 查看结果后，点击“开始核验”或“重新核验”。请求结果不确定时，主操作切换为“查询核验结果”。

关闭应用核验会返回原关联详情。普通返回不会自动发起核验，也不会改写既有策略预览。完成核验后，应重新生成策略预览，核对当前条件。

## 状态与下一步

| 状态 | 界面操作 |
| --- | --- |
| 尚未核验 | 选择应用、查询现有资料，明确点击后才开始核验 |
| 正在核验 | 查询结果；等待不会自动重复提交 |
| 等待可信报告 | 检查设备和提供方接入，再查询或按允许时间重新核验 |
| 结果尚未确认 | 先查询核对，避免重复发起请求 |
| 暂时限流或冷却 | 查询当前结果，按服务端允许时间继续 |
| 关联已变化 | 旧结果隐藏，明确返回并刷新关联后重新进入 |
| 权限或工作空间变化 | 旧操作立即失效；关闭窗口，在当前空间重新进入 |
| 核验已过期 | 隐藏已过期操作范围，按当前条件重新核验 |

目录中的登记资料用于查找应用。缺少可信报告不能解释为应用未安装。界面展示的当前操作范围需要继续经过策略预览及设备执行确认。

## 界面与交互

- 沿用现有 Flutter Material 组件、滚动条和状态管理，不新增界面框架或依赖。
- 目录搜索明确限定为已加载的应用；更多资料由用户主动加载。
- 核验结果、原因、时效和当前操作范围在同一窗口查看，详细操作按需展开。
- 主操作随当前状态变化；未知结果和等待中的请求不会因倒计时结束而自动重发。
- 窄屏及大字号使用可滚动内容和换行按钮，关闭入口保持可达。
- 每次进入固定同一关联版本；父窗口普通重建不会更换正在使用的关联上下文。
