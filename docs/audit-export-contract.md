# 审计异步导出合同

## 使用流程

1. 打开审计日志，选择日期与筛选条件并应用。
2. 选择“导出当前结果”，核对范围后生成。尚未应用的输入不参与导出。
3. 在“导出任务”查看本人任务；等待/生成状态每 15 秒更新，离开前台后暂停。
4. 完成后下载 JSON；任务可以取消，创建后 24 小时到期。

创建与下载都需要近期真实多因素认证。重新安全验证后返回原页面，不自动重复写入。创建前的日期与筛选条件暂不跨登录保存，返回后需要重新选择；已生成任务仍可在任务列表查看。READY 状态暂不持续轮询，到期后下载会被服务端拒绝，点击刷新可查看终态。

## API

根路径：`/api/v1/tenants/{tenantId}/audit-exports`。

| 方法 | 路径 | 语义 |
| --- | --- | --- |
| POST | 根路径 | 必需 Idempotency-Key；from/to 毫秒时间戳，action/resourceId/correlationId 可选；202 返回当前作业 |
| GET | 根路径 | 本人作业；limit 1–50，时间/id 倒序，cursor 绑定租户和创建者 |
| GET | /{id} | 当前作业元数据，重新鉴权 |
| POST | /{id}/cancel | 本人任务取消；清除在线密文；重复取消返回终态 |
| GET | /{id}/content | 近期 MFA、当前成员角色/版本/创建者检查；application/json、no-store、固定文件名 |

允许 OWNER、GUARDIAN、ORG_ADMIN、AUDITOR；其他角色不能访问。范围最多 366 天，左闭右开，实际截止不晚于创建时刻。操作代码为大写代码，资源编号为 UUID 或 64 位成员哈希，关联编号为 UUID。

每个创建者一分钟内最多创建一次、最多 5 个有效任务，同租户最多 100 个；同幂等键重试不重复计数。不使用公开下载 URL 或 URL 令牌。仅输出受控 JSON，前端核对任务、租户、范围、记录数、排序及原始字节长度后交给浏览器保存。

## 后台与权限

- V22 持久化 QUEUED/RUNNING/READY/FAILED/CANCELLED/EXPIRED/REVOKED 状态。
- 数据库事务锁顺序为创建者成员→租户导出头→作业。导出头原子 upsert 直接取得排他锁，避免普通重复 INSERT 的共享锁升级死锁。
- 领取、生成、失败恢复独立事务；60 秒租约、随机 claim token、最多 3 次尝试，按 30 秒乘尝试数退避。旧执行者不能覆盖新领取、取消或到期状态。
- 执行、产物提交、下载都重验当前成员版本；撤权、重新加入或角色/范围变化不能复活旧文件。
- 最多 10,000 条、8 MiB 明文，超限明确失败，不静默截断。客户端接收也有字节上限及超时。
- 24 小时到期，后台批量清理密文；终态元数据保留 30 天。取消也立即清除在线密文。

## 加密与配置

使用 Nimbus JOSE 标准 JWE `dir`/`A256GCM`。保护头绑定用途、租户、作业、成员版本、选择范围及文件统计摘要，替换其他作业密文会被拒绝。数据库保存密文，不保存密钥。

`AUDIT_EXPORT_KEY_FILE` 指向独立本地 JWK Set 文件，最多 8 把 256 位 oct 密钥，必须有 `use=enc`、`alg=dir` 和唯一 kid。多密钥时必须设置 `AUDIT_EXPORT_ACTIVE_KEY_ID`；轮换时保留旧键直到旧产物失效。此密钥不与配置签名密钥共用，不应进入 Git、日志或公开备份。未配置时创建返回 503；配置文件非法会阻止启动，避免误用密钥。

可配置 `AUDIT_EXPORT_MAX_ROWS`（1–10000）、`AUDIT_EXPORT_MAX_BYTES`（1024–8388608）、`AUDIT_EXPORT_WORKER_ENABLED`、`AUDIT_EXPORT_WORKER_INTERVAL_SECONDS`。默认每 5 秒有界处理，清理 25 项、生成 2 项。

## 验证和边界

证据与部署状态见 [实施记录](audit-export-plan.md)。隔离环境中的 MFA claims 不等于真实管理员 OTP 验证；真实环境仅以实际完成的密码登录、只读接口和 MFA 拒绝门槛为证据。

本功能不覆盖汇总报表、设备原生执行认证、备份擦除/恢复后再删除、诊断包或容量承诺。已下载副本由持有者管理；数据库备份中的历史密文需要后续数据治理流程处理。全产品目标仍在实施。
