# 儿童端规则解释界面

状态：已接入 `apps/child` 的「我的规则」页；适用于 Android 手机、平板和 Android TV 的同一 Flutter 界面。该页面只解释已验签、已保存的 `CONFIGURE_ONLY` 配置。

## 页面与操作

1. 设备身份确认后，在「我的规则」查看配置列表。每份配置显示名称、规则数和“当前不执行跨应用限制”。
2. 展开配置，逐条查看规则类型、应用或网站、额度或时段、监护人计划的效果、设备能力状态和可理解的原因。
3. 选择某条规则可打开完整说明。规则项使用可聚焦按钮，支持触屏与键盘操作；电视遥控器的实际焦点顺序仍需真机验证。每次先显示八条，后续由用户选择“显示更多规则”。
4. 关闭或切换策略版本时，界面从当前已验证配置重新生成，不在本地保存规则编辑结果。儿童端没有修改、授权或解除限制入口。

规则展示使用后端随设备配置签发的应用和时段名称，未知字段使用固定安全文案，不显示内部错误码或管理员资料。界面过滤控制字符，并将签名载荷中意料之外的字段类型视为“待核对”，避免把解析错误解释成允许访问。

## 证据边界

设备配置中的 `predictedEffect` 是监护人规则的预期效果，`status`/`reasonCode` 是发布时的设备能力判断；它们都不是执行回执。签名配置只在本地保存并回报 `STORED`。当前儿童端未实现跨应用系统限制，页面必须始终明确这一点，不能将“计划限制”“设备报告支持”或商业权益文案转成“已拦截”。受管模式接入后，需要独立的提供方应用状态、版本和真实执行证据，才能设计“已执行”状态。

设备离线时仍可读取最后一份通过验签的配置，但不能据此推断云端规则未变化。损坏的本地记录由配置接收组件拒绝恢复；页面不能自行放宽规则或修改设备注册。

本阶段完成只读解释交互、Flutter 全量静态分析和 Web 预览构建。Android APK、TV 真机焦点、长文本、字体放大及遥控器滚动仍需在代表性型号上验收；这些检查不能由 Web 编译代替。
