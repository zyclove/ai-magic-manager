# Guardian 操作结果到期与本机核对交互

日期：2026-10-20。90 天产品选择已确认，生产源码已静态接合。状态为 **STATIC_IMPLEMENTED_PENDING_VERIFICATION / NOT_RUN / NOT_DEPLOYED**；最终范围和静态复核见[本阶段实施记录](evidence/operation-result-retention-implementation-20261020-r1.md)。本文描述当前方案，不代表运行验收通过。

## 1. 时间和结果含义

- 服务端从成功结果随业务事务提交的时间起计算固定 90 × 24 小时。客户端不根据本机时间或预览创建时间判定到期。
- 完整可信的 HTTP `410` 与 `IDEMPOTENCY_RESULT_EXPIRED` 表示原返回结果已到期；`IDEMPOTENCY_RESPONSE_ERASED` 表示原返回结果已清除。两者都不证明原业务未发生，不允许重发、自动换键或重新预览。
- 之前已经可信确认成功的事实不能被后来的结果到期或本地存储失败改写为失败。
- 重新发布从用户再次明确打开的正常策略管理流程开始，读取当前状态、生成新预览并重新确认。

## 2. 简化后的用户流程

### 原操作结果已到期

“该操作的原返回结果已超过 90 天保留期限，不能再恢复。到期不代表操作未完成。请查看当前策略或相关审计记录。”

### 原操作结果已清除

“该操作的原返回结果已清除，不能再恢复。清除结果不代表取消了已发生的操作。请查看当前有权访问的策略或审计记录。”

### 操作彼此独立

1. **查看当前策略**：直接打开当前记录的只读详情，无须清理确认。该核对入口不提供编辑、复制或发布操作；正常策略管理入口保留原功能。
2. **查看审计记录**：有当前审计权限时直接打开已带原操作检索线索的审计页，无须清理确认。
3. **结束本机核对**：独立的一次明确确认，原子清除敏感恢复详情并保留最小防重标记。
4. **关闭**：保留本机待办，稍后可继续核对，不发起业务写入。

结束核对的确认需明确说明：只清理本机恢复详情，不取消远端操作，不删除当前策略或审计，也不重新发布。双击、存储失败或冲突不能显示虚假的清理成功。

该流程取代初版设计的“清理并查看”绑定步骤。只读查看不依赖清理；没有权限、原父窗口退出或会话变化时不导航至旧资源。

## 3. 可信状态分类

| 输入 | 行为 |
| --- | --- |
| 完整受限 JSON、正确内容类型、实际 HTTP 410、正文 status 为整数 410、精确到期错误码 | 绑定原意图和请求的 resultExpired |
| 同样可信、错误码为精确擦除错误码 | 独立的 resultErased，不能降级成到期 |
| 404、网络失败、5xx、截断或畸形正文、未知 410、字符串或小数状态 | 保留原不确定结果，不确认清理或授权重放 |
| MFA 要求 | 明确安全验证；返回后不自动发布或清理 |
| 账号、租户、角色、会话代际、权限或父窗口失效 | 永久撤销该视图，立即隐藏私有内容 |

BoundedHttpErrorEvidence 的证据必须属于实际抛出的同一个失败对象；仓库产生私有构造的终态类型，通用异常字符串不能伪造该证据。GET 查询和 POST 返回均使用这条分类链。

## 4. 持久终态和原子结束

生产接合涉及 policy_publication.dart、publication_journal.dart、browser_publication_journal.dart、仓库、控制器与对话框。

1. 可信 410 按完整 expected record、owner、policy、原 key 与 attempt 做比较后写入终态。待办保留终态解释，不循环查询原结果。
2. 用户确认结束后，在同一 IndexedDB 写事务中核对终态记录，保存独立最小标记并删除含完整意图的待办；随后复读核对。
3. 标记保留必要范围、请求摘要、终态原因、确认时间及已有成功布尔事实，不保存预览正文、设备列表、令牌、完整响应或异常原文。标识仍属于受保护资料。
4. reserve 和 claimRetry 在授予发送能力前核对标记；旧 key 不能重新占位，终态不能进入原提交重试。
5. 多标签页的旧查询、旧确认和旧清理不能覆盖新记录。完整比较失败或存储异常时停止操作，提示重新读取，不能将其当作空槽。
6. 终态标记使用独立命名空间，不占 20 个未完成待办额度，不按客户端 90 天时钟静默删除。

控制器和底层存储同时阻止重放；仅隐藏按钮不足以实现该规则。结束失败仍允许直接查看有权访问的当前记录。

## 5. 窗口与审计接合

- showPolicyPublication 使用明确的 PublicationDialogResult / PublicationExitReason，分别表达关闭、重新预览、查看当前策略、审计和结束核对；终态动作不能复用重新预览的旧布尔值。
- 只关闭自己拥有的 route，等其退出完成后再导航。父窗口即使被覆盖移除，子窗口也须立即失效；嵌套只读详情及审计继续继承原账号、工作空间和权限链。
- 当前策略从服务端重新读取，不用旧恢复快照替代。记录不存在也不证明原操作未执行。
- POLICY_CONFIGURATION_RECORDED 的审计资源是可信回执的 versionId，不能用 policy ID 或幂等 key 冒充精确资源/关联编号。
- 有可信回执时使用版本和 action；没有回执时使用 action 与本地原操作附近日期，明确其只是检索线索。查询保留时区及最多 366 天限制；审计缺失不证明从未执行。
- 审计页不能采用到期操作通常已超出的默认最近 7 天作为唯一入口。首次显示前就绑定原作用域，不能在新工作空间沿用旧查询。
