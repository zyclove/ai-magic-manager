## 操作流程

- 结果到期或清除后，可直接查看当前记录，无须先清理本机待办。
- “结束本机核对”独立确认一次，原子清除敏感恢复详情并保留最小防重标记。不会撤销业务、重发或自动换键。
- 已确认成功的事实单独保留，后续结果到期或读取失败不改写它。当前记录不能冒充原返回结果。
- 确认窗口只关闭自身。异步保存完成、窗口退出或下一帧返回前，重新核对原页面、身份与请求；被其它窗口覆盖时不误关上层窗口。
- 正常恢复的“完成核对”和“打开结果”也使用相同的页面归属检查。

范围包括应用、审计导出、设备组、邀请及接受邀请、成员权限、两类观察设置、班级、所有权、额度与计划、策略创建、时间安排、儿童档案及配置发布。额度计划复用共享恢复组件；配置发布保留 CONFIGURE_ONLY 和原模式/目标选择。

## 持久记录和身份

原生 SQLite 事务及 AndroidKeyStore AES-GCM 保存本机记录，使用应用不备份目录。占位、完整期望记录比较、终态和结束标记保持原子性；回执核对原请求的真实 SHA-256。缺失配置、损坏记录、密钥丢失或已有密钥与数据库不一致时停止写入，不能回退为内存空记录或清库重试。

API 地址与 OIDC issuer 参与物理命名空间，逻辑范围继续绑定原租户和调用者。只有显式参与同一次安全验证且此前有效的页面可接合同一身份的新代际；验证期间禁派发，旧异步请求永久失效。身份字段失配后，切回原账号也不能恢复旧页面。

HTTP 终态要求完整受限 JSON、正确内容类型、实际 410、正文整数状态 410、精确错误码和原请求绑定。普通异常或畸形响应不授权清理与重放。
