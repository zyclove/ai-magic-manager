# 审计查询工作台

## 当前能力

管理端 `/audit` 默认查询最近七天，可选择日期范围，按操作代码、资源编号和请求关联编号组合筛选。列表最新记录优先，每页最多二十条；有上一页、下一页、刷新与失败重试。详情提供原始操作者标识、毫秒时间、显示时区、资源与事件编号。标识可选择复制。

日期按照访问者设备的本地时区解释和显示。整日范围包含起始日与结束日；接口使用左闭右开的毫秒范围。最近七天随刷新更新截止时间。查询条件编辑后，点击“应用筛选”才应用；分页沿用已应用的条件。

仅 OWNER、GUARDIAN、ORG_ADMIN、AUDITOR 可读取。每次查询与打开详情检查当前数据库成员关系。儿童、教师和已撤销成员被拒绝。切换工作空间或已获知的角色变化会隐藏原页面和详情；这不代表已经实现服务器主动向浏览器推送撤权事件。

## 接口

`GET /api/v1/tenants/{tenantId}/audit-events/search`

| 参数 | 规则 |
| --- | --- |
| from、to | 必填整数毫秒；`0 ≤ from < to ≤ 8640000000000000`，区间最多 366 天 |
| limit | 默认 20，范围 1–50 |
| action | 可选大写操作代码，字母开头，后续字母/数字/下划线，最多 100 字符 |
| resourceId | 可选规范小写 UUID 或 64 位小写成员身份哈希，兼容现有审计来源 |
| correlationId | 可选服务端生成的规范小写 UUID |
| cursor | 可选不透明续查标识，最多 256 字符；必须沿用租户、时间和筛选条件 |

响应 `{items, nextCursor}`。每项包含 `id, actorId, action, resourceId, correlationId, occurredAt`；按 `(occurredAt DESC, id DESC)` 排序。游标带版本与条件摘要，用于防止误用，不是授权凭据或数据库快照。刷新重新从第一页查询；并发新事件不会插到已经读取的分页前端中，需刷新查看。

`GET /api/v1/tenants/{tenantId}/audit-events/{eventId}` 返回同一事件结构。资源不属于当前租户或不存在时返回 404。无权限时返回 403。旧 `/audit-events` 接口继续使用原先按 ID 的分页合同。

## 失败处理与边界

- 查询失败时隐藏旧结果，并提供重试；翻页失败的重试沿用原目标页。
- 详情再次读取服务器；详情读取被拒绝时隐藏列表旧记录。
- 前端拒绝重复/乱序/越界事件、错误筛选结果、过大页面和不前进的游标。
- 这是服务端管理操作的只读审计视图，不证明设备实际执行。没有新增数据库迁移，也不在查询时写入业务记录。
- 本阶段不包含异步加密导出、下载授权、报告聚合、数据删除/保留治理、主动撤权推送或容量承诺。

验证及最终运行信息见 [实施记录](audit-explorer-plan.md)。
