# 审计异步导出实施记录

依据：已批准 implementation-plan Task 10、产品运营模型 RPT-01，以及“导出请求与撤权并发：作业执行、产物生成、下载都重验权限；撤权后停止访问，过期加密产物清理”。不是完整报告/数据删除/支持诊断的替代。

## 设计与裁定

- 新增 reporting 域，使用现有 Spring 调度、JDBC 事务、幂等组件、近期认证和 Nimbus JOSE。V22 持久化异步导出作业与加密产物。
- Ruling: 当前有界审计产物使用数据库存储标准 JWE，而不是依赖未配置的对象存储。数据库统一处理作业、密文与状态的原子提交；上限 10,000 条和 8 MiB 明文，超过上限明确失败，不截断为成功。后续大报告可提供独立存储适配器。
- JSON 导出包含版本、工作空间、实际查询范围、筛选条件、生成时间、记录数与事件数组；使用 Jackson 标准编码，不提供未经处理的表格公式文本。页面明确为 JSON 日志导出。
- JWE `dir` + `A256GCM`，独立 256 位加密密钥；与配置签名密钥分离。密钥文件为受控本地 JWK Set，最多 8 把，单键可自动选择，多键必须明确 active key ID；保留旧键用于未过期产物。禁止在数据库、响应或日志存储/输出密钥。
- JWE 保护头绑定租户、作业和不可变请求/创建者成员版本摘要。使用 Nimbus 加解密；错误只返回稳定代码，不输出异常中的密文或密钥。未配置密钥时不接受创建，已有管理功能继续运行。
- API `/tenants/{tenant}/audit-exports`：POST 创建（202、必须幂等键）、GET 自己的分页作业；GET `/{id}`、POST `/{id}/cancel`、GET `/{id}/content`。无公开下载链接或 URL 令牌，下载逐次授权、no-store、固定安全文件名。
- OWNER/GUARDIAN/ORG_ADMIN/AUDITOR 可创建本人的审计导出。创建和下载要求真实近期多因素认证；取消用于立即停止自己的导出，不另要求 MFA。教师、儿童、其他创建者不可下载。
- 记录创建者 actorKey 和当前成员 version；后台执行、产物提交和下载重新检查数据库角色/撤权/成员版本。撤权、重新加入或范围变化均不能使旧产物复活。
- 输入复用审计查询范围与过滤合同：最多 366 天、标准操作代码、UUID/64 位成员资源、UUID 关联编号。实际查询截止不超过创建时刻；幂等指纹使用原请求，重复请求返回该作业的当前状态。
- 使用“创建者成员 → 导出专用头 → 作业”的锁顺序，不获取其他模块私有的 MembershipMutex。导出专用头按租户串行化容量检查；持有此头后不再锁另一成员。创建限制本人同时最多 5 个未过期有效作业、租户最多 100 个，并对本人一分钟内创建限速；相同幂等重试不重复计数。
- 状态 QUEUED → RUNNING → READY/FAILED；可进入 CANCELLED/EXPIRED/REVOKED。领取使用数据库锁、随机 claim token、60 秒租约和至多 3 次尝试；崩溃可重新领取，旧执行者不能覆盖新领取、取消或到期状态。调度按批处理，单次生成有行数/字节和事务时间上限。
- 创建后 24 小时到期；到期、取消、失权清除在线密文。终态元数据保留 30 天后有界清理。现有数据库备份的删除/恢复再删除流程仍属于后续 Task 10，不能把在线清理称为备份擦除。
- 管理端提供导出当前已应用条件、作业列表、状态/失败恢复、取消、近期认证恢复和下载。编辑但未应用的条件不进入导出；工作空间变化后隐藏旧作业和停止旧响应。

## 实施顺序

1. 写实际 HTTP/数据库旅程测试，覆盖缺接口、MFA、幂等、租户/创建者隔离、生成、密文、撤权、取消、到期、失败和重启领取。
2. 实现 V22、共享审计查询合同、密钥/JWE、作业服务与有界后台任务；验证 MySQL 和非空升级。
3. 前端作业交互与下载，先测再实现；构建独立候选，不占用在线服务或儿童宿主文件。
4. 一次独立阶段审阅，修复有证据问题；完整回归、浏览器与真实只读/MFA 门槛确认后更新本机运行版本。没有真实 OTP 时不声称真实敏感写入成功。
