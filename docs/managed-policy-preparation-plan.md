# 已发布策略的执行准备链路

2026-10-16，接续 `9a91991` 的设备资料读取。本阶段把当前绑定、冻结发布、提供方注册来源和设备资料联接到完整编译器，为后续执行入账提供可复核输入。

## 实施顺序

1. 内部服务接受租户、当前管理员、发布 ID、绑定 ID 与版本；不接受客户端传入的完整策略或系统能力。
2. 第一个 READ_COMMITTED 短事务读取已验证绑定、当前注册来源、完整发布目标；检查连接器可用且支持所需能力。
3. 事务外按顺序读取注册来源、最小设备资料、注册来源，核对精确远端设备及来源一致性。提供方错误采用固定错误码，不泄露响应体。
4. 第二个短事务重新读取同一上下文，任何授权、绑定、注册或完整发布内容变化均拒绝；校验报告时效，再编译完整文档。
5. 返回内部不可变准备结果，附带资料有效期、上下文和文档摘要。此结果仍需执行编排器核验应用签名与用户空间、兼容矩阵、资源独占，并在入账和写前重新授权；不能直接转为系统执行许可。
6. 验证外层事务拒绝、事务外网络、授权撤销、绑定/发布变化、来源不一致、提供方失败、过期和完整内容保留。采用真实事务管理器与本地模拟边界，明确其不能替代完整授权链或真实设备验收。

## 决策与边界

- 复用现有 Spring 事务、绑定和发布领域服务、官方连接器、来源核验和完整编译器。
- Google 编译器只接受 Google 连接器；合作方通过自己的适配器实现，不把 Google 文档发送给其他提供方。
- 不改并行任务的 `PolicyService`、数据库 V1 或商业目录；现有发布执行门槛保持有效。
- 原有基于冻结预览的状态不是当前应用身份或用户空间证明；准备结果不入执行账本、不发外部写请求。
- 先运行空实现的预期断言失败，再实现及回归。保留失败尝试与源码摘要，阶段完成后按授权提交 `dev`。
