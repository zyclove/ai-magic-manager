# 受管策略完整执行链路：实施计划

## 目标与现状

目标保持为管理员发布后能够完成授权检查、创建执行任务、写入完整策略、分配设备、读取回执及查询执行结果，并支持替换机构 EMM 提供方。生产启用以合格提供方及实际设备能力为前提；本地验证使用明确标识的模拟提供方，不伪装成设备已受控。

基线 `2284c25`：执行账本、查询/取消接口、Flutter 数据入口和设备回执恢复已提交。仍有明确断点：

- `PolicyService.publish` 对 ENFORCE 始终拒绝，尚未形成执行入口。
- 准备服务硬编码 Google 提供方及编译器，不能直接接入中国大陆合作方。
- 应用证据只证明身份，尚未提供受管用户空间和兼容性执行授权。
- 提供方策略资源归属、写入编排、发布事务接合和真实部署仍未完成。

## 顺序与分工

### 1. 提供方可替换的策略准备

- 抽取公开的纯编译器端口，以 Spring Bean 注册提供方代码和文档格式版本。
- 保留现有 Google 编译器、官方 SDK 和完整文档格式；不将 Google 绑定当成合作方的通用身份。
- 准备服务按当前绑定提供方选择编译器，保留前后授权快照、设备身份夹读、设备事实时效与事务边界检查。
- 校验编译结果的上下文、大小、摘要、格式版本及完整 JSON 信封；合作方编译器缺失或冲突时给出明确失败。
- 用独立模拟编译器验证非 Google 提供方通过同一条准备链路；模拟代码仅位于测试源，不注册到生产配置。

### 2. 执行准入和资源归属

- 复用当前机构合同、成员权限、设备注册/绑定及应用身份检查，补齐独立的设备用户空间、型号/系统兼容性和资源归属证据契约。
- 服务端生成候选资源 ID，持久记录归属和提供方版本。提供方须能证明专属资源或提供受审计的独占管理机制；预读 404 不替代归属证明。
- 完整策略参数、授权版本和证据截止时间随任务冻结，写入前重新验证；不得把配置成功或编译成功当成执行许可。

基线源码接合点：`ManagedApplicationEvidenceStore.forPolicy` 仅提供 `UNKNOWN` 用户空间和不可执行标记；`RuleCompiler` 对应用规则即使身份已核验，仍主动降为 `APPLICATION_PROFILE_NOT_VERIFIED`。正在按[应用控制证据计划](managed-application-control-plan.md)补齐提供方报告、精确型号资格、持久化复核和逐操作预览；未通过全部阶段验证前不作为交付。证据至少绑定租户、当前设备注册、受管绑定版本、应用定义/签名版本、提供方适配版本和有效期，且在预览、发布及写入三个时点分别校验。

资源归属接合继续遵循以下验收顺序：

1. 定义提供方可证明的独占策略资源机制、版本与有效期间；没有合作方机制时保持写入关闭，不能由租户请求体声明归属。
2. 服务端生成每次发布使用的资源标识，归属记录同时绑定租户、企业、提供方、发布、设备注册与完整文档摘要。当前完整文档 SDK 接口只是传输能力，不能替代这些事实。
3. 发布短事务重验当前应用操作资格、管理员与合同、预览版本；持久请求与发布原子落库。提供方网络调用放在事务之外。
4. 后台领取后重新准备完整策略、重验资格与独占资源；在任何远程写入前先持久化不确定状态及租约代次。进程中断后只读核对原资源，不生成新的资源来掩盖未知结果。
5. 完整文档与精确版本核对成功后才分配；真正生效仍由独立设备回执确认。取消、证据过期或管理员撤权发生在网络期间时，不接受结果继续推进到下一写操作。

以上为后续待实现与验证的接合要求；本轮应用证据的 `SUPPORTED_PENDING` 不是队列准入凭证。

### 3. 发布、任务与写入编排

- 与持有 `PolicyService.java` 和 V1 基线的协作任务协调最小接合片段；不得覆盖其家庭业务改动。
- 发布入口继续执行管理员近期认证、预览版本和幂等保护；同一发布/设备只创建一次执行请求。
- 发布事务只记录已授权的请求，远程调用在事务外；后台完成当前准备和准入后进入现有执行账本。
- 写入前提交 UNKNOWN 状态；只使用当前有效租约；确认完整内容和资源版本后方可分配。结果不确定时进入只读核对或人工复核，不盲目重发。
- 发布总体状态由设备执行结果汇总，部分失败可解释且不会误报全部生效。

### 4. 接口、界面与验收

- 与执行记录界面接通发布结果和逐设备原因，显示准备中/执行中/等待设备/需复核。
- 本地端到端覆盖管理员发布、受理、策略写入、分配、精确回执、取消、重复请求、权限撤回和进程中断恢复。
- 每阶段独立冻结源、实际验证、记录证据并提交 `dev`；完整产品验收仍包含真实 EMM、数据库、容量与 Android/TV 验证。Android 按用户要求延后，不以模拟结果代替。

## 工程约束

继续使用 Spring/JDBC/官方 SDK；编译器只实现提供方业务转换，不增加自制调度器或消息协议。新增快照、构建输出和临时文件全部放在仓库 `.cache`。SDK 与 Git index 分别明确交接。默认不开启没有合格提供方的生产写入。
