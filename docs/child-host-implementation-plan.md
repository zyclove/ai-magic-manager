## 工作记录

- professional-product-engineering、executing-plans、TDD、12ui-design 和 frontend-app-builder 用于实施。12ui 官方 CLI 安装在 Windows 返回 spawn EINVAL；npx 帮助可运行，但托管生成被自动审批拒绝：未授权将产品简报传至该第三方。没有绕过该目的地，改用当前对话内置 image_gen 的 ui-mockup 设计；第一版到第二版改为完整票据单字段粘贴，当前目标保存 `design/child/concept-v2.png`。
- Ruling: 完整注册凭据使用四字段 JSON 粘贴 — 保留精确 expiresAt 与租户绑定，避免手填期限 — 成本是需要成人端提供复制入口。服务地址、角色、私钥不接受凭据内注入。
- Ruling: Flutter 3.22 的 flutter_localizations 固定 collection1.18；http_parser>=4.1 需 collection1.19 — 将自有 device_policy 最低约束放宽至 ^4.0.2，不强制 overrides — 成本是需复核 4.0.2 的真实 MediaType 解析，独立纯 Dart lock 仍可使用 4.1.2。
- 实际 flutter_secure_storage10.0.0 的 Dart/Flutter 最低约束可解析；其 Android 构建实际要求 compileSdk36 / Java17 / minSdk24，与页面概要不完全相同，以解析源码和构建为准。插件 write 使用 apply，不能只凭 Future 完成宣称磁盘已提交。
- 真实空白模拟器安装 RED：关闭 migrateOnAlgorithmChange 导致插件首次算法标记检查失败。改用 SDK 数据保留迁移，resetOnError 仍 false；原生写入与关闭重开随后通过。后续依赖升级不得凭单元测试跳过真实初始化/迁移检查。
- 凭据过期仍显示健康、读取失败仍显示首次注册、回执失败后显示旧游标均先复现再修正；轮换未完成显示待处理状态并展开相关操作。
- Gradle 默认 4 GiB 堆触发 native malloc 失败，改为 1536 MiB / 2 workers 后构建通过；NDK 固定实际插件要求的 27.0.12077973。仅停止此前已明确归属本阶段且下载阻塞的旧 wrapper，不影响其他任务的构建服务。
- 与并行任务协调后，成人端提供相同四字段 JSON 复制入口；本阶段不暂存其管理台、后端或共享文档改动。
- 原生防卸载/强停、重启作业/可信计时、EMM、获准使用量、额度执行及电视会话仍需后续实现和逐模式验证。当前系统控制固定不支持。
