# 设备执行资料读取与时效核验

## 解决的问题

完整策略编译需要知道设备的管理模式和 Android API 等级。本阶段从服务端配置的受管提供方读取这些事实，避免由儿童客户端声明获得系统权限。读取结果本身不会启动策略写入、设备分配或系统权限提升。

## 组件与数据流

```mermaid
flowchart LR
  B[服务端当前设备绑定] --> R[连接器读取最小设备资料]
  R --> V[精确设备 / 模式 / 状态 / 时效核验]
  V --> C[完整策略编译输入]
  C -. 后续执行编排 .-> J[执行账本与设备回执]
```

- `ManagedAndroidGateway` 默认不支持设备执行资料读取，缺失适配器时返回明确不可用错误；Google 适配器显式提供读取能力。
- 只读取设备名称、管理模式、API 等级、期望状态、已应用状态和最近状态报告时间，不拉取完整应用清单或注册凭据。
- HTTP 404 对应设备资料缺失；权限失败、网络故障、格式异常等保留为失败。禁止自动重定向及重试，设置连接和读取超时，解压后的响应最多 128 KiB。错误日志仅记录状态码与异常类型。
- API 等级必须是正整数 JSON 数值，拒绝字符串、浮点、null 和溢出；精确核对设备名称，拒绝重复 JSON 键和尾随内容。
- `ManagedDeviceExecutionVerifier` 要求 `DEVICE_OWNER`、API 至少 30、期望和已应用状态均为 `ACTIVE`，并核对报告及读取时间。这些是当前完整编译器的必要条件，不代表已经通过某厂商、型号或未来系统版本的兼容认证。

## 时效与配置

有效期限取“报告时间 + 报告最长有效期”和“本次读取时间 + 最长复用期”的较早值。到期时立即拒绝；再次读取旧报告不能突破报告原来的硬期限。服务端传入当前注册/证据的下限时间，早于该下限的报告或读取结果无效。

| Spring 配置 | 默认值 | 可配置范围 |
|---|---:|---|
| `manager.emm.device-profile.max-report-age-seconds` | 600 | 1–3600 秒 |
| `manager.emm.device-profile.max-reuse-age-seconds` | 120 | 1–300 秒 |
| `manager.emm.device-profile.clock-skew-seconds` | 15 | 0–30 秒 |

非法配置启动失败，不能通过零值或负值关闭有效期检查。所有时间比较使用服务端 `Clock`。配置类只提供核验器，不启动后台执行任务。

## 错误与管理员操作

以下是服务端领域错误及后续管理界面的处理约定；本阶段没有新增对应界面或 HTTP 执行入口。

| 错误后缀（统一前缀 `MANAGED_DEVICE_PROFILE_`） | 含义与处理 |
|---|---|
| `CONTEXT_INVALID` | 当前绑定上下文不完整；重新加载绑定，不能手动填写远端身份放行 |
| `MISSING` | 没有可用资料；检查受管注册和设备是否仍存在 |
| `INVALID` | 身份、格式或时间异常；保留关联诊断并重新读取 |
| `MODE_UNSUPPORTED` | 设备模式不满足当前执行路径；显示实际模式及可用的有限能力 |
| `API_UNSUPPORTED` | 低于当前编译器最低 API 要求；使用已认证的兼容设备 |
| `NOT_ACTIVE` | 期望或已应用设备状态不是活动；先解决设备管理状态 |
| `STALE` | 资料过期或属于旧注册；重新获取，不能自动延长 |

## 尚待接通的执行环节

执行编排器仍需在入队和每次写操作前核验当前管理员、机构合同、注册、签名、应用身份、绑定版本及设备兼容矩阵；外部读取与短事务分开，写入前再次检查上下文变化。资料读取不证明远端资源独占、某次写入归因或指定策略已生效。中国大陆 Google 禁用条件及真实 EMM 准入不变。
