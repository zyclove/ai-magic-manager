## 必须保持的产品语义

- 按尚未上线的 **1.0.0** 开发；新结构直接进入初始化基线，不增加历史开发版本兼容层。已有数据库、身份凭据和备份不得被初始化命令隐式清空。
- 功能可用性分别核对配置、套餐权益、当前用户与资源授权、设备/供应商能力、运行状态。任何一项不满足都不能由前端开关或付费成功绕过。
- 保存配置、发布、设备接收、提供方接受、设备实际应用是不同结果。界面沿用各领域状态码，不用一个“成功”概括整个链路。
- 主体、租户、角色或会话变化后，旧页面与弹窗不得继续读取私有结果或提交旧上下文；网络未知结果应核对原操作，不能盲目生成新请求重试。
- 请求期限覆盖身份准备、发送与响应读取。超时后向传输层发出仅针对本次请求的中止信号，配套传输须支持该协议；身份准备或刷新晚完成也不得再派发原请求，不能关闭其他请求共用的会话客户端。中止传输不代表服务端业务已撤销，未知写入仍保留原请求内容与防重复保护。
- 有界 JSON 读取沿用同一整段 25 秒期限；已收到拒绝响应头但正文未完成时，保留已知 HTTP 状态，不出具完整拒绝证据。只有完整且通过格式、长度和作用域核对的错误响应，才可参与原操作的终态或重新验证判断。
- 通用编辑表单的未知提交保留原内容；重试遇到安全验证不能据此放开编辑。过期或已清除的结果停止再次提交并保留只读草稿；关闭未知结果时在原表单内确认，不把关闭解释成撤销；明确关闭后重读所属列表核对，不能继续使用旧草稿或据此显示保存成功。
- 只读校验与本地草稿准备可明确声明没有远端写入；失败后保留可编辑输入，不进入写入结果恢复。调用方必须保证这类回调不写入服务器状态，不能用此模式绕过真正保存、发布或其他写入的未知结果保护。
- 操作结果按既有 90 天恢复约定处理；结果过期不代表原业务未执行，不解除防重复保护。
- 策略草稿新建／编辑使用固定原正文与 UUID 的原子保存记录。未知后只查询原保存结果，完整匹配原修订及规则后才确认；读取当前草稿仅供核对，内容一致也不能证明原保存已执行或解除停止状态。查询发现后续修订时说明原保存已确认并引导核对当前列表。
- 模板复制与历史回滚草稿同样固定 UUID、名称与原修订；未知后只读查询既有原操作日志，不再次复制或回滚。完整核对原规则、来源版本及修订增量，将当前后续修改单独提示；未查到结果保持原输入锁。回滚名称默认当前名称，确认只恢复草稿，仍须重新预览并发布。

## 简洁交互的验收标准

1. 每页围绕一个主要任务组织内容；默认展示当前状态、下一步和一个主要动作，高级参数按需展开。
2. 编辑表单使用安全默认值、可理解的中文标签与就近校验；保留用户已输入内容。提交中防止重复点击，失败时给出可执行的恢复方式。选项分页位置失效时可在原表单从首页重载，保留草稿和仍可用的选择；若服务端明确返回所选目标已失效，提示重新选择，不能复活旧选项或静默换成另一目标。
3. 列表保留查询和当前位置；只读详情关闭不触发无意义刷新。仅在确有保存结果或数据变化时刷新受影响内容。异常分页不得返回部分列表或循环追加；普通读取失败保留已加载内容，权限或工作空间失效仍立即隐藏，成功刷新后再建立新的分页状态。只读工作台同样隔离账号、会话代际和路由生命周期；普通刷新不清空已读摘要，重复刷新只发一次请求，并明确标示旧数据。
4. 操作反馈就近展示，减少叠加弹窗；临时不可交互时，读取和清除入口应同步呈现不可用状态；危险或影响范围大的操作仍展示对象、后果及必要确认。
5. loading、空结果、权限不足、功能未配置、离线和结果未知分别表达；不以持续转圈掩盖失败。无效数值日期显示“时间无效”，不能导致列表构建失败，也不能据此推断已过期或离线。未知地址明确提示页面不存在，不静默加载其他页面。
6. 状态同时使用文字和视觉层级，不能仅靠颜色；长时长摘要统一为小时、分钟和秒，保留精确秒数及流水正负方向，减少手动换算；窄屏优先主要任务，保证键盘焦点、标签和操作可达。列表按自身可用宽度选择卡片或表格，嵌入窄面板／弹窗时搜索框随容器收缩；仅调整宽度须保留搜索、已加载记录、游标与当前操作范围。窄卡提供与表格一致的明确详情按钮；整行点击作为快捷方式，键盘及辅助技术通过按钮进入详情，避免重复焦点。宽屏表格行高随多行内容与字号增长，不以固定高度裁切说明；无创建入口的空态不引导用户执行不可用操作。

策略编辑先显示表单，再按所选规则读取必需目录；已有名称异步补齐。未加载、空目录与读取失败必须区分，失败不清除草稿、不冒充“尚未登记”，并允许显式重载已用选项；重载不自动复活先前关闭的子流程。

规则类型使用用途提示辅助选择；只有一种合法行为时直接说明，不要求重复选择。额度／提醒以分钟与秒输入，编辑保留原整数秒及余数，合计校验 1 秒至 24 小时，不舍入或自动钳制。加入／更新规则只修改本地草稿，完整保存仍由父编辑器完成；摘要以小时、分钟、秒呈现，不改变后台协议。

额度计划的日期例外可直接编辑，满60个仍允许修改已有日期；以分钟＋秒精确保留原值，合计允许0秒至24小时。日期确认只应用到本地草稿，最终由完整计划保存；取消不改动。复制工作日／周末额度保留源的余秒，只有手工更改分钟输入才按整分钟替换。计划提交冻结正文；408视未知，认证拒绝不解除已有未知输入锁，版本冲突／结果不可恢复后停止旧提交并保留只读内容；未知关闭需就近确认，不能被理解为撤销保存。

额度计划未知保存只查询原操作结果，不重放写入；原UUID、正文与更新版本保持，404／近期认证要求保留锁定。完整核对原回执，当前后续配置单独提示，不能代替原保存证明。列表、详情、历史及编辑共用原资源操作租约；取消与只读返回保留列表位置和搜索，已尝试保存或明确关闭未知结果才核对列表，布尔信号不代表保存成功。

每日额度创建／调整采用分钟＋可选秒，精确到1秒；减少前就近检查已结算与预留下界。未知后只查询原创建／调整结果，固定UUID、正文和原版本；当前余额变化单独展示，不替代原回执。取消及只读账本返回保留列表，已有写入尝试才核对；页签切换同步退役原视图，下一帧之前的旧读取也不能打开窗口或影响新页签。额度池完整返回18个事实字段，空关联必须明确为null，不能把缺失资料视同无关联。

机构设备组使用一个加入入口选择1～50台设备，单台与多台均核对完整设备编号及注册周期，再按原组版本整批提交。详情操作串行，选择／确认期间不能重复打开窗口或改变所属视图，旧视图回调不能在返回后复活。多选器的本地搜索不清空已选，满50台就近说明；明确失去读取权限时隐藏原设备及选择，普通网络失败或近期认证要求仍可保留待核对选择。

设备组新建、改名、归档及成员维护统一使用固定UUID与原正文，未知后只查询原操作，保留原版本和明确注册关联；查询未找到、认证要求或普通拒绝不解除未知保护。原回执与当前事实分别核对，合法同名改名或全部设备已存在可返回完整未变快照，不能误判为失败；真实变更须符合版本及成员数关系。版本冲突／结果过期或清除停止旧提交，明确关闭未知结果需就地确认后核对记录。新建表单借用原列表操作租约，普通取消不重读列表，原列表失效后旧创建不能继续提交或打开详情。

设备组列表、详情、成员分页及操作响应在原有效范围内明确拒绝访问时，当前页面锁存失权，清除私有详情、成员、摘要和筛选，并退役原回调及自有窗口；本地会话资料未变化也不能继续操作。已离开的旧视图拒绝不能影响新视图。近期认证要求保留原未知操作，普通网络失败沿用原读取及未知结果恢复语义；不借刷新或短暂恢复重新启用失权页面，重新进入后按服务端当前权限读取。

同一设备组详情刷新时保留已读资料供核对，标明“上次读取”与刷新状态；等待或失败期间暂停修改和继续翻页，避免将旧版本用于新操作，完整读取成功后恢复。用户可直接“刷新设备组”，重复点击不并发读取；切换分组或成员筛选清空旧视图。明确权限拒绝仍清除全部私有资料，未知提交后的当前记录读取不代替原操作证明。

访问审批优先使用已支持的服务端状态筛选，不用单页本地搜索冒充全局待办查询；响应协调后的实际状态决定待办接收，空批次保留后续页入口。角色允许的展示名称可直接使用，缺失时保留完整编号，不为列表展示扩大目录权限。详情中的展示名称须绑定当前请求和完整对象引用，不能覆盖新读取的状态或版本。批准时长以分钟与秒输入，提交前校验合计并保持原整数秒协议。具体边界见[访问申请契约](access-request-contract.md)。

工作空间、时间计划和额度的时区输入复用本地搜索建议，支持城市名称或时区编号，选择只填写编号；已有值不自动改写，目录之外的手填值仍由服务端校验。建议数量有界，不为输入新增网络查询。提交中、结果未知、权限失效或字段移除后，旧建议回调不能改变提交内容。

成员邀请普通取消保留当前分页和搜索；需要核对邀请时直接进入邀请记录，不先重读成员目录。成员、设备与审批操作在首个等待前防重，筛选回调捕获原视图代次；旧回调不能在切换后复活。设备详情、添加／查询注册及访问申请以布尔值返回列表核对信号，纯查看与普通取消不重读，已派发修改或明确退出未知结果后核对；信号不代表保存成功。退出代理操作只观察本窗口交给客户端的确认／取消尝试，不能从已有恢复记录推断新写入。

列表操作及嵌套历史共用原权限和资源租约。原页面关闭或失权时隐藏私有资料，只退役自有窗口；独立通知覆盖时，成功完成也不能关闭通知。注册“查看设备”在原注册窗口结束后继续并等待详情完成，不借延迟回调越过原作用域。

列表筛选状态统一使用类型化路由视图；设备与访问申请页面由宿主持有选择，页面只发出筛选事件。工作台待办直达对应筛选，返回及登录回跳只恢复明确列入白名单的视图，不由参数扩大角色权限；UI 的“全部”视图不冒充后端状态。

设备详情查看纯只读诊断后保留原资料、当前栏目与读取时间，不自动重读详情；用户仍可明确刷新。执行记录可能包含管理员复核、取消或重新检查，继续保留返回后的核对。设备详情的栏目、刷新、撤销、验证、搜索、关闭与子操作入口统一捕获原控制器、窗口代次和所属路由；设备或通知源换绑、离开或关闭时同步退役，控制器往返也不能复活旧事件。关闭只受实际写入保护，失权及读取中仍可关闭；未知撤销仍允许只读核对，MFA 验证仍沿原权限条件可用。输入及入口门禁与内部完成核对分开，不能因自己置忙或打开子窗口而阻断正常续程；确认和子流程仅清理自己仍持有的展示标识。

设备连接检查使用服务端队列，谓词与概览一致并在分页前应用；心跳缺失与过期仅提示检查连接。优先任务直达相应筛选，普通设备入口保留全部视图；筛选切换更新当前路由，保持原权限与游标隔离。

工作台只突出一个当前可查看的优先事项，顺序为求助、访问申请、设备连接；文案按当前角色区分管理审批、本人申请进度及审计只读查看。依据既有授权概览计数与可用入口，不增加权限或自动操作；不可用计数不当作零。正在刷新或读取失败时隐藏任务建议，保留旧摘要说明和读取时间，不用旧数据催办。

通用列表在读取明确被拒绝时清除旧记录与搜索、作废原列表回调和自动刷新；新操作等待一次完整且获授权的读取成功后恢复，保留显式读取重试与安全验证入口。单次操作要求近期 MFA 不等于失去列表读取权，网络失败也不能被表述为操作确定未执行。

设置页的编辑、创建、邀请及账户操作绑定页面展示期的原始账号、工作空间、角色和会话代际；旧入口不能在点击时重新绑定当前身份而复活。页面失效立即拒绝旧操作，编辑弹窗的通知器保留至路由完成后释放，确保页面替换前后均隐藏旧内容；失权后的晚到结果不刷新当前工作空间，也不把拒绝或未知结果当成已取消。

成员详情先读取当前权限事实并展示核心资料；仅在实际获授班级非空时异步补充名称，班级目录失败不阻断成员资料，不当作没有班级。辅助名称保留完整获授编号并提供只读重试；失权、父窗口关闭或原捕获改变时隐藏名称并丢弃晚到结果。调整权限先重新读取最新权限事实，再按所选角色和范围读取所需档案或班级；不把目录作为进入表单的门槛，也不将展示名称当作授权或提交版本。应用身份详情与分类流程返回目录时保留已加载页和搜索；分类独立保存不触发身份目录的无关重读。

成员与邀请的只读详情、权限历史和取消确认返回时保留列表分页与搜索；只有已尝试的保存、撤销或取消邀请及明确核对信号才重读列表。待核对不等于保存成功，PATCH/DELETE 发送前即记录信号，不能因未知结果表单返回空值而漏掉核对。成员表单在调用提交前冻结原正文及班级列表；先前结果未知后，后续安全验证或普通拒绝不能解锁输入。版本冲突或结果过期/已清除时停止旧请求重试，保留带完整编号的只读草稿；未知关闭须就地二次确认，明确不会取消已提交操作。危险确认包含原对象完整编号、成员权限版本及影响，绑定原窗口与权限租约；页面退役立即停止旧入口，帧后通知关闭确认，不能误关独立覆盖窗口。

成员范围选项按需读取：无档案/班级范围的角色不查询目录，儿童及教师单档案只读档案，教师班级只读班级。未读、读取失败与成功空目录分别表达，失败可就地重试；切换角色不必等待无关目录。加载或重载不清空原引用、不默认改为第一项，不更换原版本和请求键；未知提交重试仍使用原正文。目录只属于本次窗口，退役或失权清除缓存并停止晚到分页。

成员范围目录是否就绪与选择是否有效分别处理：加载完成后由原表单就近解释必填、上限和不可用引用，不以无说明的禁用按钮代替选择校验。班级多选支持在已加载名称和完整编号中本地查找、仅看已选；筛选不改变选择，目录缺失的已选项仍可移除。大列表在有限视口内按需构建，达到50项后允许先取消旧项；旧筛选、旧目录或其他范围模式的回调不能越过当前操作锁和权限。

班级与名册的纯查看、取消和只读确认保留已加载页及搜索；写入或恢复信号只表示需要核对，不等于转班或保存成功。操作锁独立于权限与读取作用域，阻止重复打开、导航和旧工具栏事件；需核对时先读取当前班级版本，再重建名册，旧列表不能随后重复读取。班级短表单沿用原内容冻结、认证拒绝后保持未知、不可恢复结果停止重试与就地关闭确认；已提交操作不会因关闭而取消。

儿童档案、应用、时间计划与策略的新建统一返回需核对信号；普通取消不重读列表，真实提交尝试后关闭仍核对，不能只凭表单非空返回判断。档案纯查看、编辑取消及归档取消保留原页，编辑或归档的未知结果关闭后只读核对，不当作成功或重放。概览取消新建时保留原摘要、读取时间与既有错误；若启动操作曾中断正在读取的概览，须补一次读取，不能停留在无数据或擦掉旧错误。

领域格式错误应在字段旁提示并在提交前阻止请求；共享 FieldSpec 可追加纯校验，保留原必填和数值边界规则。具备原结果查询接口的表单可显式提供未知结果查询回调，必须与首次提交成对捕获，查询模式不能在窗口中切回写入；未知恢复只使用不可变原值，不重新解释或校验已锁定控件。HTTP408同样视为结果未知，查询404或认证拒绝不能解除锁定。应用登记的规范化与完整结果核对见[应用契约](policy-application-schedule-contract.md)。

时间计划编辑器的未知保存只查询原 UUID 和冻结正文，不能再次创建；普通安全验证、查询未找到或坏回执不解除未知保护。首次创建和查询都核对完整计划后才确认保存，不能只凭HTTP成功或编号判断。核对复用既有日程模型，不将时区换成工作空间默认值、不遗漏空每周安排或日期例外；复制不改原计划及其策略引用。

ResourcePage 的布尔创建/打开回调接收该次操作的 ResourceActionLease，并与领域原账号、租户、角色及权限捕获取交集。资源离开、来源/筛选变化或失权时同步退役，帧后通知窗口；回调须等待整个子流程及路由完成，由资源页最后释放租约，不能在页面卸载时提前释放。忙碌和子弹窗覆盖不使原操作失权；旧事件、晚结果及旧结束逻辑不能在同键重挂、筛选往返或新操作开始后复活、刷新或解锁新流程。宿主元素被其他模块复用时，原模块捕获也须立即失效；嵌套的编辑、历史与策略预览继续传递同一有效期，不以页面仍 mounted 作为唯一授权依据。

儿童档案默认显示活动档案；成人管理角色可通过“包含已归档”读取服务端管理列表和当前状态，其他角色仍使用原授权活动列表。归档详情仅供查看，不提供编辑或重复归档；未知状态同样停止变更入口。归档确认展示昵称、完整编号、年龄段及影响，说明设备管理不会自动解除。切换筛选开始新的视图代次，往返相同筛选也不能复活旧事件；操作期间禁止筛选切换与重复入口，取消或只读返回仍保留原分页和搜索。操作持有独立于页面释放的通知器，页面离开即停止旧操作，不能在其他模块打开晚到的档案详情或继续原表单。

档案归档在同一确认窗口内提交，使用既有 subjects/changes、一次 UUID 请求键及固定的 operation/subjectId/version 正文。未知结果后禁止再次提交，仅通过原操作编号查询；未查到、查询认证失败或普通拒绝都不能证明未执行。查询须验证原结果的档案编号、归档状态、提交后版本及原昵称/年龄段，同时校验当前快照的编号、状态及版本关系；不能把其他档案或活动状态当作归档成功。版本冲突或结果到期/清除后停止旧请求，保留原档案、版本与操作编号；未知关闭须就地确认，收起确认后旧确认回调无效。尝试后的关闭只表示需要核对，须同时退出外层旧详情再刷新列表；初次明确认证拒绝仍可使用原键和正文人工重试。

档案创建、编辑也使用同一变更与原结果查询契约：CREATE正文不带编号/版本，UPDATE携原编号及原版本；未知后仅查原键和固定正文。原回执须匹配操作、昵称/年龄段、编号及版本增量，当前快照可反映后续编辑或归档，但版本不能倒退，同版本不能变更内容。确认原操作后核对当前列表；若当前档案已有后续变化，提示实际状态，不能把原回执当作刚保存后的最新值。昵称必填和长度在字段旁解释，权限及近期认证仍由服务端独立校验。

求助确认先展示当前记录的对象、设备、类型和提交时间；结果未知时就地提供只读核对入口。服务端明确拒绝访问后，隐藏旧记录并作废当前页面捕获及私有确认窗口，旧会话状态、迟到读取或捕获的按钮不能复活内容。

这些是后续页面增改的标准，不表示全部现有页面均已完成改造。优先复用现有主题、表单、列表与对话框组件。

## 配置、自动化与智能建议

- 部署参数、租户业务规则、商业权益与个人显示偏好分开管理；秘密通过专用文件/Secret 注入，不能进入前端构建参数、公开设置或日志。
- 管理台模块目录只统一导航名称、分组、搜索词和已知内部路由；它不授予 API 权限，也不是可绕过服务端检查的动态功能开关。
- 配置有明确所有者、类型、默认值、范围、校验、应用时机和失效方式；需要重启或重新发布时直接提示，不假装即时生效。
- 自动化使用已有作业、事务幂等与有界重试；配置缺失、授权撤销或身份变化时暂停并说明原因。
- 智能建议展示依据、适用范围和建议动作；高影响策略、权限、收费和设备执行仍需既有授权及确认。建议不能直接扩大权限或伪造执行状态。

## 部署支持与交付判断

Compose 是现有独立环境部署入口，Helm 是已有可配置模板。Windows、Linux、macOS 主机应按实际依赖和各平台验证结果说明支持程度；脚本可解析不等于该平台安装验收完成。

部署预览与初始化共用纯地址、端口及 TLS 校验，在创建目录和密钥前拒绝明显冲突；预览不读取部署凭据或执行工具。工具盘点发现缺项时先说明缺失命令、适用的覆盖参数和重跑入口，不能引导跳过缺项继续部署；参数误用给当前动作的可用参数及帮助，不回显原参数值。自定义工具名称和路径按字面发现，不以通配模式的其他匹配项代替实际配置；预览与输出保留用户原值，构建实际调用绑定已核对的工具完整来源。工具发现、语法通过与真实安装验收分别记录。

管理台 Web 的浏览器可访问性与设备系统管控能力分别验收。Android、TV、iOS、桌面端不因共享 Flutter 代码自动获得同等能力；供应商、真机、Kubernetes、容量与恢复能力仍按各自记录判断。

本批只验证受影响内容：文档核对链接与差异；行为改动优先已有定向测试；授权、数据一致性或发布边界改动检查相应集成。范围内检查通过后停止重复验证，资源不足的项明确写“未运行”。规则见 [AGENTS.md](../AGENTS.md)。
