## 必须保持的产品语义

- 按尚未上线的 **1.0.0** 开发；新结构直接进入初始化基线，不增加历史开发版本兼容层。已有数据库、身份凭据和备份不得被初始化命令隐式清空。
- 功能可用性分别核对配置、套餐权益、当前用户与资源授权、设备/供应商能力、运行状态。任何一项不满足都不能由前端开关或付费成功绕过。
- 保存配置、发布、设备接收、提供方接受、设备实际应用是不同结果。界面沿用各领域状态码，不用一个“成功”概括整个链路。
- 主体、租户、角色或会话变化后，旧页面与弹窗不得继续读取私有结果或提交旧上下文；网络未知结果应核对原操作，不能盲目生成新请求重试。
- 请求期限覆盖身份准备、发送与响应读取。超时后向传输层发出仅针对本次请求的中止信号，配套传输须支持该协议；身份准备或刷新晚完成也不得再派发原请求，不能关闭其他请求共用的会话客户端。中止传输不代表服务端业务已撤销，未知写入仍保留原请求内容与防重复保护。
- 有界 JSON 读取沿用同一整段 25 秒期限；已收到拒绝响应头但正文未完成时，保留已知 HTTP 状态，不出具完整拒绝证据。只有完整且通过格式、长度和作用域核对的错误响应，才可参与原操作的终态或重新验证判断。
- 通用编辑表单的未知提交保留原内容；重试遇到安全验证不能据此放开编辑。过期或已清除的结果停止再次提交并保留只读草稿；关闭未知结果时在原表单内确认，不把关闭解释成撤销；明确关闭后重读所属列表核对，不能继续使用旧草稿或据此显示保存成功。
- 只读校验与本地草稿准备可明确声明没有远端写入；失败后保留可编辑输入，不进入写入结果恢复。调用方必须保证这类回调不写入服务器状态，不能用此模式绕过真正保存、发布或其他写入的未知结果保护。
- 操作结果按既有 90 天恢复约定处理；结果过期不代表原业务未执行，不解除防重复保护。

## 简洁交互的验收标准

1. 每页围绕一个主要任务组织内容；默认展示当前状态、下一步和一个主要动作，高级参数按需展开。
2. 编辑表单使用安全默认值、可理解的中文标签与就近校验；保留用户已输入内容。提交中防止重复点击，失败时给出可执行的恢复方式。选项分页位置失效时可在原表单从首页重载，保留草稿和仍可用的选择；若服务端明确返回所选目标已失效，提示重新选择，不能复活旧选项或静默换成另一目标。
3. 列表保留查询和当前位置；只读详情关闭不触发无意义刷新。仅在确有保存结果或数据变化时刷新受影响内容。异常分页不得返回部分列表或循环追加；普通读取失败保留已加载内容，权限或工作空间失效仍立即隐藏，成功刷新后再建立新的分页状态。只读工作台同样隔离账号、会话代际和路由生命周期；普通刷新不清空已读摘要，重复刷新只发一次请求，并明确标示旧数据。
4. 操作反馈就近展示，减少叠加弹窗；危险或影响范围大的操作仍展示对象、后果及必要确认。
5. loading、空结果、权限不足、功能未配置、离线和结果未知分别表达；不以持续转圈掩盖失败。未知地址明确提示页面不存在，不静默加载其他页面。
6. 状态同时使用文字和视觉层级，不能仅靠颜色；窄屏优先主要任务，保证键盘焦点、标签和操作可达。宽屏表格行高随多行内容与字号增长，不以固定高度裁切说明；无创建入口的空态不引导用户执行不可用操作。

策略编辑先显示表单，再按所选规则读取必需目录；已有名称异步补齐。未加载、空目录与读取失败必须区分，失败不清除草稿、不冒充“尚未登记”，并允许显式重载已用选项；重载不自动复活先前关闭的子流程。

访问审批优先使用已支持的服务端状态筛选，不用单页本地搜索冒充全局待办查询；响应协调后的实际状态决定待办接收，空批次保留后续页入口。角色允许的展示名称可直接使用，缺失时保留完整编号，不为列表展示扩大目录权限。详情中的展示名称须绑定当前请求和完整对象引用，不能覆盖新读取的状态或版本。批准时长以分钟与秒输入，提交前校验合计并保持原整数秒协议。具体边界见[访问申请契约](access-request-contract.md)。

工作空间、时间计划和额度的时区输入复用本地搜索建议，支持城市名称或时区编号，选择只填写编号；已有值不自动改写，目录之外的手填值仍由服务端校验。建议数量有界，不为输入新增网络查询。提交中、结果未知、权限失效或字段移除后，旧建议回调不能改变提交内容。

列表筛选状态统一使用类型化路由视图；设备与访问申请页面由宿主持有选择，页面只发出筛选事件。工作台待办直达对应筛选，返回及登录回跳只恢复明确列入白名单的视图，不由参数扩大角色权限；UI 的“全部”视图不冒充后端状态。

设备连接检查使用服务端队列，谓词与概览一致并在分页前应用；心跳缺失与过期仅提示检查连接。优先任务直达相应筛选，普通设备入口保留全部视图；筛选切换更新当前路由，保持原权限与游标隔离。

工作台只突出一个当前可查看的优先事项，顺序为求助、访问申请、设备连接；文案按当前角色区分管理审批、本人申请进度及审计只读查看。依据既有授权概览计数与可用入口，不增加权限或自动操作；不可用计数不当作零。正在刷新或读取失败时隐藏任务建议，保留旧摘要说明和读取时间，不用旧数据催办。

通用列表在读取明确被拒绝时清除旧记录与搜索、作废原列表回调和自动刷新；新操作等待一次完整且获授权的读取成功后恢复，保留显式读取重试与安全验证入口。单次操作要求近期 MFA 不等于失去列表读取权，网络失败也不能被表述为操作确定未执行。

设置页的编辑、创建、邀请及账户操作绑定页面展示期的原始账号、工作空间、角色和会话代际；旧入口不能在点击时重新绑定当前身份而复活。页面失效立即拒绝旧操作，编辑弹窗的通知器保留至路由完成后释放，确保页面替换前后均隐藏旧内容；失权后的晚到结果不刷新当前工作空间，也不把拒绝或未知结果当成已取消。

成员详情先读取当前权限事实并展示核心资料；仅在实际获授班级非空时异步补充名称，班级目录失败不阻断成员资料，不当作没有班级。辅助名称保留完整获授编号并提供只读重试；失权、父窗口关闭或原捕获改变时隐藏名称并丢弃晚到结果。调整权限仍重新读取最新事实、可选档案和班级，不能将展示名称当作授权或提交版本。应用身份详情与分类流程返回目录时保留已加载页和搜索；分类独立保存不触发身份目录的无关重读。

成员与邀请的只读详情、权限历史和取消确认返回时保留列表分页与搜索；只有已尝试的保存、撤销或取消邀请及明确核对信号才重读列表。待核对不等于保存成功，PATCH/DELETE 发送前即记录信号，不能因未知结果表单返回空值而漏掉核对。成员表单在调用提交前冻结原正文及班级列表；先前结果未知后，后续安全验证或普通拒绝不能解锁输入。版本冲突或结果过期/已清除时停止旧请求重试，保留带完整编号的只读草稿；未知关闭须就地二次确认，明确不会取消已提交操作。危险确认包含原对象完整编号、成员权限版本及影响，绑定原窗口与权限租约；页面退役立即停止旧入口，帧后通知关闭确认，不能误关独立覆盖窗口。

求助确认先展示当前记录的对象、设备、类型和提交时间；结果未知时就地提供只读核对入口。服务端明确拒绝访问后，隐藏旧记录并作废当前页面捕获及私有确认窗口，旧会话状态、迟到读取或捕获的按钮不能复活内容。

这些是后续页面增改的标准，不表示全部现有页面均已完成改造。优先复用现有主题、表单、列表与对话框组件。

## 配置、自动化与智能建议

- 部署参数、租户业务规则、商业权益与个人显示偏好分开管理；秘密通过专用文件/Secret 注入，不能进入前端构建参数、公开设置或日志。
- 管理台模块目录只统一导航名称、分组、搜索词和已知内部路由；它不授予 API 权限，也不是可绕过服务端检查的动态功能开关。
- 配置有明确所有者、类型、默认值、范围、校验、应用时机和失效方式；需要重启或重新发布时直接提示，不假装即时生效。
- 自动化使用已有作业、事务幂等与有界重试；配置缺失、授权撤销或身份变化时暂停并说明原因。
- 智能建议展示依据、适用范围和建议动作；高影响策略、权限、收费和设备执行仍需既有授权及确认。建议不能直接扩大权限或伪造执行状态。

## 部署支持与交付判断

Compose 是现有独立环境部署入口，Helm 是已有可配置模板。Windows、Linux、macOS 主机应按实际依赖和各平台验证结果说明支持程度；脚本可解析不等于该平台安装验收完成。

管理台 Web 的浏览器可访问性与设备系统管控能力分别验收。Android、TV、iOS、桌面端不因共享 Flutter 代码自动获得同等能力；供应商、真机、Kubernetes、容量与恢复能力仍按各自记录判断。

本批只验证受影响内容：文档核对链接与差异；行为改动优先已有定向测试；授权、数据一致性或发布边界改动检查相应集成。范围内检查通过后停止重复验证，资源不足的项明确写“未运行”。规则见 [AGENTS.md](../AGENTS.md)。
