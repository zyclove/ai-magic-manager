# 工作台摘要读取合同

`GET /api/v1/tenants/{tenantId}/overview` 通过当前 OIDC 身份和数据库中的现行成员关系授权，响应 `Cache-Control: no-store`。管理端工作台只取这份摘要，不再为计数和最近活动拉取整个租户的档案、设备、策略、申请和审计列表。

| 字段 | 计算与授权 |
| --- | --- |
| `subjectCount` | 当前可见且未归档的儿童档案数；审计员为 `null` |
| `activeDeviceCount` | 当前可见且 `ACTIVE` 的设备数；审计员为 `null` |
| `connectionCheckCount` | 上述设备中尚无心跳或心跳超过服务端观察时限的数量；审计员为 `null` |
| `policyDraftCount` | 租户策略草稿数；教师、儿童为 `null` |
| `pendingRequestCount` | 尚未到期的 `PENDING` 申请数；儿童和教师仅统计本人提交且仍在当前范围内的申请 |
| `openHelpRequestCount` | 云端仍为 `OPEN` 的儿童求助数；仅家庭所有者、监护人和机构管理员可见，其他角色为 `null` |
| `recentActivity` | 最多五条审计事实，按时间和 ID 倒序；教师、儿童为空数组 |

`null` 表示角色无权读取该维度，不能显示为零。家庭所有者、监护人和机构管理员界面显示主要指标与待查看求助提示；需要检查连接的设备另显示解释与设备列表入口。教师、儿童和审计员首页分别展示其可读的指标与导航：教师和儿童不出现策略草稿、审计事实或成人求助计数，审计员不出现儿童档案和设备计数。设备数字表示注册状态为 `ACTIVE`，不是实时连接数；连接情况另由心跳观察说明。

角色首页随工作空间和角色变化重新建立读取状态。旧请求返回时重新核对当前选中的工作空间、角色和请求代次，不把上一个空间的数据填进新页面。接口失败展示错误与刷新入口，不将失败转成空统计。页面只给出当前角色已有权限的操作入口；所有服务端路由仍独立授权。

各计数通过数据库聚合查询，审计活动限制为五条，不把完整集合送到浏览器。1.0.0 初始建库包含租户内活动档案、设备心跳、待处理申请及求助状态索引。不同计数是独立查询，在并发写入时可能来自不同瞬间；工作台是运营概览，不用于结算、审批或策略执行判定。待处理数用固定读取时刻剔除已到期但尚未由领域流程持久化为 `EXPIRED` 的申请。

`connectionCheckCount` 只表示连接证据不足。心跳过期与尚无心跳不证明设备限制被绕过，也不自动生成儿童安全事件。刷新工作台可重新读取；打开设备列表可查看每台设备的服务端观察状态和最后心跳。
