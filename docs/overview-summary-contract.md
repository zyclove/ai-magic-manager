# 工作台摘要读取合同

`GET /api/v1/tenants/{tenantId}/overview` 通过当前 OIDC 身份和数据库中的现行成员关系授权，响应 `Cache-Control: no-store`。管理端工作台只取这份摘要，不再为四个计数和最近活动拉取整个租户的档案、设备、策略、申请和审计列表。

| 字段 | 计算与授权 |
| --- | --- |
| `subjectCount` | 当前可见且未归档的儿童档案数；审计员为 `null` |
| `activeDeviceCount` | 当前可见且 `ACTIVE` 的设备数；审计员为 `null` |
| `connectionCheckCount` | 上述设备中尚无心跳或心跳超过服务端观察时限的数量；审计员为 `null` |
| `policyDraftCount` | 租户策略草稿数；教师、儿童为 `null` |
| `pendingRequestCount` | 尚未到期的 `PENDING` 申请数；儿童和教师仅统计本人提交且仍在当前范围内的申请 |
| `recentActivity` | 最多五条审计事实，按时间和 ID 倒序；教师、儿童为空数组 |

`null` 表示角色无权读取该维度，不能显示为零。家庭所有者、监护人和机构管理员界面显示四个主要指标；需要检查连接的设备另显示解释与设备列表入口。审计员、教师和儿童目前使用各自的导航首页，摘要接口仍遵循相同的成员授权边界，供后续角色工作台复用。

各计数通过数据库聚合查询，审计活动限制为五条，不把完整集合送到浏览器。V3 增加租户内活动档案、设备心跳及待处理申请索引。不同计数是独立查询，在并发写入时可能来自不同瞬间；工作台是运营概览，不用于结算、审批或策略执行判定。待处理数用固定读取时刻剔除已到期但尚未由领域流程持久化为 `EXPIRED` 的申请。

`connectionCheckCount` 只表示连接证据不足。心跳过期与尚无心跳不证明设备限制被绕过，也不自动生成儿童安全事件。刷新工作台可重新读取；打开设备列表可查看每台设备的服务端观察状态和最后心跳。
