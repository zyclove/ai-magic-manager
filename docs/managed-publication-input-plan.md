## 约定与实施

1. 通过现有租户权限和 ENFORCE 发布目标读取边界取得快照；新增只读方法，返回不可变的应用意图、全部源规则标识、预览就绪状态及保护清单。

3. 保留应用声明的签名与用户空间，但这些声明不成为系统权限证明。预览状态不改成已生效，也不放宽已有发布门槛。
