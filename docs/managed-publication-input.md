# 已发布规则的完整执行输入

## 用户意图与实现流程

管理员预览并确认发布后，执行准备必须使用该次发布的不可变版本，不能重新读取已编辑的草稿，也不能让调用方只传一部分应用或权限。

```mermaid
flowchart LR
  P[发布记录] --> A[当前租户管理员权限]
  A --> V[ENFORCE 版本与精确设备注册]
  V --> S[完整源规则和预览核对]
  S --> D[不可变期望策略]
  D --> C[官方 SDK 完整文档]
  C --> G[后续执行授权与远端资源核验]
  G --> J[后续执行账本与发送器]
```

本阶段完成 P 到 C 的内部读取和转换链路。生产发布入口仍拒绝 ENFORCE，G 到实际发送/回执流程尚未全部接通。不存在以本地编译成功替代系统执行的公开接口。

## 领域边界

- `ManagedExecutionPublicationAccess.requireDesiredTarget` 在既有事务中要求当前 OWNER/ORG_ADMIN 权限，再从发布记录关联版本读取固定快照，核对设备及注册标识。
- 策略模块中的 `ManagedDesiredPolicyResolver` 校验完整源规则与目标预览的覆盖关系。每一条源规则必须在且只在对应分组中出现，种类、应用、权限、预测效果、必需标记保持一致。
- `ManagedDesiredPolicy` 是不可变的领域交接数据；应用签名、用户空间是声明，源规则状态是当时的预览信息。集合不可修改，默认字符串输出隐藏内容。
- `GoogleCompletePolicyCompiler.compileDesired` 消费全部应用和权限，同时合并发布时及当前配置的恢复应用保护清单。系统 API 等级及 DEVICE_OWNER 模式由独立可信上下文提供。
- `managedandroid` 不依赖 `policy.internal`；策略模块实现托管域定义的读取接口，避免循环依赖。

## 转换规则

| 已发布规则 | 完整输入 |
| --- | --- |
| 应用启动允许/禁止 | ALLOW / BLOCK_LAUNCH |
| 应用安装禁止 | BLOCK_INSTALL；官方语义可能卸载已有应用 |
| 安装允许与启动禁止 | 保留 BLOCK_LAUNCH |
| 安装禁止与启动禁止 | BLOCK_INSTALL 同时满足限制；保留两组源规则标识 |
| 安装禁止与启动允许 | 拒绝，不能同时承诺允许启动和可能移除应用 |
| 安装禁止与运行时权限 | 拒绝，不能将权限规则静默丢弃 |
| 运行时权限 DENY / DEFAULT | DENY / PROMPT |
| 同一应用、种类、权限的冲突 | DENY 优先；权限 DEFAULT 优于 GRANT；保留所有源规则标识 |
| 最终仍要求 GRANT | 拒绝自动授予 |
| 卸载策略、特殊访问、额度、时段、网站、提醒 | 本适配器尚不支持完整转换；即使可选也明确拒绝 |

若未来增加其他执行器，应先定义跨执行器完整性与失败恢复契约，再分发规则。本阶段不会先丢弃当前执行器无法表达的部分。

## 数据与授权约束

- 源规则及应用声明各最多 100 项，签名摘要最多 8 项；沿用领域规则的字段、运行时权限和安全包校验。
- 重复规则 ID、重复应用 ID、同包名多个应用声明、缺失来源集合、缺失/重复/不匹配预览分组均拒绝。
- 非 PRIMARY 用户空间、平台不匹配、非活动的冻结设备状态明确拒绝。通过这些检查不证明当前设备仍有执行能力。
- 读取拒绝重复 JSON 字段、未知字段、数字枚举、字符串向布尔或整数的隐式转换、整数向布尔的转换和尾随数据；存储文档最多 4 Mi 字符，防止无界读取。
- 仅读取发布版本，不读取草稿、调用提供方、创建执行任务或改变预览/生效状态。
- 实际发送仍需要当前成员权限、合同资格、设备注册、绑定、真实应用身份和用户空间、提供方准入与远端资源归属验证。已撤销或过期的能力不能使用旧快照恢复。

## 错误契约

这些是内部领域错误，后续界面应通过统一错误翻译展示原因，不能将异常正文直接作为用户说明。

| 错误代码 | 含义与下一步 |
| --- | --- |
| EXECUTION_PUBLICATION_REQUIRED | 不是执行发布；返回配置状态，不能自动升级 |
| EXECUTION_PUBLICATION_TARGET_MISMATCH | 设备或注册不属于这次发布；重新预览 |
| EXECUTION_RULE_KIND_UNSUPPORTED | 规则种类未被完整支持；显示全部相关规则并选择已支持的方案 |
| EXECUTION_RULE_EFFECT_UNSUPPORTED | 最终效果不可执行，如自动授予权限 |
| EXECUTION_RULE_COMBINATION_UNSUPPORTED | 应用与权限组合不能完整表达；要求管理员调整并重新预览 |
| EXECUTION_RULE_COVERAGE_INVALID | 源规则与预览不一致；停止该执行准备并记录关联请求 |
| EXECUTION_APPLICATION_IDENTITY_INVALID | 应用声明缺失、重复或不合法 |
| EXECUTION_APPLICATION_SCOPE_UNSUPPORTED | 平台或用户空间不支持 |
| EXECUTION_TARGET_UNAVAILABLE | 冻结设备状态不可执行 |
| EXECUTION_SOURCE_INVALID | 来源结构不完整或超限 |

既有 SCOPE_DENIED 和安全基线校验错误继续有效。快照解析异常不包含原始存储内容、签名或租户信息。
