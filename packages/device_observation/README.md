# device_observation

独立于 UI 的设备观察协议。复用 `device_policy` 的有界 HTTPS 传输与固定设备路由；Android 宿主提供 Pigeon 系统查询和成熟加密 SDK 存储，不在本包模拟系统权限或实现密码算法。

## 接入约束

- 每个租户/设备/注册周期只有一个 `ObservationAgent`；宿主禁止并行后台采集实例。
- `ObservationStore` 必须原子、耐久且加密，读取失败不得返回空记录。当前 Android 适配为 `flutter_secure_storage` 单记录与原生提交屏障；Web 没有回退。
- `ObservationHttpApi` 使用固定设备路由，凭据由现有身份管理器逐请求提供。不得传入成人令牌或从远程响应改写 API 地址。
- `synchronize(collect: false)` 只核对云端授权及系统许可，不读取应用清单/使用记录。`synchronize()` 仅在本次在线授权通过后采集；宿主仅由明确前台操作调用。
- 生命周期离开前台时调用 `pause()`；销毁时调用 `close()`。暂停不删除已持久化请求，下次须重新核对授权。

## 重试与清理

请求先持久化，后发送；每种报告最多一份 pending。结果未知保留原序号、报告 ID 与载荷，重试前重新核对当前授权。回执注册周期/序号/报告 ID 不匹配时不得推进本地事实。授权版本变化、服务端拒绝授权或设备凭据失效时清理待发载荷，序号不回退。

系统使用访问撤回即在下一次前台核对时清除本地使用载荷；云端离线不可核对时不新增采集。清单 pending 本地最多保留 15 分钟，使用摘要 7 天；这些期限不延长服务端授权或服务端重放窗口。时钟异常、损坏记录或存储失败停止协议，不自动重置身份。

## 边界与验证

仅当前用户可见启动应用，最多 500 条；系统聚合保留实际区间。应用签名摘要和使用记录是设备自报数据，不是安全证明、精确自然日账单、可信计时或系统拦截回执。当前没有周期后台任务、DPC、防卸载和重启策略。

执行 `dart analyze`、`dart test --concurrency=1`。宿主、原生和浏览器验收及后端依赖见 [客户端阶段契约](../../docs/device-observation-client-contract.md)。
